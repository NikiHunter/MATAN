## Источники и пометки

- Транскрипция как есть: [`ocr/raw/`](../../ocr/raw) (по файлу на страницу, `p001`–`p082`).
- Инвентарь сканов: [`ocr/MANIFEST.md`](../../ocr/MANIFEST.md) — три части, 82 страницы.
- Спорные места: [`ocr/ISSUES.md`](../../ocr/ISSUES.md) — **434** пометки, все со статусом `open`.
  Столбец `My decision` пуст, поэтому ни один `⟦ID⟧` не заменён «исправлением» и
  ни одного HTML-комментария вида `<!-- fixed ... -->` в лекциях нет.
- Все пометки продублированы блоками `> [!warning]` с ссылкой на `ocr/ISSUES.md`.
- Рисунки: [`ocr/crops/`](../../ocr/crops) — вырезки `p009`, `p037`, `p070`, `p072`, `p079`;
  в лекциях они подключены относительными путями `../../ocr/crops/...`.
- Сканы `raw/scans/p022.jpg`–`p082.jpg` не коммитятся (см. `.gitignore`): они
  воспроизводятся из присланных архивов, текстовые артефакты ссылаются на них по имени.

Формулы приведены в LaTeX в том виде, в каком они записаны в тетради,
включая описки и незамкнутые выкладки; в лекциях изменена только разметка.

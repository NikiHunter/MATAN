# MathInMind vault

Choose a language:

- [English](en/index.md)
- [Русский](ru/index.md)
- [Español](es/index.md)

The language folders have identical chapter numbers and filenames. This makes it easy to compare terminology while keeping each course independently readable.

For Obsidian, select **Open folder as vault** and choose this `MathInMind` directory. Standard Markdown links, MathJax, Mermaid, and HTML `<details>` blocks are supported. No community plugins are required.

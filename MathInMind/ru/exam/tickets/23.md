# Билет 23. Формула Ньютона–Лейбница. Интегрирование по частям и замена переменной в определенном интеграле

## Вопрос

[Формула Ньютона–Лейбница](../../lectures/04-riemann-properties-4-3.md#thm-4-3-2). [Интегрирование по частям](../../lectures/02-antiderivatives-4-1.md#thm-4-1-4) и замена переменной в [определенном интеграле](../../lectures/03-riemann-integral-4-2.md#def-4-2-6).

## Эталонный ответ

Если $`F'=f`$ и $`f\in\mathcal R[a,b]`$, то $`\int_a^bf=F(b)-F(a)`$.

Интегрирование по частям:

```math
\int_a^bfg'=[fg]_a^b-\int_a^bf'g.
```

Замена переменной:

```math
\int_\alpha^\beta f(\varphi(x))\varphi'(x)dx
=\int_{\varphi(\alpha)}^{\varphi(\beta)}f(t)dt
```

при соответствующих условиях регулярности. Все формулы доказываются формулой Ньютона–Лейбница; нельзя применять её через точку, где $`F`$ не является [первообразной](../../lectures/02-antiderivatives-4-1.md#def-4-1-1).

## Разобранный пример

$`\int_0^\pi x\sin x\,dx=[-x\cos x]_0^\pi+\int_0^\pi\cos x\,dx=\pi`$. Для $`\int_0^1x/(1+x^2)dx`$ замена $`t=1+x^2`$ даёт $`\frac12\log2`$.

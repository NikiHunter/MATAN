# Билет 64. Дифференцирование и арифметические операции. Дифференцирование обратного отображения

[Все билеты](../index.md) · [Лекционный раздел](../../lectures/15-differentiation-rules-6-2.md) · [Термины](../../lectures/terms.md)

> **Лекционная опора:** теоремы 6.2.2 и 6.2.3. При расхождении формулировок приоритет имеет лекция.

## Вопрос

Дифференцирование и арифметические операции. Дифференцирование обратного отображения.

## Эталонный ответ

Дифференциал линеен. Для скалярной $\lambda$ и векторной $f$:

$$d_a(\lambda f)=f(a)d_a\lambda+\lambda(a)d_af.$$

Для скалярного произведения $d_a(f\cdot g)=g(a)d_af+f(a)d_ag$, для частного $d_a(f/g)=(g\,d_af-f\,d_ag)/g^2$.

Если $d_af$ обратим и обратное отображение непрерывно в $f(a)$ при прочих условиях лекции, то $d_{f(a)}f^{-1}=(d_af)^{-1}$. Доказательство использует оценку $\|h\|=O(\|k\|)$ из обратимости.

## Разобранный пример

Для $y=e^x$ производная обратной функции $x=\log y$ равна $1/e^x=1/y$. Для полярной замены определитель обратной Якобиан-матрицы равен $1/r$.

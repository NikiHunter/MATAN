# Билет 26. Вторая теорема о среднем интегрального исчисления. Применение для оценок

[← Билет 25](25.md) · [Все билеты](../index.md) · [Лекционный раздел](../../lectures/05-taylor-wallis-inequalities-4-4.md) · [Термины](../../lectures/terms.md) · [Билет 27 →](27.md)

> **Лекционная опора:** [теорема 4.4.3](../../lectures/05-taylor-wallis-inequalities-4-4.md#thm-4-4-3) (Бонне). При расхождении формулировок приоритет имеет лекция.

## Вопрос

[Вторая теорема о среднем](../../lectures/04-riemann-properties-4-3.md#thm-4-3-1) интегрального исчисления. Применение для оценок.

## Эталонный ответ

Для $`f\in C[a,b]`$ и монотонной $`g\in C^1[a,b]`$ существует $`c\in[a,b]`$:

```math
\int_a^bfg=g(a)\int_a^cf+g(b)\int_c^bf.
```

Это вторая теорема о среднем. Доказательство: для $`F(x)=\int_a^xf`$ интегрируют $`\int fg`$ по частям и применяют первую теорему о среднем к $`\int Fg'`$.

Для оценок монотонный множитель заменяется значениями на концах, а оставшийся интеграл $`F`$ оценивается через его максимум и минимум. Это основа [признаков Дирихле](../../lectures/06-improper-integrals-4-5.md#thm-4-5-4) и Абеля.

## Доказательство

Пусть $`f\in C[a,b]`$, $`g\in C^1[a,b]`$ монотонна и $`F(x)=\int_a^xf`$; тогда $`F'=f`$, $`F(a)=0`$. По частям
```math
\int_a^bfg=F(b)g(b)-\int_a^bF(x)g'(x)\,dx .
```
[Производная](../../lectures-2025-26/lecture-22-23.md#def-3-1-1) $`g'`$ сохраняет знак, $`F`$ непрерывна, поэтому по первой теореме о среднем $`\int_a^bFg'=F(c)\int_a^bg'=F(c)\bigl(g(b)-g(a)\bigr)`$ при некотором $`c\in[a,b]`$. Отсюда
```math
\int_a^bfg=g(a)F(c)+g(b)\bigl(F(b)-F(c)\bigr)=g(a)\int_a^cf+g(b)\int_c^bf .\qquad\square
```
*Оценка.* Если $`|\int_\alpha^\beta f|\le K`$ на всех подотрезках, то $`\bigl|\int_a^bfg\bigr|\le K\bigl(|g(a)|+|g(b)|\bigr)`$: монотонный множитель заменяется значениями в концах.

## Разобранный пример

Для $`f=1`$ и $`g(x)=x`$ на $`[0,1]`$ формула даёт $`\int_0^1x\,dx=0\cdot c+1\cdot(1-c)`$, поэтому $`c=1/2`$. Это согласуется со значением интеграла $`1/2`$.

## Задачи

1. Оцените $`\bigl|\int_{10}^{20}\frac{\sin x}x\,dx\bigr|`$.
2. Докажите, что $`\bigl|\int_A^B\sin(x^2)\,dx\bigr|\le\frac1A+\frac1B`$ при $`0<A<B`$, и выведите сходимость $`\int_1^{\infty}\sin(x^2)\,dx`$.
3. Найдите $`c`$ из теоремы для $`f=\cos x`$, $`g=x`$ на $`\bigl[0,\frac\pi2\bigr]`$.

<details>
<summary>Ответы</summary>

1. $`g=\frac1x`$, $`\bigl|\int_\alpha^\beta\sin x\,dx\bigr|\le2`$: не больше $`2\bigl(\frac1{10}+\frac1{20}\bigr)=\frac3{10}`$.
2. $`\sin(x^2)=2x\sin(x^2)\cdot\frac1{2x}`$, $`\bigl|\int2x\sin(x^2)\,dx\bigr|=|\cos\alpha^2-\cos\beta^2|\le2`$; по [критерию Коши](../../lectures-2025-26/lecture-13.md#thm-2-3-7) интеграл сходится.
3. $`\int_0^{\pi/2}x\cos x\,dx=\frac\pi2-1=\frac\pi2(1-\sin c)`$, $`c=\arcsin\frac2\pi`$.
</details>

## Если снять условие

- **$`g`$ не монотонна.** Для $`f=1`$, $`g=x(1-x)`$ на $`[0,1]`$ правая часть равна нулю при любом $`c`$ ($`g(0)=g(1)=0`$), а $`\int_0^1x(1-x)\,dx=\frac16`$.
- **Без второй теоремы о среднем.** Оценка через первую теорему ($`|\int fg|\le\sup|g|\int|f|`$) для $`\int_A^B\frac{\sin x}x`$ даёт лишь $`\frac{B-A}A`$ и не доказывает сходимость $`\int_1^\infty\frac{\sin x}x\,dx`$.

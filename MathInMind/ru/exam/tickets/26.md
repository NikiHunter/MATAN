# Билет 26. Вторая теорема о среднем интегрального исчисления. Применение для оценок

[Все билеты](../index.md) · [Лекционный раздел](../../lectures/05-taylor-wallis-inequalities-4-4.md) · [Термины](../../lectures/terms.md)

> **Лекционная опора:** теорема 4.4.3 (Бонне). При расхождении формулировок приоритет имеет лекция.

## Вопрос

Вторая теорема о среднем интегрального исчисления. Применение для оценок.

## Эталонный ответ

Для $f\in C[a,b]$ и монотонной $g\in C^1[a,b]$ существует $c\in[a,b]$:

$$\int_a^bfg=g(a)\int_a^cf+g(b)\int_c^bf.$$

Это вторая теорема о среднем. Доказательство: для $F(x)=\int_a^xf$ интегрируют $\int fg$ по частям и применяют первую теорему о среднем к $\int Fg'$.

Для оценок монотонный множитель заменяется значениями на концах, а оставшийся интеграл $F$ оценивается через его максимум и минимум. Это основа признаков Дирихле и Абеля.

## Разобранный пример

Для $f=1$ и $g(x)=x$ на $[0,1]$ формула даёт $\int_0^1x\,dx=0\cdot c+1\cdot(1-c)$, поэтому $c=1/2$. Это согласуется со значением интеграла $1/2$.

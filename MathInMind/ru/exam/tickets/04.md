# Билет 4. Описание опорных прямых выпуклой функции. Характеристика выпуклости с помощью опорных прямых

[Все билеты](../index.md) · [Лекционный раздел](../../lectures/01-convexity-3-8.md) · [Термины](../../lectures/terms.md)

## Вопрос

Описание опорных прямых выпуклой функции. Характеристика выпуклости с помощью опорных прямых.

## Эталонный ответ

Опорная прямая в $a$ имеет вид $g(x)=f(a)+k(x-a)$ и удовлетворяет $f(x)\ge g(x)$ для всех $x$ области. Для внутренней точки выпуклой функции допустимые наклоны описываются

$$k\in[f'_-(a),f'_+(a)].$$

Доказательство сводится к неравенствам для секущих слева и справа. Обратная характеристика: если опорная прямая существует в каждой точке, функция выпукла. Для доказательства берут опорную в выпуклой комбинации $c=\lambda a+(1-\lambda)b$ и складывают два неравенства с весами.

## Разобранный пример

Для $|x|$ в нуле подходят ровно $y=kx$, $-1\le k\le1$. Наклон $k=2$ не подходит, поскольку при $x>0$ график $y=x$ лежит ниже прямой $y=2x$.

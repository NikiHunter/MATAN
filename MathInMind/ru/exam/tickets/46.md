# Билет 46. Критерий Больцано–Коши для последовательности векторов

[Все билеты](../index.md) · [Лекционный раздел](../../lectures/10-vector-sequences-5-2.md) · [Термины](../../lectures/terms.md)

> **Лекционная опора:** теорема 5.2.5. При расхождении формулировок приоритет имеет лекция.

## Вопрос

Критерий Больцано–Коши для последовательности векторов.

## Эталонный ответ

Последовательность фундаментальна, если для любого $\varepsilon>0$ найдётся $N$ с $\|x^k-x^m\|<\varepsilon$ при $k,m>N$. В $\mathbb R^n$ сходимость равносильна фундаментальности.

Необходимость — неравенство треугольника через предел. Достаточность: фундаментальная последовательность ограничена, имеет сходящуюся подпоследовательность по Больцано–Вейерштрассу, а условие Коши приближает всю последовательность к тому же пределу.

## Разобранный пример

Для $x^k=(1/k,1/k^2)$ оценка $\|x^k-x^m\|\le2/\min(k,m)$ в норме $\|\cdot\|_1$ показывает фундаментальность без предварительного нахождения предела.

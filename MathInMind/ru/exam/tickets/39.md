# Билет 39. Применение интеграла Римана к вычислению длины гладкого пути

## Вопрос

Применение [интеграла Римана](../../lectures/03-riemann-integral-4-2.md#def-4-2-6) к вычислению длины [гладкого пути](../../lectures/07-measure-paths-4-6.md#def-4-6-1).

## Эталонный ответ

Для гладкого пути $`\gamma`$ длина равна

```math
s=\int_a^b\|\gamma'(t)\|\,dt.
```

Для графика $`y=f(x)`$: $`s=\int_a^b\sqrt{1+f'^2}dx`$. В [полярных координатах](../../17-multiple-integrals.md#sec-17-3) $`r=r(\theta)`$:

```math
s=\int_\alpha^\beta\sqrt{r^2+(r')^2}\,d\theta.
```

Формула доказывается приближением длин ломаных [суммами Римана](../../lectures/03-riemann-integral-4-2.md#def-4-2-4) и [равномерной непрерывностью](../../lectures-2025-26/lecture-17-18.md#def-2-5-7) $`\gamma'`$. Длина не зависит от сохраняющей ориентацию параметризации.

## Разобранный пример

Для $`y=\frac23x^{3/2}`$ на $`[0,3]`$ имеем $`y'=\sqrt x`$ и $`s=\int_0^3\sqrt{1+x}\,dx=14/3`$. Для $`r=e^\theta`$ на $`[0,1]`$ длина $`\sqrt2(e-1)`$.

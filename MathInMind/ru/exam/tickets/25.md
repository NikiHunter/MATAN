# Билет 25. Формула Валлиса

[← Билет 24](24.md) · [Все билеты](../index.md) · [Лекционный раздел](../../lectures/05-taylor-wallis-inequalities-4-4.md) · [Термины](../../lectures/terms.md) · [Билет 26 →](26.md)

> **Лекционная опора:** [теорема 4.4.2](../../lectures/05-taylor-wallis-inequalities-4-4.md#thm-4-4-2) и [лемма 4.4.1](../../lectures/05-taylor-wallis-inequalities-4-4.md#lem-4-4-1). При расхождении формулировок приоритет имеет лекция.

## Вопрос

Формула Валлиса.

## Эталонный ответ

Формула Валлиса:

```math
\pi=\lim_{n\to\infty}\frac1n\left(\frac{(2n)!!}{(2n-1)!!}\right)^2.
```

Для $`I_m=\int_0^{\pi/2}\sin^mx\,dx`$ [интегрирование по частям](../../lectures/02-antiderivatives-4-1.md#thm-4-1-4) даёт $`I_m=\frac{m-1}{m}I_{m-2}`$, откуда формула через двойные факториалы. Затем используют

```math
\sin^{2n+1}x\le\sin^{2n}x\le\sin^{2n-1}x
```

на $`[0,\pi/2]`$, интегрируют и применяют теорему о зажатии к отношению соседних интегралов.

## Доказательство

*Рекуррентная формула.* Для $`I_m=\int_0^{\pi/2}\sin^mx\,dx`$ при $`m\ge2`$ по частям ($`u=\sin^{m-1}x`$, $`dv=\sin x\,dx`$):
```math
I_m=\bigl[-\sin^{m-1}x\cos x\bigr]_0^{\pi/2}+(m-1)\int_0^{\pi/2}\sin^{m-2}x\cos^2x\,dx=(m-1)(I_{m-2}-I_m),
```
откуда $`I_m=\frac{m-1}mI_{m-2}`$. С $`I_0=\frac\pi2`$, $`I_1=1`$:
```math
I_{2n}=\frac{(2n-1)!!}{(2n)!!}\cdot\frac\pi2,\qquad I_{2n+1}=\frac{(2n)!!}{(2n+1)!!}.
```
*Зажатие.* На $`\bigl[0,\frac\pi2\bigr]`$ $`0\le\sin x\le1`$, поэтому $`\sin^{2n+1}x\le\sin^{2n}x\le\sin^{2n-1}x`$ и $`I_{2n+1}\le I_{2n}\le I_{2n-1}`$. Так как $`\frac{I_{2n-1}}{I_{2n+1}}=\frac{2n+1}{2n}\to1`$, то $`\frac{I_{2n}}{I_{2n+1}}\to1`$. Но
```math
\frac{I_{2n}}{I_{2n+1}}=\frac\pi2(2n+1)\Bigl(\frac{(2n-1)!!}{(2n)!!}\Bigr)^2\to1
\implies \pi=\lim_{n\to\infty}\frac{2}{2n+1}\Bigl(\frac{(2n)!!}{(2n-1)!!}\Bigr)^2=\lim_{n\to\infty}\frac1n\Bigl(\frac{(2n)!!}{(2n-1)!!}\Bigr)^2 .\qquad\square
```

## Разобранный пример

$`I_4=\frac{3\cdot1}{4\cdot2}\frac\pi2=3\pi/16`$, $`I_5=\frac{4\cdot2}{5\cdot3\cdot1}=8/15`$. Их отношение согласуется с приближением $`I_{m+1}/I_m\to1`$.

## Задачи

1. Вычислите $`I_6`$.
2. Выведите из формулы Валлиса асимптотику $`\frac{(2n)!!}{(2n-1)!!}`$.
3. Найдите $`\lim_{n\to\infty}\sqrt n\,\binom{2n}{n}4^{-n}`$.

<details>
<summary>Ответы</summary>

1. $`I_6=\frac{5\cdot3\cdot1}{6\cdot4\cdot2}\cdot\frac\pi2=\frac{5\pi}{32}`$.
2. $`\frac{(2n)!!}{(2n-1)!!}\sim\sqrt{\pi n}`$.
3. $`\binom{2n}n4^{-n}=\frac{(2n-1)!!}{(2n)!!}\sim\frac1{\sqrt{\pi n}}`$, предел равен $`\frac1{\sqrt\pi}`$.
</details>

## Если снять условие

- **Конечное $`n`$ вместо предела.** При $`n=1`$ выражение $`\frac1n\bigl(\frac{(2n)!!}{(2n-1)!!}\bigr)^2`$ равно $`4`$, при $`n=2`$ — $`\frac{32}9\approx3{,}56`$: формула Валлиса — только предельное равенство, и сходимость медленная.
- **Нет оценки отношения соседних интегралов.** Одна лишь цепочка $`I_{2n+1}\le I_{2n}\le I_{2n-1}`$ даёт $`I_{2n}\to0`$, но не предел отношения; ключевой шаг — $`\frac{I_{2n-1}}{I_{2n+1}}=\frac{2n+1}{2n}\to1`$.

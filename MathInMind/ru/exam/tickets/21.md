# Билет 21. Свойства интеграла Римана

[← Билет 20](20.md) · [Все билеты](../index.md) · [Лекционный раздел](../../lectures/04-riemann-properties-4-3.md) · [Термины](../../lectures/terms.md) · [Билет 22 →](22.md)

> **Лекционная опора:** ненумерованные свойства §4.3 и [теорема 4.2.4](../../lectures/03-riemann-integral-4-2.md#thm-4-2-4). При расхождении формулировок приоритет имеет лекция.

## Вопрос

Свойства [интеграла Римана](../../lectures/03-riemann-integral-4-2.md#def-4-2-6).

## Эталонный ответ

Для интегрируемых $`f,g`$:

```math
\int_a^b(\alpha f+\beta g)=\alpha\int_a^b f+\beta\int_a^b g,
\qquad \int_a^b f=\int_a^c f+\int_c^b f.
```

Из $`f\le g`$ следует $`\int f\le\int g`$. Также

```math
m(b-a)\le\int_a^b f\le M(b-a),\qquad
\left|\int_a^b f\right|\le\int_a^b|f|.
```

По соглашению $`\int_a^a f=0`$, $`\int_b^a f=-\int_a^b f`$. Свойства доказываются предельным переходом в [суммах Римана](../../lectures/03-riemann-integral-4-2.md#def-4-2-4).

## Разобранный пример

Для $`0\le x^2\le1`$ на $`[0,1]`$ получаем $`0\le\int_0^1x^2dx\le1`$. Точное значение $`1/3`$ согласуется с оценкой.

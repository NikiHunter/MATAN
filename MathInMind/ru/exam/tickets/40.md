# Билет 40. Применение интеграла Римана к вычислению работы силы

> **Лекционная опора:** приложение работы из лекции 53. При расхождении формулировок приоритет имеет лекция.

## Вопрос

Применение [интеграла Римана](../../lectures/03-riemann-integral-4-2.md#def-4-2-6) к вычислению работы силы.

## Эталонный ответ

При движении по прямой под действием силы $`F(x)`$ в направлении перемещения работа равна

```math
W=\int_a^bF(x)\,dx.
```

На малом отрезке сила почти постоянна, $`\Delta W\approx F(\xi_k)\Delta x_k`$; предел сумм даёт интеграл. Для переменной силы вдоль кривой используется [криволинейный интеграл](../../18-vector-calculus.md#sec-18-1) $`\int_\gamma\mathbf F\cdot d\mathbf r`$. Знак работы зависит от направления силы относительно движения.

## Разобранный пример

Для пружины $`F=kx`$ работа растяжения от $`0`$ до $`a`$ равна $`\int_0^akx\,dx=ka^2/2`$. Для $`F=2x+1`$ на $`[0,3]`$ работа равна $`12`$.

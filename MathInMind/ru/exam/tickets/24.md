# Билет 24. Формула Тейлора с остатком в интегральной форме

[← Билет 23](23.md) · [Все билеты](../index.md) · [Лекционный раздел](../../lectures/05-taylor-wallis-inequalities-4-4.md) · [Термины](../../lectures/terms.md) · [Билет 25 →](25.md)

> **Лекционная опора:** [теорема 4.4.1](../../lectures/05-taylor-wallis-inequalities-4-4.md#thm-4-4-1). При расхождении формулировок приоритет имеет лекция.

## Вопрос

[Формула Тейлора](../../lectures-2025-26/lecture-27-28.md#thm-3-6-3) с остатком в интегральной форме.

## Эталонный ответ

Для $`f\in C^{n+1}`$:

```math
f(x)=\sum_{k=0}^n\frac{f^{(k)}(a)}{k!}(x-a)^k
+\frac1{n!}\int_a^x f^{(n+1)}(t)(x-t)^n\,dt.
```

Последнее слагаемое — остаток в интегральной форме. При $`n=0`$ формула совпадает с Ньютоном–Лейбницем. [Индукционный](../../01-logic-sets-functions.md#example-induction) переход выполняется [интегрированием по частям](../../lectures/02-antiderivatives-4-1.md#thm-4-1-4). Из интегрального остатка получают формы Лагранжа и оценки ошибки через supremum $`|f^{(n+1)}|`$.

## Доказательство

Индукция по $`n`$. При $`n=0`$ это [формула Ньютона–Лейбница](../../lectures/04-riemann-properties-4-3.md#thm-4-3-2) $`f(x)=f(a)+\int_a^xf'(t)\,dt`$. Пусть формула верна для $`n-1`$ и $`f\in C^{n+1}`$. Проинтегрируем остаток по частям, положив $`u=f^{(n)}(t)`$, $`dv=(x-t)^{n-1}dt`$, $`v=-\frac{(x-t)^n}{n}`$:
```math
\frac{1}{(n-1)!}\int_a^xf^{(n)}(t)(x-t)^{n-1}dt
=\frac{f^{(n)}(a)}{n!}(x-a)^n+\frac1{n!}\int_a^xf^{(n+1)}(t)(x-t)^n\,dt ,
```
так как подстановка $`t=x`$ даёт нуль. Подставив это в формулу для $`n-1`$, получаем формулу для $`n`$.

*Форма Лагранжа.* Множитель $`(x-t)^n`$ не меняет знак между $`a`$ и $`x`$, поэтому по [первой теореме о среднем](../../lectures/04-riemann-properties-4-3.md#thm-4-3-1) (с непрерывной $`f^{(n+1)}`$) найдётся $`c`$ между $`a`$ и $`x`$:
```math
\frac1{n!}\int_a^xf^{(n+1)}(t)(x-t)^n\,dt=\frac{f^{(n+1)}(c)}{n!}\cdot\frac{(x-a)^{n+1}}{n+1}=\frac{f^{(n+1)}(c)}{(n+1)!}(x-a)^{n+1}.\qquad\square
```

## Разобранный пример

Для $`e^x`$ при $`a=0`$:

```math
e^x=\sum_{k=0}^n\frac{x^k}{k!}+\frac1{n!}\int_0^xe^t(x-t)^n\,dt.
```

При ограниченном $`x`$ модуль остатка стремится к нулю.

## Задачи

1. Оцените погрешность приближения $`e\approx\sum_{k=0}^n\frac1{k!}`$.
2. Запишите интегральный остаток для $`\ln(1+x)`$ при $`a=0`$, $`n=1`$.
3. Выведите из интегрального остатка оценку $`|R_n(x)|\le\frac{\sup|f^{(n+1)}|}{(n+1)!}|x-a|^{n+1}`$.

<details>
<summary>Ответы</summary>

1. $`R_n=\frac1{n!}\int_0^1e^t(1-t)^n\,dt\le\frac{e}{(n+1)!}`$.
2. $`f''(t)=-\frac1{(1+t)^2}`$: $`R_1(x)=-\int_0^x\frac{x-t}{(1+t)^2}\,dt`$.
3. $`\bigl|\int_a^xf^{(n+1)}(t)(x-t)^n\,dt\bigr|\le\sup|f^{(n+1)}|\cdot\frac{|x-a|^{n+1}}{n+1}`$.
</details>

## Если снять условие

- **$`f'`$ не дифференцируема в одной точке.** Для $`f=|x|`$, $`n=1`$, $`a=-1`$, $`x=1`$ «формула» с $`f''=0`$ вне нуля даёт $`f(1)=f(-1)+f'(-1)\cdot2=-1`$, а на самом деле $`f(1)=1`$.
- **Остаток не обязан стремиться к нулю при $`n\to\infty`$.** Для $`e^{-1/x^2}`$ ($`0`$ в нуле) все многочлены Тейлора в нуле нулевые, и остаток равен самой функции.

# Билет 24. Формула Тейлора с остатком в интегральной форме

[Все билеты](../index.md) · [Лекционный раздел](../../lectures/05-taylor-wallis-inequalities-4-4.md) · [Термины](../../lectures/terms.md)

> **Лекционная опора:** теорема 4.4.1. При расхождении формулировок приоритет имеет лекция.

## Вопрос

Формула Тейлора с остатком в интегральной форме.

## Эталонный ответ

Для $f\in C^{n+1}$:

$$f(x)=\sum_{k=0}^n\frac{f^{(k)}(a)}{k!}(x-a)^k
+\frac1{n!}\int_a^x f^{(n+1)}(t)(x-t)^n\,dt.$$

Последнее слагаемое — остаток в интегральной форме. При $n=0$ формула совпадает с Ньютоном–Лейбницем. Индукционный переход выполняется интегрированием по частям. Из интегрального остатка получают формы Лагранжа и оценки ошибки через supremum $|f^{(n+1)}|$.

## Разобранный пример

Для $e^x$ при $a=0$:

$$e^x=\sum_{k=0}^n\frac{x^k}{k!}+\frac1{n!}\int_0^xe^t(x-t)^n\,dt.$$

При ограниченном $x$ модуль остатка стремится к нулю.

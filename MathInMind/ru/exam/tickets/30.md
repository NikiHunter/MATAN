# Билет 30. Аддитивность несобственного интеграла по промежутку. Остаток несобственного интеграла

[← Билет 29](29.md) · [Все билеты](../index.md) · [Лекционный раздел](../../lectures/06-improper-integrals-4-5.md) · [Термины](../../lectures/terms.md) · [Билет 31 →](31.md)

> **Лекционная опора:** [лемма 4.5.2](../../lectures/06-improper-integrals-4-5.md#lem-4-5-2), [определение 4.5.3](../../lectures/06-improper-integrals-4-5.md#def-4-5-3) и [лемма 4.5.3](../../lectures/06-improper-integrals-4-5.md#lem-4-5-3). При расхождении формулировок приоритет имеет лекция.

## Вопрос

Аддитивность [несобственного интеграла](../../lectures/06-improper-integrals-4-5.md#def-4-5-2) по промежутку. Остаток несобственного интеграла.

## Эталонный ответ

Для $`a<c<b`$:

```math
\int_a^{\to b}f=\int_a^cf+\int_c^{\to b}f.
```

Поэтому сходимость определяется только хвостом. Остаток после $`A`$ равен $`\int_A^{\to b}f`$. Если полный интеграл сходится к $`I`$, то остаток равен $`I-\int_a^Af`$ и стремится к нулю при $`A\to b^-`$.

Эквивалентный [критерий Коши](../../lectures-2025-26/lecture-13.md#thm-2-3-7): для любого $`\varepsilon`$ существует $`A_0`$ такое, что при $`A_0<A<B<b`$ имеем $`|\int_A^Bf|<\varepsilon`$.

## Доказательство

*Аддитивность* — [лемма 4.5.2](../../lectures/06-improper-integrals-4-5.md#lem-4-5-2) (билет 29): $`\int_a^Bf=\int_a^cf+\int_c^Bf`$ и предельный переход при $`B\to b-0`$.

*Остаток* $`\int_A^{\to b}f`$ существует при каждом $`A`$ одновременно со всем интегралом и равен $`I-\int_a^Af\to0`$ ([лемма 4.5.3](../../lectures/06-improper-integrals-4-5.md#lem-4-5-3)).

*Критерий Коши.* Сходимость означает существование конечного [предела функции](../../lectures-2025-26/lecture-14.md#def-2-4-4) $`\Phi(B)=\int_a^Bf`$ при $`B\to b-0`$. По критерию Коши для предела функции (он выводится из критерия Коши для последовательностей через определение Гейне) это равносильно условию
```math
\forall\varepsilon>0\ \exists A_0<b\ \forall A,B\in(A_0,b):\quad|\Phi(B)-\Phi(A)|=\Bigl|\int_A^Bf\Bigr|<\varepsilon .\qquad\square
```

## Разобранный пример

Для $`\int_1^\infty x^{-2}dx=1`$ остаток после $`A`$ равен $`1/A`$ и стремится к нулю. Для гармонического интеграла остаток $`\log(B/A)`$ не становится малым при фиксированном отношении $`B/A`$.

## Задачи

1. Найдите остаток $`\int_A^\infty e^{-x}\,dx`$.
2. Докажите расходимость $`\int_1^\infty\frac{dx}x`$ по критерию Коши.
3. Докажите: если $`\int_a^\infty f`$ сходится и существует $`\lim_{x\to\infty}f(x)=L`$, то $`L=0`$.

<details>
<summary>Ответы</summary>

1. $`e^{-A}`$.
2. $`\int_A^{2A}\frac{dx}x=\ln2`$ при любом $`A`$: [условие Коши](../../lectures-2025-26/lecture-13.md#def-2-3-10) нарушено для $`\varepsilon<\ln2`$.
3. Если $`L>0`$, то $`f>\frac L2`$ на луче $`[A_0,+\infty)`$ и $`\int_{A_0}^Bf>\frac L2(B-A_0)\to\infty`$; случай $`L<0`$ аналогичен.
</details>

## Если снять условие

- **Без предела у $`f`$.** Из сходимости $`\int_a^\infty f`$ не следует $`f\to0`$: $`\int_1^\infty\sin(x^2)\,dx`$ сходится (билет 26), а $`\sin(x^2)`$ не стремится к нулю.
- **Предел по одной последовательности.** $`\int_0^{2\pi n}\sin x\,dx=0`$ при всех $`n`$, но $`\int_0^\infty\sin x\,dx`$ расходится: предел нужен при любом $`B\to b-0`$.

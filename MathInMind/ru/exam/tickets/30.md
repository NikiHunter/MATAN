# Билет 30. Аддитивность несобственного интеграла по промежутку. Остаток несобственного интеграла

## Вопрос

Аддитивность [несобственного интеграла](../../lectures/06-improper-integrals-4-5.md#def-4-5-2) по промежутку. Остаток несобственного интеграла.

## Эталонный ответ

Для $`a<c<b`$:

```math
\int_a^{\to b}f=\int_a^cf+\int_c^{\to b}f.
```

Поэтому сходимость определяется только хвостом. Остаток после $`A`$ равен $`\int_A^{\to b}f`$. Если полный интеграл сходится к $`I`$, то остаток равен $`I-\int_a^Af`$ и стремится к нулю при $`A\to b^-`$.

Эквивалентный [критерий Коши](../../lectures-2025-26/lecture-13.md#thm-2-3-7): для любого $`\varepsilon`$ существует $`A_0`$ такое, что при $`A_0<A<B<b`$ имеем $`|\int_A^Bf|<\varepsilon`$.

## Разобранный пример

Для $`\int_1^\infty x^{-2}dx=1`$ остаток после $`A`$ равен $`1/A`$ и стремится к нулю. Для гармонического интеграла остаток $`\log(B/A)`$ не становится малым при фиксированном отношении $`B/A`$.

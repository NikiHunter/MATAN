# Билет 72. Дифференциалы высших порядков

[Все билеты](../index.md) · [Лекционный раздел](../../lectures/17-higher-derivatives-6-4.md) · [Термины](../../lectures/terms.md)

> **Лекционная опора:** определение 6.4.3 и теорема 6.4.2. При расхождении формулировок приоритет имеет лекция.

## Вопрос

Дифференциалы высших порядков.

## Эталонный ответ

Высшие дифференциалы определяются рекурсивно $d_a^sf(h)=d_a(d^{s-1}f(h))(h)$. Для $C^2$:

$$d_a^2f(h)=\sum_{i,j}f_{x_ix_j}(a)h_ih_j.$$

В общем виде при $|\alpha|=s$:

$$d_a^sf(h)=\sum_{|\alpha|=s}\frac{s!}{\alpha!}\partial^\alpha f(a)h^\alpha.$$

В формуле Тейлора вклад порядка $s$ равен $d_a^sf(h)/s!$. Для $n=2$: $d^2f=f_{xx}h^2+2f_{xy}hk+f_{yy}k^2$ при симметрии смешанных производных.

## Разобранный пример

Для $f=x^2e^y$ в $(1,0)$ вторые производные $(2,2;2,1)$, поэтому $d^2f(h,k)=2h^2+4hk+k^2$. Для одной переменной $d^sf=f^{(s)}(x)h^s$.

# Билет 62. Геометрические свойства градиента. Экстремальное свойство градиента

[← Билет 61](61.md) · [Все билеты](../index.md) · [Лекционный раздел](../../lectures/14-differentiability-6-1.md) · [Термины](../../lectures/terms.md) · [Билет 63 →](63.md)

> **Лекционная опора:** [теорема 6.1.4](../../lectures/14-differentiability-6-1.md#thm-6-1-4). При расхождении формулировок приоритет имеет лекция.

## Вопрос

Геометрические свойства [градиента](../../lectures/14-differentiability-6-1.md#def-6-1-6). Экстремальное свойство градиента.

## Эталонный ответ

При дифференцируемости $`\partial_ef(a)=\nabla f(a)\cdot e`$. Для единичного $`e`$ по Коши–Буняковскому:

```math
|\partial_ef(a)|\le\|\nabla f(a)\|.
```

Равенство достигается только при $`e=\pm\nabla f/\|\nabla f\|`$. Таким образом градиент указывает направление наибольшего возрастания, $`-\nabla f`$ — наибольшего убывания, а максимальная скорость равна $`\|\nabla f\|`$. Градиент также нормален линии или поверхности уровня при его ненулевом значении.

## Доказательство

Для дифференцируемой $`f`$ и единичного $`e`$ по билету 60 $`\partial_ef(a)=\nabla f(a)\cdot e`$, и по [неравенству Коши–Буняковского](../../lectures/05-taylor-wallis-inequalities-4-4.md#thm-4-4-6)
```math
|\partial_ef(a)|\le\|\nabla f(a)\|\,\|e\|=\|\nabla f(a)\| .
```
Если $`\nabla f(a)\ne0`$, равенство достигается только для коллинеарных векторов, то есть при $`e=\pm\frac{\nabla f(a)}{\|\nabla f(a)\|}`$: при знаке «$`+`$» производная по направлению максимальна и равна $`\|\nabla f(a)\|`$, при «$`-`$» — минимальна.

*Ортогональность поверхностям уровня.* Если гладкая кривая $`\gamma(t)`$ лежит на множестве $`\{f=c\}`$ и $`\gamma(0)=a`$, то $`f(\gamma(t))\equiv c`$, и по правилу дифференцирования композиции $`\nabla f(a)\cdot\gamma'(0)=0`$: градиент ортогонален касательным векторам. $`\square`$

## Разобранный пример

Для $`f=x^2+y^2`$ в $`(1,2)`$: $`\nabla f=(2,4)`$, максимальная [производная по направлению](../../lectures/14-differentiability-6-1.md#def-6-1-4) $`2\sqrt5`$ при $`e=(1,2)/\sqrt5`$.

## Задачи

1. Найдите направление наибольшего возрастания $`f=xy+z^2`$ в $`(1,2,1)`$ и скорость роста.
2. Найдите единичную нормаль к кривой $`x^2+2y^2=3`$ в точке $`(1,1)`$.
3. По каким направлениям производная $`x^2-y^2`$ в $`(1,1)`$ равна нулю?

<details>
<summary>Ответы</summary>

1. $`\nabla f=(2,1,2)`$, направление $`\frac13(2,1,2)`$, скорость $`3`$.
2. $`\nabla=(2,4)`$, нормаль $`\frac{(1,2)}{\sqrt5}`$.
3. $`\nabla f=(2,-2)`$, нужно $`e\perp\nabla f`$: $`e=\pm\frac{(1,1)}{\sqrt2}`$.
</details>

## Если снять условие

- **Нулевой градиент.** Для $`x^2+y^2`$ в нуле все производные по направлениям равны нулю, и направления наибольшего роста нет.
- **Нет дифференцируемости.** Для $`\frac{x^2y}{x^2+y^2}`$ (нуль в нуле) «градиент» из [частных производных](../../lectures/14-differentiability-6-1.md#def-6-1-5) равен нулю, а производная по направлению $`\frac{(1,1)}{\sqrt2}`$ положительна: формула $`\partial_ef=\nabla f\cdot e`$ неверна.

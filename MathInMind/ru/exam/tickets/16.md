# Билет 16. Ограниченность интегрируемой функции. Верхний и нижний интегралы Дарбу. Критерий интегрируемости функции. Колебание функции и интегрируемость

## Вопрос

Ограниченность интегрируемой функции. Верхний и [нижний интегралы Дарбу](../../lectures/03-riemann-integral-4-2.md#def-4-2-8). [Критерий интегрируемости](../../lectures/03-riemann-integral-4-2.md#thm-4-2-1) функции. [Колебание](../../lectures/03-riemann-integral-4-2.md#def-4-2-9) функции и интегрируемость.

## Эталонный ответ

[Интегрируемая по Риману](../../lectures/03-riemann-integral-4-2.md#def-4-2-6) функция ограничена: иначе [оснащением](../../lectures/03-riemann-integral-4-2.md#def-4-2-4) можно сделать суммы неограниченными. Для ограниченной $`f`$ определяются $`I_*=\sup s_\tau`$ и $`I^*=\inf S_\tau`$.

Критерий Дарбу: $`f\in\mathcal R[a,b]\iff I_*=I^*\iff S_\tau-s_\tau\to0`$. Достаточно для любого $`\varepsilon`$ найти одно [разбиение](../../lectures/03-riemann-integral-4-2.md#def-4-2-2) с $`S_\tau-s_\tau<\varepsilon`$.

Колебание $`\omega_D(f)=\sup_Df-\inf_Df`$ связывает суммы: $`S_\tau-s_\tau=\sum\omega_k\Delta x_k`$.

## Разобранный пример

Для функции Дирихле на $`[0,1]`$ каждый частичный отрезок содержит рациональные и иррациональные точки, поэтому $`\omega_k=1`$ и $`S_\tau-s_\tau=1`$ для всех разбиений. Интегрируемости нет.

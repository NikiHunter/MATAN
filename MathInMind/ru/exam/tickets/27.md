# Билет 27. Неравенство Иенсена и Неравенство Гёльдера для интегралов

[← Билет 26](26.md) · [Все билеты](../index.md) · [Лекционный раздел](../../lectures/05-taylor-wallis-inequalities-4-4.md) · [Термины](../../lectures/terms.md) · [Билет 28 →](28.md)

> **Лекционная опора:** [теоремы 4.4.4](../../lectures/05-taylor-wallis-inequalities-4-4.md#thm-4-4-4) и [4.4.5](../../lectures/05-taylor-wallis-inequalities-4-4.md#thm-4-4-5). При расхождении формулировок приоритет имеет лекция.

## Вопрос

Неравенство Иенсена и [Неравенство Гёльдера](../../lectures/05-taylor-wallis-inequalities-4-4.md#thm-4-4-5) для интегралов.

## Эталонный ответ

Интегральное [неравенство Йенсена](../../lectures/05-taylor-wallis-inequalities-4-4.md#thm-4-4-4) для выпуклой $`\varphi`$ и веса $`\lambda\ge0`$ с $`\int\lambda=1`$:

```math
\varphi\left(\int_a^b\lambda f\right)\le\int_a^b\lambda(\varphi\circ f).
```

Оно получается пределом дискретного неравенства Йенсена.

Неравенство Гёльдера для $`1/p+1/q=1`$:

```math
\left|\int fg\right|\le\|f\|_p\|g\|_q.
```

Его можно доказать через неравенство Юнга $`uv\le u^p/p+v^q/q`$, которое само следует из [выпуклости](../../lectures/01-convexity-3-8.md#def-3-8-1) $`e^x`$ или вогнутости логарифма. При $`p=q=2`$ получается Коши–Буняковский.

## Разобранный пример

Для $`\varphi(x)=x^2`$ и равномерного веса получаем $`(\int_a^bf)^2\le(b-a)\int_a^bf^2`$. Это также прямое следствие [Коши–Буняковского](../../lectures/05-taylor-wallis-inequalities-4-4.md#thm-4-4-6) с $`g=1`$.

# Билет 27. Неравенство Иенсена и Неравенство Гёльдера для интегралов

[← Билет 26](26.md) · [Все билеты](../index.md) · [Лекционный раздел](../../lectures/05-taylor-wallis-inequalities-4-4.md) · [Термины](../../lectures/terms.md) · [Билет 28 →](28.md)

> **Лекционная опора:** [теоремы 4.4.4](../../lectures/05-taylor-wallis-inequalities-4-4.md#thm-4-4-4) и [4.4.5](../../lectures/05-taylor-wallis-inequalities-4-4.md#thm-4-4-5). При расхождении формулировок приоритет имеет лекция.

## Вопрос

Неравенство Иенсена и [Неравенство Гёльдера](../../lectures/05-taylor-wallis-inequalities-4-4.md#thm-4-4-5) для интегралов.

## Эталонный ответ

Интегральное [неравенство Йенсена](../../lectures/05-taylor-wallis-inequalities-4-4.md#thm-4-4-4) для выпуклой $`\varphi`$ и веса $`\lambda\ge0`$ с $`\int\lambda=1`$:

```math
\varphi\left(\int_a^b\lambda f\right)\le\int_a^b\lambda(\varphi\circ f).
```

Оно получается пределом дискретного неравенства Йенсена.

Неравенство Гёльдера для $`1/p+1/q=1`$:

```math
\left|\int fg\right|\le\|f\|_p\|g\|_q.
```

Его можно доказать через неравенство Юнга $`uv\le u^p/p+v^q/q`$, которое само следует из [выпуклости](../../lectures/01-convexity-3-8.md#def-3-8-1) $`e^x`$ или вогнутости логарифма. При $`p=q=2`$ получается Коши–Буняковский.

## Доказательство

*Йенсен.* Пусть $`\varphi`$ выпукла на промежутке, содержащем значения $`f`$, $`\lambda\ge0`$, $`\int_a^b\lambda=1`$, и $`m=\int_a^b\lambda f`$ — внутренняя точка промежутка. Возьмём опорную прямую в $`m`$ ([лемма 3.8.2](../../lectures/01-convexity-3-8.md#lem-3-8-2)): $`\varphi(y)\ge\varphi(m)+k(y-m)`$. Подставим $`y=f(x)`$, умножим на $`\lambda(x)\ge0`$ и проинтегрируем:
```math
\int_a^b\lambda\,\varphi(f)\ge\varphi(m)\int_a^b\lambda+k\Bigl(\int_a^b\lambda f-m\int_a^b\lambda\Bigr)=\varphi(m).
```
*Юнг.* Для $`u,v>0`$ по вогнутости логарифма $`\ln\bigl(\frac{u^p}p+\frac{v^q}q\bigr)\ge\frac1p\ln u^p+\frac1q\ln v^q=\ln(uv)`$, то есть $`uv\le\frac{u^p}p+\frac{v^q}q`$.

*Гёльдер.* Если $`\|f\|_p,\|g\|_q>0`$, положим $`u=\frac{|f|}{\|f\|_p}`$, $`v=\frac{|g|}{\|g\|_q}`$ и проинтегрируем неравенство Юнга: $`\int uv\le\frac1p+\frac1q=1`$, то есть $`\int|fg|\le\|f\|_p\|g\|_q`$. Если, например, $`\|f\|_p=0`$, то из $`|fg|\le\frac{t^p|f|^p}p+\frac{|g|^q}{qt^q}`$ получаем $`\int|fg|\le\frac{\|g\|_q^q}{qt^q}\to0`$ при $`t\to\infty`$. Наконец, $`\bigl|\int fg\bigr|\le\int|fg|`$. $`\square`$

## Разобранный пример

Для $`\varphi(x)=x^2`$ и равномерного веса получаем $`(\int_a^bf)^2\le(b-a)\int_a^bf^2`$. Это также прямое следствие [Коши–Буняковского](../../lectures/05-taylor-wallis-inequalities-4-4.md#thm-4-4-6) с $`g=1`$.

## Задачи

1. Докажите $`\bigl(\int_0^1f\bigr)^2\le\int_0^1f^2`$.
2. Докажите $`\int_0^1\ln f\le\ln\int_0^1f`$ для положительной непрерывной $`f`$.
3. Оцените $`\int_0^1\sqrt{x(1-x)}\,dx`$ неравенством Гёльдера при $`p=q=2`$.

<details>
<summary>Ответы</summary>

1. Йенсен для $`\varphi(y)=y^2`$ и $`\lambda\equiv1`$.
2. Йенсен для выпуклой $`-\ln`$.
3. $`\le\bigl(\int_0^1x\bigr)^{1/2}\bigl(\int_0^1(1-x)\bigr)^{1/2}=\frac12`$; точное значение $`\frac\pi8\approx0{,}39`$.
</details>

## Если снять условие

- **$`\varphi`$ не выпукла.** Для вогнутой $`\varphi=-y^2`$ и $`f=x`$ на $`[0,1]`$: $`\varphi\bigl(\int f\bigr)=-\frac14>-\frac13=\int\varphi(f)`$.
- **Показатели не сопряжены.** При $`p=q=1`$ неравенство $`\int|fg|\le\int|f|\int|g|`$ неверно: для $`f=g=3\cdot1_{[0,1/3]}`$ слева $`3`$, справа $`1`$.

# 15. Дифференцирование отображений нескольких переменных

[← 14. Функции нескольких переменных](14-several-variables.md) · [Оглавление](index.md) · [Термины и теоремы](term-index.md) · [16. Обратные и неявные функции; экстремумы →](16-implicit-functions-extrema.md)

> **Цель.** Использовать [полную производную](#sec-15-1) как линейное отображение и связывать её с [частными производными](#sec-15-2), градиентом и приближениями высших порядков.

<a id="sec-15-1"></a>
## 15.1 Полная производная

Для $`F:D\subseteq\mathbb R^n\to\mathbb R^m`$ и [внутренней точки](13-metric-spaces.md#sec-13-2) $`a`$ производная — линейное отображение $`DF(a):\mathbb R^n\to\mathbb R^m`$ такое, что

```math
F(a+h)=F(a)+DF(a)h+o(\|h\|)\qquad(h\to0).
```

Равносильно, $`\|F(a+h)-F(a)-DF(a)h\|/\|h\|\to0`$. Дифференцируемость влечёт непрерывность. Матрица $`DF(a)`$ в стандартных координатах называется **матрицей Якоби**.

Для скалярной $`f`$ производная представляется градиентом $`\nabla f(a)`$:

```math
f(a+h)=f(a)+\nabla f(a)\cdot h+o(\|h\|).
```

Градиент указывает направление наискорейшего возрастания среди единичных направлений; максимум производной по направлению равен $`\|\nabla f(a)\|`$.

<a id="sec-15-2"></a>
## 15.2 Частные производные и производные по направлению

Частные производные:

```math
\frac{\partial f}{\partial x_i}(a)
=\lim_{t\to0}\frac{f(a+te_i)-f(a)}t.
```

Если $`F`$ дифференцируема, все частные производные существуют и

```math
DF(a)=\left(\frac{\partial F_i}{\partial x_j}(a)\right)_{i,j}.
```

Обратное требует осторожности: существование частных производных, даже около $`a`$, не гарантирует дифференцируемость. Достаточное условие: все частные производные существуют около $`a`$ и непрерывны в $`a`$; тогда $`F`$ дифференцируема в $`a`$.

Производная по вектору $`v`$:

```math
D_vf(a)=\left.\frac{d}{dt}f(a+tv)\right|_{t=0}.
```

Если $`f`$ дифференцируема, то $`D_vf(a)=\nabla f(a)\cdot v`$. Одного существования всех производных по направлениям недостаточно.

<a id="sec-15-3"></a>
## 15.3 Правило цепочки и касательные плоскости

Если $`F`$ дифференцируема в $`a`$, а $`G`$ — в $`F(a)`$, то

```math
D(G\circ F)(a)=DG(F(a))\,DF(a),
```

где произведение матричное. Эта формула содержит все многомерные правила цепочки.

Для дифференцируемой $`f(x,y)`$ касательная плоскость к графику в $`(a,b)`$:

```math
z=f(a,b)+f_x(a,b)(x-a)+f_y(a,b)(y-b).
```

Для поверхности уровня $`F(x,y,z)=c`$ с $`\nabla F(a)\ne0`$ касательная плоскость имеет вид $`\nabla F(a)\cdot(x-a)=0`$. Градиент нормален множеству уровня.

<a id="sec-15-4"></a>
## 15.4 Высшие производные и формула Тейлора

Функция принадлежит $`C^k`$, если все частные производные до порядка $`k`$ существуют и непрерывны.

> <a id="clairaut-schwarz-theorem"></a>**Теорема Клеро–Шварца.** Если смешанные вторые частные производные непрерывны около точки, порядок дифференцирования можно менять: $`f_{xy}=f_{yx}`$.

Для $`f\in C^2`$ гессиан $`Hf(a)`$ — симметричная матрица вторых частных производных. Разложение Тейлора второго порядка:

```math
f(a+h)=f(a)+\nabla f(a)\cdot h
+\frac12h^{T}Hf(a)h+o(\|h\|^2).
```

Квадратичная форма $`h^THh`$ описывает локальную кривизну и используется в исследовании экстремумов.

<a id="sec-15-5"></a>
## 15.5 Частные производные: вычисление, примеры, приёмы

### Как вычислять

Чтобы найти $`f_x(a,b)`$, «заморозьте» вторую переменную: положите $`y=b`$ и продифференцируйте по $`x`$ функцию одной переменной $`\varphi(x)=f(x,b)`$. Это не отдельное правило, а определение из [§15.2](#sec-15-2), записанное через $`\varphi`$:

```math
f_x(a,b)=\lim_{t\to0}\frac{f(a+t,b)-f(a,b)}t=\lim_{t\to0}\frac{\varphi(a+t)-\varphi(a)}t=\varphi'(a).
```

Поэтому для частных производных годятся [таблица производных](formula-sheet.md#derivative-table) и все одномерные правила, включая [правило цепочки](06-derivatives.md#chain-rule), а замороженная переменная ведёт себя как константа: $`\frac{\partial}{\partial x}y^2=0`$, $`\frac{\partial}{\partial x}(xy)=y`$, $`\frac{\partial}{\partial x}e^{xy}=y\,e^{xy}`$. Геометрически $`f_x(a,b)`$ — угловой коэффициент касательной к сечению графика $`z=f(x,y)`$ плоскостью $`y=b`$. Для $`f(x_1,\dots,x_n)`$ при вычислении $`\partial f/\partial x_i`$ замораживают все переменные, кроме $`x_i`$.

Обозначения: $`f_x=f'_x=\frac{\partial f}{\partial x}`$. Из частных производных собираются градиент $`\nabla f=(f_x,f_y)`$ и матрица Якоби $`DF=\left(\frac{\partial F_i}{\partial x_j}\right)`$: её $`i`$-я строка — градиент компоненты $`F_i`$.

### Разобранные примеры

**Пример 1.** $`f(x,y)=x^2y+\sin(xy)`$. При фиксированном $`y`$ слагаемое $`x^2y`$ — это $`x^2`$, умноженное на константу $`y`$, а $`\sin(xy)`$ — сложная функция с внутренней функцией $`xy`$, производная которой по $`x`$ равна $`y`$. По $`y`$ роли меняются: $`\frac{\partial}{\partial y}(x^2y)=x^2`$, $`\frac{\partial}{\partial y}(xy)=x`$. Итак,

```math
f_x=2xy+y\cos(xy),\qquad f_y=x^2+x\cos(xy).
```

**Пример 2.** $`f(x,y)=x^y`$, $`x>0`$. Логарифмическое дифференцирование: $`\ln f=y\ln x`$. Продифференцируем это равенство по $`x`$ и по $`y`$; слева по правилу цепочки получаются $`f_x/f`$ и $`f_y/f`$:

```math
\frac{f_x}f=\frac yx\ \Longrightarrow\ f_x=x^y\cdot\frac yx=y\,x^{y-1},
\qquad
\frac{f_y}f=\ln x\ \Longrightarrow\ f_y=x^y\ln x.
```

Проверка заморозкой: при фиксированном $`y`$ функция $`x^y`$ степенная, при фиксированном $`x`$ — показательная, и табличные формулы дают те же ответы.

**Пример 3.** $`f(x,y)=\operatorname{arctg}\frac yx`$, $`x\ne0`$. Внешняя функция — $`\operatorname{arctg}`$, внутренняя — $`\frac yx`$, и $`\frac1{1+(y/x)^2}=\frac{x^2}{x^2+y^2}`$. Поэтому

```math
f_x=\frac{x^2}{x^2+y^2}\cdot\Bigl(-\frac y{x^2}\Bigr)=-\frac y{x^2+y^2},
\qquad
f_y=\frac{x^2}{x^2+y^2}\cdot\frac1x=\frac x{x^2+y^2}.
```

**Пример 4 (правило цепочки).** $`z=F(u,v)`$, где $`u=xy`$, $`v=x+y`$, а $`F`$ дифференцируема. Переменная $`x`$ влияет на $`z`$ двумя путями, через $`u`$ и через $`v`$, и вклады путей складываются:

```math
z_x=F_u\,u_x+F_v\,v_x=y\,F_u+F_v,
\qquad
z_y=F_u\,u_y+F_v\,v_y=x\,F_u+F_v,
```

где $`F_u`$ и $`F_v`$ вычисляются в точке $`(xy,\,x+y)`$. В матричной форме это правило цепочки из [§15.3](#sec-15-3) для композиции $`z=F\circ\Phi`$, где $`\Phi(x,y)=(xy,\,x+y)`$: строка $`(F_u,F_v)`$ умножается на матрицу Якоби отображения $`\Phi`$,

```math
(z_x,\ z_y)=(F_u,\ F_v)\begin{pmatrix}u_x&u_y\\v_x&v_y\end{pmatrix}=(F_u,\ F_v)\begin{pmatrix}y&x\\1&1\end{pmatrix}.
```

Проверка на $`F(u,v)=uv`$: тогда $`z=xy(x+y)=x^2y+xy^2`$, и напрямую $`z_x=2xy+y^2`$; по формуле $`y\,F_u+F_v=y\,v+u=y(x+y)+xy=2xy+y^2`$.

**Пример 5 (неявная функция).** Пусть $`F(x,y(x))\equiv0`$ и $`F_y\ne0`$. Продифференцируем тождество по $`x`$: $`x`$ входит в $`F`$ и напрямую, и через $`y`$, поэтому $`F_x+F_y\,y'=0`$ и

```math
\frac{dy}{dx}=-\frac{F_x}{F_y}.
```

Существование и дифференцируемость $`y(x)`$ при $`F\in C^1`$ и $`F_y\ne0`$ гарантирует [теорема о неявной функции](16-implicit-functions-extrema.md#sec-16-3). Для декартова листа $`x^3+y^3-3xy=0`$ имеем $`F_x=3x^2-3y`$, $`F_y=3y^2-3x`$, и при $`y^2\ne x`$

```math
\frac{dy}{dx}=-\frac{3x^2-3y}{3y^2-3x}=\frac{y-x^2}{y^2-x}.
```

Тот же ответ даёт прямое дифференцирование тождества: $`3x^2+3y^2y'-3y-3xy'=0`$, откуда $`(3y^2-3x)\,y'=3y-3x^2`$. Точка $`\bigl(\frac32,\frac32\bigr)`$ лежит на кривой: $`\frac{27}8+\frac{27}8=\frac{27}4=3\cdot\frac32\cdot\frac32`$. В ней

```math
y'=\frac{3/2-9/4}{9/4-3/2}=\frac{-3/4}{3/4}=-1.
```

На кривой $`F_y=0`$ ровно в точках $`(0,0)`$ и $`(\sqrt[3]4,\sqrt[3]2)`$, и там формула неприменима: в начале координат кривая пересекает сама себя, а во второй точке касательная вертикальна ($`F_x=3\sqrt[3]2\ne0`$).

**Пример 6 (дифференциал).** Дифференциал $`df=f_x\,dx+f_y\,dy`$ — линейная часть приращения. Для [дифференцируемой](#sec-15-1) $`f`$

```math
f(a+h)\approx f(a)+\nabla f(a)\cdot h=f(a)+f_x(a)\,h_1+f_y(a)\,h_2
```

с ошибкой $`o(\|h\|)`$. Оценим $`1{,}02^{3{,}01}`$: $`f(x,y)=x^y`$, $`a=(1,3)`$, $`h=(0{,}02;\ 0{,}01)`$. По примеру 2 $`f_x(1,3)=3\cdot1^2=3`$ и $`f_y(1,3)=1^3\ln1=0`$, поэтому

```math
1{,}02^{3{,}01}\approx1+3\cdot0{,}02+0\cdot0{,}01=1{,}06.
```

Точное значение $`1{,}0614\ldots`$; ошибка $`\approx0{,}0014`$ на порядок меньше $`\|h\|\approx0{,}022`$. Тот же градиент даёт производную по направлению: для единичного вектора $`v=\bigl(\frac35,\frac45\bigr)`$ имеем $`D_vf(1,3)=\nabla f(1,3)\cdot v=3\cdot\frac35+0\cdot\frac45=\frac95`$.

### Смешанные производные и теорема Шварца

Вторые частные производные — частные производные от частных производных. Порядок как в лекции: $`f_{xy}=\frac{\partial^2f}{\partial x\,\partial y}=(f_x)_y`$ — сначала по $`x`$, затем по $`y`$; $`f_{yx}=(f_y)_x`$. Вместе с $`f_{xx}`$ и $`f_{yy}`$ они образуют [гессиан](#sec-15-4)

```math
Hf=\begin{pmatrix}f_{xx}&f_{xy}\\f_{yx}&f_{yy}\end{pmatrix},
```

и его симметричность — это равенство $`f_{xy}=f_{yx}`$.

**Теорема Шварца** ([теорема 6.4.1](lectures-2025-26/lecture-63-64.md#thm-6-4-1); в курсе — [теорема Клеро–Шварца](#clairaut-schwarz-theorem)). Если $`f_{xy}`$ и $`f_{yx}`$ определены в окрестности точки $`a`$ и непрерывны в $`a`$, то $`f_{xy}(a)=f_{yx}(a)`$. Лекция даёт и второе достаточное условие: $`f`$ дважды дифференцируема в $`a`$. В частности, при $`f\in C^2`$ гессиан симметричен и порядок дифференцирования не важен.

Без условия теорема неверна. Классический контрпример (он же разобран в лекции):

```math
f(x,y)=\begin{cases}xy\,\dfrac{x^2-y^2}{x^2+y^2},&(x,y)\ne(0,0),\\0,&(x,y)=(0,0).\end{cases}
```

**Шаг 1.** $`f_x`$ на оси $`x=0`$. При $`y\ne0`$ по определению

```math
f_x(0,y)=\lim_{t\to0}\frac{f(t,y)-f(0,y)}t=\lim_{t\to0}\frac{y\,(t^2-y^2)}{t^2+y^2}=-y,
```

а из $`f(t,0)=0`$ следует $`f_x(0,0)=0`$. Итак, $`f_x(0,y)=-y`$ при всех $`y`$.

**Шаг 2.** $`f_y`$ на оси $`y=0`$. При $`x\ne0`$

```math
f_y(x,0)=\lim_{t\to0}\frac{f(x,t)-f(x,0)}t=\lim_{t\to0}\frac{x\,(x^2-t^2)}{x^2+t^2}=x,
```

а из $`f(0,t)=0`$ следует $`f_y(0,0)=0`$. Итак, $`f_y(x,0)=x`$ при всех $`x`$.

**Шаг 3.** Смешанные производные в нуле:

```math
f_{xy}(0,0)=\lim_{s\to0}\frac{f_x(0,s)-f_x(0,0)}s=\lim_{s\to0}\frac{-s}s=-1,
\qquad
f_{yx}(0,0)=\lim_{s\to0}\frac{f_y(s,0)-f_y(0,0)}s=\lim_{s\to0}\frac ss=1.
```

Где нарушено условие: вне начала координат $`f`$ рациональна и

```math
f_{xy}=f_{yx}=\frac{(x^2-y^2)(x^4+10x^2y^2+y^4)}{(x^2+y^2)^3}.
```

На оси $`y=0`$ это $`1`$, на оси $`x=0`$ — $`-1`$, так что в нуле смешанные производные разрывны. При этом $`\lvert f_x\rvert\le2\lvert y\rvert`$ и $`\lvert f_y\rvert\le2\lvert x\rvert`$, то есть $`f\in C^1`$: непрерывности первых производных для перестановки мало.

### Приёмы

- **Теорема Эйлера об однородных функциях.** Если $`f(tx,ty)=t^kf(x,y)`$ при всех $`t>0`$ и $`f`$ дифференцируема, то $`x\,f_x+y\,f_y=k\,f`$. Доказательство: продифференцировать тождество по $`t`$ и положить $`t=1`$. Проверка на $`f=x^2y+y^3`$ ($`k=3`$): $`f_x=2xy`$, $`f_y=x^2+3y^2`$, и $`x\cdot2xy+y\,(x^2+3y^2)=3x^2y+3y^3=3f`$. Для $`\operatorname{arctg}\frac yx`$ из примера 3 ($`k=0`$): $`x\cdot\frac{-y}{x^2+y^2}+y\cdot\frac x{x^2+y^2}=0`$ — быстрая проверка ответа.
- **Частные производные есть, а дифференцируемости может не быть.** Пусть $`f=\frac{xy}{x^2+y^2}`$, $`f(0,0)=0`$. На осях $`f\equiv0`$, поэтому $`f_x(0,0)=f_y(0,0)=0`$. Но $`f(t,t)=\frac12`$ при $`t\ne0`$, так что $`f`$ не непрерывна в нуле и тем более не [дифференцируема](#sec-15-1) там. Равенство $`D_vf=\nabla f\cdot v`$ тоже ломается: $`\nabla f(0,0)=(0,0)`$, а для $`v=(1,1)`$ отношение $`\frac{f(t,t)-f(0,0)}t=\frac1{2t}`$ предела не имеет. Достаточное условие дифференцируемости — непрерывность частных производных ([§15.2](#sec-15-2)).
- **Проверка подстановкой.** Подставьте вместо другой переменной число и продифференцируйте функцию одной переменной. Для примера 1 при $`y=2`$: $`f(x,2)=2x^2+\sin2x`$, её производная $`4x+2\cos2x`$, и формула $`f_x=2xy+y\cos(xy)`$ при $`y=2`$ даёт то же. Так ловится потерянный множитель от внутренней функции.

**Частые ошибки.**

1. Забыть множитель от внутренней функции: $`\frac{\partial}{\partial x}\sin(xy)=y\cos(xy)`$, а не $`\cos(xy)`$.
2. Дифференцировать $`x^y`$ по $`y`$ как степень: $`(x^y)_y=x^y\ln x`$, а не $`y\,x^{y-1}`$.
3. В правиле цепочки потерять один из путей или взять не ту точку: $`z_x=F_u\,u_x+F_v\,v_x`$ — сумма по всем промежуточным переменным, а $`F_u`$, $`F_v`$ берутся в точке $`(u(x,y),v(x,y))`$.
4. Выводить из существования $`f_x`$ и $`f_y`$ непрерывность или дифференцируемость, а из существования $`f_{xy}`$ и $`f_{yx}`$ — их равенство (контрпримеры выше).
5. Потерять минус в $`y'=-F_x/F_y`$ или перепутать числитель со знаменателем.

### Самопроверка

1. Найдите $`f_x`$ и $`f_y`$ для $`f=y^x`$, $`y>0`$. Сравните с примером 2.
2. Пусть $`z=F(x^2-y^2,\,2xy)`$, $`F`$ дифференцируема. Выразите $`z_x`$ и $`z_y`$ через $`F_u`$ и $`F_v`$.
3. Оцените $`\sqrt{3{,}02^2+3{,}97^2}`$ с помощью дифференциала.
4. Следует ли из существования $`f_x(0,0)`$ и $`f_y(0,0)`$ непрерывность $`f`$ в нуле? Следует ли из существования $`f_{xy}(0,0)`$ и $`f_{yx}(0,0)`$ их равенство? Что требует теорема Шварца?

<summary>Ответы</summary>

1. По $`x`$ функция показательная, по $`y`$ — степенная: $`f_x=y^x\ln y`$, $`f_y=x\,y^{x-1}`$. По сравнению с примером 2 переменные поменялись ролями.
2. $`u_x=2x`$, $`u_y=-2y`$, $`v_x=2y`$, $`v_y=2x`$, поэтому $`z_x=2x\,F_u+2y\,F_v`$ и $`z_y=-2y\,F_u+2x\,F_v`$; $`F_u`$ и $`F_v`$ берутся в точке $`(x^2-y^2,\,2xy)`$.
3. $`f=\sqrt{x^2+y^2}`$, $`a=(3,4)`$, $`f(a)=5`$, $`\nabla f(a)=\bigl(\frac35,\frac45\bigr)`$, $`h=(0{,}02;\ -0{,}03)`$: $`f(a+h)\approx5+0{,}012-0{,}024=4{,}988`$; точное значение $`\approx4{,}98812`$.
4. Нет и нет. Функция $`\frac{xy}{x^2+y^2}`$ имеет в нуле обе частные производные, но разрывна там; для контрпримера $`xy\,\frac{x^2-y^2}{x^2+y^2}`$ имеем $`f_{xy}(0,0)=-1\ne1=f_{yx}(0,0)`$. Теорема Шварца требует, чтобы $`f_{xy}`$ и $`f_{yx}`$ существовали в окрестности точки и были непрерывны в ней (или чтобы $`f`$ была дважды дифференцируема в точке).
</details>

## Разобранный пример

Пусть $`f(x,y)=x^2e^y`$ и $`a=(1,0)`$. Тогда

```math
f(a)=1,\qquad \nabla f=(2xe^y,x^2e^y),\qquad \nabla f(a)=(2,1).
```

Линейное приближение: $`f(1+h,k)\approx1+2h+k`$. Для единичного направления $`v=(3/5,4/5)`$

```math
D_vf(a)=(2,1)\cdot(3/5,4/5)=2.
```

## Типичные ошибки

1. Частные производные сами по себе не доказывают полную дифференцируемость.
2. Матрица Якоби представляет линейное отображение, а не просто таблицу чисел.
3. Градиент нормален множеству уровня; для графика $`z=f(x,y)`$ касательная строится по линейному приближению.

## Упражнения

1. Найдите матрицу Якоби и [якобиан](17-multiple-integrals.md#sec-17-2) $`F(r,\theta)=(r\cos\theta,r\sin\theta)`$.
2. Найдите [касательную плоскость](#sec-15-3) к $`z=x^2+y^2`$ в $`(1,1,2)`$.
3. Найдите гессиан $`f(x,y)=x^2e^y`$ в $`(1,0)`$.

<details>
<summary>Краткие ответы</summary>

1. Строки матрицы: $`(\cos\theta,-r\sin\theta)`$ и $`(\sin\theta,r\cos\theta)`$; определитель равен $`r`$.
2. $`z-2=2(x-1)+2(y-1)`$.
3. Гессиан в $`(1,0)`$ равен $`\begin{pmatrix}2&2\\2&1\end{pmatrix}`$.
</details>

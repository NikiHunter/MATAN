# 15. Дифференцирование отображений нескольких переменных

[← 14. Функции нескольких переменных](14-several-variables.md) · [Оглавление](index.md) · [Термины и теоремы](term-index.md) · [16. Обратные и неявные функции; экстремумы →](16-implicit-functions-extrema.md)

> **Цель.** Использовать [полную производную](#sec-15-1) как линейное отображение и связывать её с [частными производными](#sec-15-2), градиентом и приближениями высших порядков.

<a id="sec-15-1"></a>
## 15.1 Полная производная

Для $`F:D\subseteq\mathbb R^n\to\mathbb R^m`$ и [внутренней точки](13-metric-spaces.md#sec-13-2) $`a`$ производная — линейное отображение $`DF(a):\mathbb R^n\to\mathbb R^m`$ такое, что

```math
F(a+h)=F(a)+DF(a)h+o(\|h\|)\qquad(h\to0).
```

Равносильно, $`\|F(a+h)-F(a)-DF(a)h\|/\|h\|\to0`$. Дифференцируемость влечёт непрерывность. Матрица $`DF(a)`$ в стандартных координатах называется **матрицей Якоби**.

Для скалярной $`f`$ производная представляется градиентом $`\nabla f(a)`$:

```math
f(a+h)=f(a)+\nabla f(a)\cdot h+o(\|h\|).
```

Градиент указывает направление наискорейшего возрастания среди единичных направлений; максимум производной по направлению равен $`\|\nabla f(a)\|`$.

<a id="sec-15-2"></a>
## 15.2 Частные производные и производные по направлению

Частные производные:

```math
\frac{\partial f}{\partial x_i}(a)
=\lim_{t\to0}\frac{f(a+te_i)-f(a)}t.
```

Если $`F`$ дифференцируема, все частные производные существуют и

```math
DF(a)=\left(\frac{\partial F_i}{\partial x_j}(a)\right)_{i,j}.
```

Обратное требует осторожности: существование частных производных, даже около $`a`$, не гарантирует дифференцируемость. Достаточное условие: все частные производные существуют около $`a`$ и непрерывны в $`a`$; тогда $`F`$ дифференцируема в $`a`$.

Производная по вектору $`v`$:

```math
D_vf(a)=\left.\frac{d}{dt}f(a+tv)\right|_{t=0}.
```

Если $`f`$ дифференцируема, то $`D_vf(a)=\nabla f(a)\cdot v`$. Одного существования всех производных по направлениям недостаточно.

<a id="sec-15-3"></a>
## 15.3 Правило цепочки и касательные плоскости

Если $`F`$ дифференцируема в $`a`$, а $`G`$ — в $`F(a)`$, то

```math
D(G\circ F)(a)=DG(F(a))\,DF(a),
```

где произведение матричное. Эта формула содержит все многомерные правила цепочки.

Для дифференцируемой $`f(x,y)`$ касательная плоскость к графику в $`(a,b)`$:

```math
z=f(a,b)+f_x(a,b)(x-a)+f_y(a,b)(y-b).
```

Для поверхности уровня $`F(x,y,z)=c`$ с $`\nabla F(a)\ne0`$ касательная плоскость имеет вид $`\nabla F(a)\cdot(x-a)=0`$. Градиент нормален множеству уровня.

<a id="sec-15-4"></a>
## 15.4 Высшие производные и формула Тейлора

Функция принадлежит $`C^k`$, если все частные производные до порядка $`k`$ существуют и непрерывны.

> <a id="clairaut-schwarz-theorem"></a>**Теорема Клеро–Шварца.** Если смешанные вторые частные производные непрерывны около точки, порядок дифференцирования можно менять: $`f_{xy}=f_{yx}`$.

Для $`f\in C^2`$ гессиан $`Hf(a)`$ — симметричная матрица вторых частных производных. Разложение Тейлора второго порядка:

```math
f(a+h)=f(a)+\nabla f(a)\cdot h
+\frac12h^{T}Hf(a)h+o(\|h\|^2).
```

Квадратичная форма $`h^THh`$ описывает локальную кривизну и используется в исследовании экстремумов.

## Разобранный пример

Пусть $`f(x,y)=x^2e^y`$ и $`a=(1,0)`$. Тогда

```math
f(a)=1,\qquad \nabla f=(2xe^y,x^2e^y),\qquad \nabla f(a)=(2,1).
```

Линейное приближение: $`f(1+h,k)\approx1+2h+k`$. Для единичного направления $`v=(3/5,4/5)`$

```math
D_vf(a)=(2,1)\cdot(3/5,4/5)=2.
```

## Типичные ошибки

1. Частные производные сами по себе не доказывают полную дифференцируемость.
2. Матрица Якоби представляет линейное отображение, а не просто таблицу чисел.
3. Градиент нормален множеству уровня; для графика $`z=f(x,y)`$ касательная строится по линейному приближению.

## Упражнения

1. Найдите матрицу Якоби и [якобиан](17-multiple-integrals.md#sec-17-2) $`F(r,\theta)=(r\cos\theta,r\sin\theta)`$.
2. Найдите [касательную плоскость](#sec-15-3) к $`z=x^2+y^2`$ в $`(1,1,2)`$.
3. Найдите гессиан $`f(x,y)=x^2e^y`$ в $`(1,0)`$.

<details>
<summary>Краткие ответы</summary>

1. Строки матрицы: $`(\cos\theta,-r\sin\theta)`$ и $`(\sin\theta,r\cos\theta)`$; определитель равен $`r`$.
2. $`z-2=2(x-1)+2(y-1)`$.
3. Гессиан в $`(1,0)`$ равен $`\begin{pmatrix}2&2\\2&1\end{pmatrix}`$.
</details>

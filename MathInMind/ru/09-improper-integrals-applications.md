# 9. Несобственные интегралы и приложения

[← 8. Интеграл Римана](08-riemann-integration.md) · [Оглавление](index.md) · [Термины и теоремы](term-index.md) · [10. Последовательности и ряды функций →](10-function-sequences-series.md)

> **Цель.** Работать с неограниченными промежутками и подынтегральными функциями через пределы, применять интеграл в геометрии и физике.

<a id="sec-9-1"></a>
## 9.1 Определения

На бесконечном промежутке полагают

```math
\int_a^\infty f(x)\,dx
=\lim_{R\to\infty}\int_a^R f(x)\,dx,
```

если предел существует и конечен. Если функция неограниченна около $`b`$, то

```math
\int_a^b f(x)\,dx
=\lim_{t\to b^-}\int_a^t f(x)\,dx.
```

Если особенности на обоих концах, промежуток делят [внутренней точкой](13-metric-spaces.md#sec-13-2) и требуют независимой сходимости обеих частей. На $`(-\infty,\infty)`$ оба хвоста должны сходиться по отдельности. Симметричный предел, называемый **главным значением**, может существовать и при расходящемся несобственном интеграле.

Например,

```math
\int_1^\infty\frac{dx}{x^p}<\infty\iff p>1,
\qquad
\int_0^1\frac{dx}{x^p}<\infty\iff p<1.
```

<a id="sec-9-2"></a>
## 9.2 Признаки сходимости

Для неотрицательной функции сходимость равносильна ограниченности интегралов по конечным частям. Признаки сравнения аналогичны рядам: на бесконечном промежутке $`f\sim C/x^p`$ даёт сходимость при $`p>1`$.

[Абсолютная сходимость](04-numeric-series.md#sec-4-3) означает сходимость $`\int|f|`$ и при обычной локальной интегрируемости влечёт обычную. Для осциллирующих функций возможна условная сходимость.

> <a id="dirichlet-test-for-integrals"></a>**Признак Дирихле.** Если $`F(T)=\int_a^T f`$ ограничена, а $`g`$ монотонно убывает к нулю с подходящей регулярностью, то $`\int_a^\infty f(x)g(x)\,dx`$ сходится.

Поэтому $`\int_1^\infty\sin x/x\,dx`$ сходится условно: сходимость следует из [интегрирования по частям](08-riemann-integration.md#sec-8-4) или [признака Дирихле](#dirichlet-test-for-integrals), а расходимость $`\int|\sin x|/x`$ — из оценок на интервалах около кратных $`\pi`$.

[Критерий Коши](03-sequences.md#sec-3-4) для $`\int_a^\infty f`$: величина $`\int_S^T f`$ должна становиться сколь угодно малой для всех достаточно больших $`S<T`$.

<a id="sec-9-3"></a>
## 9.3 Площадь, длина и объём

Если $`f\ge g`$ на $`[a,b]`$, площадь между графиками равна

```math
A=\int_a^b(f(x)-g(x))\,dx.
```

В [полярных координатах](17-multiple-integrals.md#sec-17-3) площадь, заметаемая радиусом $`r=r(\theta)`$:

```math
A=\frac12\int_\alpha^\beta r(\theta)^2\,d\theta.
```

Длина [непрерывно дифференцируемой](15-multivariable-differentiation.md#sec-15-1) кривой $`\gamma(t)=(x(t),y(t))`$:

```math
L=\int_a^b\sqrt{x'(t)^2+y'(t)^2}\,dt.
```

Для графика $`L=\int_a^b\sqrt{1+f'(x)^2}\,dx`$. В полярной форме

```math
L=\int_\alpha^\beta\sqrt{r^2+(dr/d\theta)^2}\,d\theta.
```

Если площадь сечения тела равна $`A(x)`$, то $`V=\int_a^b A(x)\,dx`$. Вращение $`0\le y=f(x)`$ вокруг оси $`x`$ даёт

```math
V=\pi\int_a^b f(x)^2\,dx,
```

а метод цилиндрических слоёв вокруг оси $`y`$ при $`x\ge0`$ даёт $`V=2\pi\int_a^b x f(x)\,dx`$.

<a id="sec-9-4"></a>
## 9.4 Работа и среднее значение

Работа переменной силы $`F(x)`$ вдоль прямолинейного пути:

```math
W=\int_a^b F(x)\,dx.
```

В общем случае работа вдоль кривой — [криволинейный интеграл](18-vector-calculus.md#sec-18-1) из главы 18. Среднее значение интегрируемой функции:

```math
f_{\mathrm{avg}}=\frac1{b-a}\int_a^b f(x)\,dx.
```

Все эти формулы получаются [разбиением](08-riemann-integration.md#sec-8-1), приближением малых вкладов и предельным переходом.

## Разобранный пример

Для длины $`y=\frac23x^{3/2}`$ от $`0`$ до $`3`$ имеем $`y'=\sqrt x`$, поэтому

```math
L=\int_0^3\sqrt{1+x}\,dx
=\left.\frac23(1+x)^{3/2}\right|_0^3
=\frac{14}{3}.
```

## Типичные ошибки

1. Бесконечность нельзя просто подставлять в [первообразную](08-riemann-integration.md#sec-8-3): нужен предел.
2. Симметричный предел не заменяет независимую сходимость двух хвостов.
3. Длина использует $`\sqrt{1+(y')^2}`$, а не $`1+y'`$.

## Упражнения

1. Сходится ли $`\int_0^\infty dx/(1+x^2)`$? Вычислите его.
2. Найдите площадь одного лепестка $`r=\cos(2\theta)`$.
3. Найдите объём тела, полученного вращением $`y=\sqrt x`$, $`0\le x\le1`$, вокруг оси $`x`$.

<details>
<summary>Краткие ответы</summary>

1. Сходится и равен $`\pi/2`$.
2. Один лепесток соответствует $`-\pi/4\le\theta\le\pi/4`$; площадь $`\pi/8`$.
3. $`V=\pi\int_0^1x\,dx=\pi/2`$.
</details>

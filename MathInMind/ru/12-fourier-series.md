# 12. Ряды Фурье

[← 11. Степенные ряды и аналитические функции](11-power-series.md) · [Оглавление](index.md) · [Термины и теоремы](term-index.md) · [13. Метрические пространства, компактность и полнота →](13-metric-spaces.md)

> **Цель.** Представлять периодические функции ортогональными тригонометрическими модами и различать поточечную и среднеквадратичную сходимость.

<a id="sec-12-1"></a>
## 12.1 Тригонометрическая система и коэффициенты

Для $`2\pi`$-периодической интегрируемой функции $`f`$ положим

```math
a_0=\frac1\pi\int_{-\pi}^{\pi}f(x)\,dx,
```
```math
a_n=\frac1\pi\int_{-\pi}^{\pi}f(x)\cos(nx)\,dx,
\qquad
b_n=\frac1\pi\int_{-\pi}^{\pi}f(x)\sin(nx)\,dx.
```

Её ряд Фурье:

```math
f(x)\sim \frac{a_0}{2}
+\sum_{n=1}^{\infty}\bigl(a_n\cos(nx)+b_n\sin(nx)\bigr).
```

Символ $`\sim`$ сначала означает лишь сопоставление коэффициентов; равенство требует теоремы о сходимости.

Система $`\{1,\cos nx,\sin nx\}`$ ортогональна относительно [скалярного произведения](21-lp-spaces.md#sec-21-4)

```math
\langle f,g\rangle=\int_{-\pi}^{\pi}f(x)g(x)\,dx.
```

Например, $`\int_{-\pi}^{\pi}\cos(nx)\sin(mx)\,dx=0`$, а $`\int_{-\pi}^{\pi}\cos^2(nx)\,dx=\pi`$ при $`n\ge1`$.

Для периода $`2L`$ выражение $`nx`$ заменяют на $`n\pi x/L`$ и интегрируют по промежутку длины $`2L`$ с соответствующей нормировкой.

<a id="sec-12-2"></a>
## 12.2 Симметрия

Если $`f`$ чётна, все $`b_n=0`$ и

```math
a_n=\frac2\pi\int_0^\pi f(x)\cos(nx)\,dx.
```

Если $`f`$ нечётна, все $`a_n=0`$ и

```math
b_n=\frac2\pi\int_0^\pi f(x)\sin(nx)\,dx.
```

Разложения по синусам и косинусам на полупериоде представляют соответственно нечётное и чётное периодические продолжения функции с $`(0,L)`$. Поведение на границе определяется продолжением.

<a id="sec-12-3"></a>
## 12.3 Сходимость

> <a id="dirichlet-pointwise-theorem"></a>**Теорема Дирихле.** Если периодическая $`f`$ кусочно непрерывна и кусочно [непрерывно дифференцируема](15-multivariable-differentiation.md#sec-15-1), её [ряд Фурье](#sec-12-1) сходится в каждой точке к
> ```math
> \frac{f(x^-)+f(x^+)}2.
> ```
> В точках непрерывности это просто $`f(x)`$.

В скачке ряд выбирает середину независимо от заданного значения $`f(x)`$.

Для квадратично интегрируемых функций [частичные суммы](04-numeric-series.md#sec-4-1) Фурье дают наилучшее среднеквадратичное приближение тригонометрическими многочленами той же степени, и

```math
\int_{-\pi}^{\pi}|f(x)-s_N(x)|^2\,dx\to0.
```

Это само по себе не влечёт [поточечную сходимость](10-function-sequences-series.md#sec-10-1). Для равномерной сходимости нужны более сильные условия; около скачков возникает явление Гиббса.

<a id="sec-12-4"></a>
## 12.4 Равенство Парсеваля

Для $`f\in L^2([-\pi,\pi])`$

```math
\frac1\pi\int_{-\pi}^{\pi}|f(x)|^2\,dx
=\frac{a_0^2}{2}+\sum_{n=1}^{\infty}(a_n^2+b_n^2).
```

Это бесконечномерная теорема Пифагора. Она также превращает коэффициенты Фурье в инструмент суммирования числовых рядов.

Формальное дифференцирование требует осторожности. Если $`f`$ непрерывна, периодична и кусочно гладка, а [производная](06-derivatives.md#sec-6-1) достаточно интегрируема, ряд $`f'`$ получается почленным дифференцированием. Интегрирование обычно менее требовательно, но для периодичности нужно условие нулевого среднего.

## Разобранный пример

Для $`f(x)=x`$ на $`(-\pi,\pi)`$ с периодическим продолжением нечётность даёт $`a_n=0`$. [Интегрирование по частям](08-riemann-integration.md#sec-8-4):

```math
b_n=\frac2\pi\int_0^\pi x\sin(nx)\,dx
=\frac{2(-1)^{n+1}}n.
```

Следовательно,

```math
x=2\sum_{n=1}^{\infty}\frac{(-1)^{n+1}}n\sin(nx),
\qquad -\pi<x<\pi.
```

При $`x=\pi`$ ряд равен нулю — середине скачка между $`\pi`$ и $`-\pi`$. Подстановка $`x=\pi/2`$ даёт $`\sum_{k=0}^{\infty}(-1)^k/(2k+1)=\pi/4`$. Равенство Парсеваля даёт $`\sum_{n=1}^{\infty}1/n^2=\pi^2/6`$.

## Типичные ошибки

1. Знак равенства до доказательства сходимости не обоснован.
2. В скачке предел равен среднему односторонних значений.
3. Среднеквадратичная сходимость не влечёт автоматически поточечную сходимость всюду.

## Упражнения

1. Найдите ряд Фурье $`f(x)=x^2`$ на $`(-\pi,\pi)`$.
2. Объясните, почему ряд чётной функции содержит только косинусы.
3. Через равенство Парсеваля для $`f(x)=x`$ проверьте $`\sum1/n^2=\pi^2/6`$.

<details>
<summary>Краткие ответы</summary>

1. $`x^2=\pi^2/3+4\sum_{n=1}^{\infty}(-1)^n\cos(nx)/n^2`$ на $`[-\pi,\pi]`$ с учётом периодического продолжения.
2. Произведения $`f(x)\sin(nx)`$ нечётны, поэтому их симметричные интегралы равны нулю.
3. Используйте $`b_n=2(-1)^{n+1}/n`$ и $`(1/\pi)\int_{-\pi}^{\pi}x^2\,dx=2\pi^2/3`$.
</details>

## Вопрос

[Дивергенция](../../18-vector-calculus.md#sec-18-3). Теорема Остроградского в векторной форме.

## Эталонный ответ

**Определение 13.2.1 (2024/25).** Дивергенцией векторного поля $`\vec F=(F_1,F_2,F_3)`$ называется
```math
\operatorname{div}\vec F=\frac{\partial F_1}{\partial x}+\frac{\partial F_2}{\partial y}+\frac{\partial F_3}{\partial z}\;\bigl(=\nabla\cdot\vec F\bigr).
```

**Теорема 13.2.1 (Остроградского).** [Поток](../../18-vector-calculus.md#sec-18-2) векторного поля $`\vec F`$ через замкнутую поверхность $`S`$ наружу равен [тройному интегралу](../../17-multiple-integrals.md#sec-17-1) от дивергенции по телу $`T`$, ограниченному поверхностью $`S`$:
```math
\iint_SF_n\,dS=\iiint_T\operatorname{div}\vec F\,dx\,dy\,dz ,
```
где $`F_n=\vec F\cdot\vec n`$, $`\vec n`$ — внешняя нормаль (поле [непрерывно дифференцируемо](../../15-multivariable-differentiation.md#sec-15-1) в замкнутом теле $`T`$).

**Инвариантное определение и физический смысл.** Для непрерывной $`\operatorname{div}\vec F`$
```math
\operatorname{div}\vec F(M)=\lim_{T\to M}\frac{1}{V(T)}\iint_{\partial T}F_n\,dS
```
(тело $`T`$ стягивается к точке $`M`$). Дивергенция — объёмная плотность потока, т. е. мощность источников: $`\operatorname{div}\vec F(M)>0`$ — в точке $`M`$ источник, $`<0`$ — сток. В частности, дивергенция не зависит от выбора системы координат.

**Свойства.** $`\operatorname{div}(\alpha\vec F+\beta\vec G)=\alpha\operatorname{div}\vec F+\beta\operatorname{div}\vec G`$; $`\operatorname{div}(U\vec F)=U\operatorname{div}\vec F+\vec F\cdot\nabla U`$; $`\operatorname{div}\vec r=3`$; дивергенция постоянного поля равна нулю.

## Доказательство

*Теорема.* Это координатная [формула Гаусса–Остроградского](../../18-vector-calculus.md#divergence-theorem) ([билет 80](80.md)) с $`P=F_1`$, $`Q=F_2`$, $`R=F_3`$:
```math
\iint_SF_1\,dy\,dz+F_2\,dz\,dx+F_3\,dx\,dy=\iiint_T\Bigl(\frac{\partial F_1}{\partial x}+\frac{\partial F_2}{\partial y}+\frac{\partial F_3}{\partial z}\Bigr)dx\,dy\,dz .
```
Слева — интеграл II рода по внешней стороне; переходя к интегралу I рода ([билет 79](79.md)), получаем $`\iint_S(F_1\cos\lambda+F_2\cos\mu+F_3\cos\nu)\,dS=\iint_SF_n\,dS`$.

*Инвариантное определение.* По теореме о среднем для тройного интеграла (функция $`\operatorname{div}\vec F`$ непрерывна, $`T`$ [связно](../../13-metric-spaces.md#sec-13-5)) найдётся точка $`M_1\in T`$ с $`\iiint_T\operatorname{div}\vec F\,dV=\operatorname{div}\vec F(M_1)\,V(T)`$. По теореме
```math
\frac{1}{V(T)}\iint_{\partial T}F_n\,dS=\operatorname{div}\vec F(M_1)\xrightarrow[T\to M]{}\operatorname{div}\vec F(M),
```
так как $`M_1\to M`$ и дивергенция непрерывна. Левая часть определена без координат (поток и объём), значит, и $`\operatorname{div}\vec F`$ от координат не зависит.

*Формула для $`U\vec F`$.* Покоординатно: $`\frac{\partial(UF_1)}{\partial x}=U\frac{\partial F_1}{\partial x}+F_1\frac{\partial U}{\partial x}`$; сумма трёх таких равенств даёт $`U\operatorname{div}\vec F+\vec F\cdot\nabla U`$. $`\square`$

## Разобранный пример

1) $`\vec r=(x,y,z)`$: $`\operatorname{div}\vec r=3`$, и поток через внешнюю сторону сферы радиуса $`R`$ равен $`3\cdot\frac43\pi R^3=4\pi R^3`$ — совпадает с прямым вычислением ($`r_n=R`$, площадь $`4\pi R^2`$, [билет 90](90.md)).

2) Поток поля $`\vec F=(x^3,y^3,z^3)`$ через внешнюю сторону сферы $`x^2+y^2+z^2=R^2`$: $`\operatorname{div}\vec F=3(x^2+y^2+z^2)=3\rho^2`$, в [сферических координатах](../../17-multiple-integrals.md#sec-17-3)
```math
\iint_SF_n\,dS=\iiint_{\rho\le R}3\rho^2\,dV=3\int_0^R\rho^2\cdot4\pi\rho^2\,d\rho=\frac{12\pi R^5}{5}.
```

3) Поле точечного заряда $`\vec E=\frac{\vec r}{r^3}`$: при $`r\ne0`$
```math
\operatorname{div}\vec E=\sum_{x,y,z}\Bigl(\frac1{r^3}-\frac{3x^2}{r^5}\Bigr)=\frac3{r^3}-\frac{3r^2}{r^5}=0 .
```

## Если снять условие

- **Поле должно быть гладким во всём теле $`T`$.** Для $`\vec E=\frac{\vec r}{r^3}`$ (пример 3) $`\operatorname{div}\vec E=0`$ вне начала координат, но поток через сферу радиуса $`R`$ равен $`\frac1{R^2}\cdot4\pi R^2=4\pi\ne0`$: шар содержит особую точку. Для тела, не содержащего начала координат, поток равен нулю (закон Гаусса).
- **Поверхность должна быть замкнутой, нормаль — внешней:** при внутренней нормали меняется знак, а для незамкнутой поверхности (полусферы) формула не имеет смысла — нужно достраивать поверхность до замкнутой.
- **Инвариантное определение требует непрерывности $`\operatorname{div}\vec F`$** (для теоремы о среднем и предельного перехода).

## Проверка готовности

1. Дайте определение дивергенции. Чему равна $`\operatorname{div}\vec r`$?
2. Сформулируйте теорему Остроградского в векторной форме. Как она получается из координатной?
3. Выведите инвариантное определение дивергенции. Каков её физический смысл?
4. Докажите формулу $`\operatorname{div}(U\vec F)=U\operatorname{div}\vec F+\vec F\cdot\nabla U`$.
5. Найдите поток поля $`(x^3,y^3,z^3)`$ через внешнюю сторону сферы радиуса $`R`$.

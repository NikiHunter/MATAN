# Билет 5. Многомерная теорема Лагранжа о среднем. Формула Тейлора–Лагранжа для отображений. Оценка остатка

[← Билет 4](04.md) · [Все билеты](../EXAM_SEM3.md) · [Лекции 65–66](../../lectures-2025-26/lecture-65-66.md) · [Билет 6 →](06.md)

> **Лекционная опора:** [теорема 6.5.3](../../lectures-2025-26/lecture-65-66.md#thm-6-5-3), [теорема 6.5.4](../../lectures-2025-26/lecture-65-66.md#thm-6-5-4), [теорема 6.5.5](../../lectures-2025-26/lecture-65-66.md#thm-6-5-5), [теорема 6.5.2](../../lectures-2025-26/lecture-65-66.md#thm-6-5-2) (лекции 65–66). При расхождении формулировок приоритет у лекции.

## Вопрос

Многомерная [теорема Лагранжа](../../lectures-2025-26/lecture-24-25-26.md#thm-3-4-3) о среднем. [Формула Тейлора–Лагранжа](../../lectures-2025-26/lecture-65-66.md#thm-6-5-4) для отображений. Оценка остатка.

## Эталонный ответ

Всюду $`E`$ открыто в $`\mathbb R^n`$, $`a,x\in E`$, $`a\ne x`$, $`\Delta_{a,x}=\{a+t(x-a):\ t\in[0,1]\}\subset E`$, $`\hat\Delta_{a,x}`$ — отрезок без концов.

**Теорема 6.5.3 (о среднем).** Если функция $`f:E\to\mathbb R`$ [дифференцируема](../../lectures-2025-26/lecture-22-23.md#def-3-2-1) на $`E`$, то существует $`c\in\hat\Delta_{a,b}`$, для которой $`f(b)-f(a)=d_cf(b-a)`$ (для точек $`a\ne b`$ с $`\Delta_{a,b}\subset E`$). Это случай $`s=0`$ [теоремы 6.5.2](../../lectures-2025-26/lecture-65-66.md#thm-6-5-2).

**Замечание.** Для отображений $`f:E\to\mathbb R^m`$, $`m\ge2`$, [теоремы 6.5.2](../../lectures-2025-26/lecture-65-66.md#thm-6-5-2) и [6.5.3](../../lectures-2025-26/lecture-65-66.md#thm-6-5-3) неверны (пример ниже). Верна оценка по [норме](../../14-several-variables.md#sec-14-1).

**Теорема 6.5.4 (формула Тейлора–Лагранжа для отображений).** Пусть $`s\in\mathbb Z_+`$, отображение $`f:E\to\mathbb R^m`$ дифференцируемо $`s+1`$ раз на $`E`$. Тогда
```math
\left\|f(x)-\sum_{k=0}^{s}\frac{d_a^kf(x-a)}{k!}\right\|\le\frac1{(s+1)!}\sup_{c\in\hat\Delta_{a,x}}\bigl\|d_c^{s+1}f(x-a)\bigr\|.\qquad(6.5.2)
```

**Теорема 6.5.5 (оценка остатка).** Пусть $`s\in\mathbb Z_+`$, $`f\in C^{s+1}(E,\mathbb R^m)`$, $`M_{s+1}`$ — множество мультииндексов порядка $`s+1`$, и
```math
M=\max_{\alpha\in M_{s+1}}\ \sup_{c\in\hat\Delta_{a,x}}\left\|\frac{\partial^\alpha f}{\partial x^\alpha}(c)\right\|.
```
Тогда $`M<+\infty`$ и
```math
\|R_{a,s}f(x)\|\le\frac{M}{(s+1)!}\bigl(\sqrt n\,\|x-a\|\bigr)^{s+1}.
```

## Доказательство

**Теорема 6.5.3.** Положим $`F(t)=f(a+t(b-a))`$. По теореме о дифференцировании композиции $`F`$ дифференцируема на $`[0,1]`$ и $`F'(t)=d_{a+t(b-a)}f(b-a)`$. По теореме Лагранжа для функции одной переменной найдётся $`\theta\in(0,1)`$ с $`F(1)-F(0)=F'(\theta)`$, т. е. $`f(b)-f(a)=d_cf(b-a)`$ при $`c=a+\theta(b-a)\in\hat\Delta_{a,b}`$. $`\square`$

**Теорема 6.5.4.** Обозначим $`v=f(x)-\sum_{k=0}^{s}\frac{d_a^kf(x-a)}{k!}`$. Если $`v=0`$, доказывать нечего. Иначе положим $`e=\frac{v}{\|v\|}`$ и $`g(y)=\langle f(y),e\rangle`$, $`y\in E`$. Функция $`g`$ — линейная комбинация координатных функций $`f`$, поэтому дифференцируема $`s+1`$ раз на $`E`$ и $`d_y^kg(h)=\langle d_y^kf(h),e\rangle`$ при $`k\le s+1`$. По [теореме 6.5.2](../../lectures-2025-26/lecture-65-66.md#thm-6-5-2) для $`g`$ найдётся $`c\in\hat\Delta_{a,x}`$ (зависящая от $`e`$), для которой
```math
\|v\|=\langle v,e\rangle=g(x)-\sum_{k=0}^{s}\frac{d_a^kg(x-a)}{k!}=\frac{d_c^{s+1}g(x-a)}{(s+1)!}=\frac{\langle d_c^{s+1}f(x-a),e\rangle}{(s+1)!}\le\frac{\|d_c^{s+1}f(x-a)\|}{(s+1)!}
```
([неравенство Коши–Буняковского](../../lectures/05-taylor-wallis-inequalities-4-4.md#thm-4-4-6), $`\|e\|=1`$). Заменяя правую часть [супремумом](../../lectures-2025-26/lecture-11-12.md#def-2-3-1) по $`c\in\hat\Delta_{a,x}`$, получаем (6.5.2). $`\square`$

**Теорема 6.5.5.** Каждая [производная](../../lectures-2025-26/lecture-22-23.md#def-3-1-1) $`\frac{\partial^\alpha f}{\partial x^\alpha}`$, $`|\alpha|=s+1`$, непрерывна на $`E`$, а значит ограничена на отрезке $`\Delta_{a,x}\subset E`$ (непрерывная функция на [компакте](../../lectures/11-topology-rn-5-3.md#def-5-3-7)); мультииндексов порядка $`s+1`$ конечное число, поэтому $`M<+\infty`$. Пусть $`c\in\hat\Delta_{a,x}`$, $`h=x-a`$. По [теореме 6.4.2](../../lectures/17-higher-derivatives-6-4.md#thm-6-4-2)
```math
d_c^{s+1}f(h)=\sum_{i_1,\ldots,i_{s+1}=1}^{n}\frac{\partial^{s+1}f}{\partial x_{i_1}\cdots\partial x_{i_{s+1}}}(c)\,h_{i_1}\cdots h_{i_{s+1}}.
```
Для $`f\in C^{s+1}`$ порядок дифференцирования не важен, и каждая из этих производных равна $`\frac{\partial^\alpha f}{\partial x^\alpha}(c)`$ при подходящем $`\alpha\in M_{s+1}`$, так что её норма не больше $`M`$. Отсюда и из неравенства $`|h_1|+\ldots+|h_n|\le\sqrt n\,\|h\|`$ (Коши–Буняковский)
```math
\|d_c^{s+1}f(h)\|\le M\sum_{i_1,\ldots,i_{s+1}}|h_{i_1}|\cdots|h_{i_{s+1}}|=M\bigl(|h_1|+\ldots+|h_n|\bigr)^{s+1}\le M\bigl(\sqrt n\,\|h\|\bigr)^{s+1}.
```
Отображение класса $`C^{s+1}`$ дифференцируемо $`s+1`$ раз на $`E`$, поэтому применима [теорема 6.5.4](../../lectures-2025-26/lecture-65-66.md#thm-6-5-4), и из (6.5.2) следует требуемая оценка для $`R_{a,s}f(x)=f(x)-\sum_{k\le s}\frac{d_a^kf(x-a)}{k!}`$. $`\square`$

## Разобранный пример

**Равенство для отображений неверно.** Пусть $`f(t)=(\cos t,\sin t)`$, $`t\in\mathbb R`$; $`f'(t)=(-\sin t,\cos t)`$, $`\|f'(t)\|=1`$. При $`a=0`$, $`b=2\pi`$ имеем $`f(b)-f(a)=(0,0)`$, но $`\|d_cf(b-a)\|=2\pi\ne0`$ при любом $`c`$: равенство [теоремы 6.5.3](../../lectures-2025-26/lecture-65-66.md#thm-6-5-3) не выполняется. Оценка (6.5.2) при $`s=0`$ верна: $`0\le2\pi`$. При $`b=\frac\pi2`$ она даёт $`\|f(b)-f(a)\|=\sqrt2\le\frac\pi2`$, и равенства снова нет, так как $`\sqrt2\ne\frac\pi2`$.

**Оценка остатка.** Для $`f(x,y)=(e^x\cos y,\ e^x\sin y)`$, $`a=(0,0)`$, $`s=1`$ имеем $`T_{0,1}f(h)=(1+h_1,h_2)`$. Все вторые [частные производные](../../lectures/14-differentiability-6-1.md#def-6-1-5) ($`f_{xx}=f`$, $`f_{xy}=f_{yx}=(-e^x\sin y,\ e^x\cos y)`$, $`f_{yy}=-f`$) имеют норму $`e^x`$. На отрезке $`\Delta_{0,h}`$ при $`\|h\|\le1`$ первая координата точки не превосходит $`1`$, поэтому $`M\le e`$ и по [теореме 6.5.5](../../lectures-2025-26/lecture-65-66.md#thm-6-5-5) ($`n=2`$)
```math
\|R_{0,1}f(h)\|\le\frac{e}{2!}\bigl(\sqrt2\,\|h\|\bigr)^2=e\,\|h\|^2\qquad(\|h\|\le1).
```
Проверка при $`h=(0,t)`$: $`R=(\cos t-1,\ \sin t-t)`$, $`\|R\|\approx\frac{t^2}{2}\le e\,t^2`$.

## Если снять условие

- **Векторнозначность.** Для $`m\ge2`$ равенство $`f(b)-f(a)=d_cf(b-a)`$ может не выполняться ни при каком $`c`$ (окружность выше); сохраняется только неравенство по норме.
- **Гладкость класса $`C^{s+1}`$ (ограниченность производных на отрезке).** Для $`f(t)=t^2\sin\frac1{t^2}`$, $`f(0)=0`$, функция дифференцируема на $`\mathbb R`$, но $`f'(t)=2t\sin\frac1{t^2}-\frac2t\cos\frac1{t^2}`$ неограничена на $`(0,1)`$; поэтому в (6.5.2) при $`s=0`$ правая часть равна $`+\infty`$: неравенство верно, но ничего не даёт. В [теореме 6.5.5](../../lectures-2025-26/lecture-65-66.md#thm-6-5-5) вывод $`M<+\infty`$ без $`C^{s+1}`$ теряется.
- **Включение $`\Delta_{a,x}\subset E`$:** для $`E=\mathbb R\setminus\{0\}`$, $`f=\operatorname{sgn}x`$, $`a=-1`$, $`b=1`$ [теорема 6.5.3](../../lectures-2025-26/lecture-65-66.md#thm-6-5-3) неверна ($`f'\equiv0`$, но $`f(1)-f(-1)=2`$), так как отрезок не лежит в $`E`$.

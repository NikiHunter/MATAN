# Билет 81. Формула Стокса

[← Билет 80](80.md) · [Все билеты](../EXAM_SEM3.md) · [Тема в курсе: гл. 18](../../18-vector-calculus.md) · [Билет 82 →](82.md)

> **Прогноз.** Билет по гл. 11–13; лекций 2025/26 ещё нет, нумерация по слайдам 2024/25 (стр. 116: «§4. Формула Стокса», малые формулы (11.4.1)–(11.4.3), правило ориентации контура, полная формула). После лекций формулировки и номера нужно сверить.

## Вопрос

[Формула Стокса](../../18-vector-calculus.md#stokes-theorem).

## Эталонный ответ

**Условия (2024/25).** $`S`$ — двусторонняя гладкая поверхность, ограниченная контуром $`L`$; $`S`$ проектируется на каждую координатную плоскость в область, ограниченную замкнутым самонепересекающимся контуром. Функции $`P,Q,R`$ непрерывны на $`S`$ вместе с нужными [частными производными](../../15-multivariable-differentiation.md#sec-15-2).

**Ориентация.** Интеграл по $`S`$ берётся по выбранной стороне, а контур $`L`$ обходится так, чтобы наблюдатель, у которого нормаль выбранной стороны направлена от ног к голове, оставлял поверхность слева.

**Малые формулы Стокса:**
```math
\iint_S\frac{\partial P}{\partial z}dz\,dx-\frac{\partial P}{\partial y}dx\,dy=\oint_LP\,dx ,\qquad(11.4.1)
```
и аналогично (11.4.2) для $`Q`$ ($`\iint_SQ'_xdx\,dy-Q'_zdy\,dz=\oint_LQ\,dy`$), (11.4.3) для $`R`$ ($`\iint_SR'_ydy\,dz-R'_xdz\,dx=\oint_LR\,dz`$).

**Формула Стокса** — их сумма:
```math
\iint_S\Bigl(\frac{\partial Q}{\partial x}-\frac{\partial P}{\partial y}\Bigr)dx\,dy+\Bigl(\frac{\partial R}{\partial y}-\frac{\partial Q}{\partial z}\Bigr)dy\,dz+\Bigl(\frac{\partial P}{\partial z}-\frac{\partial R}{\partial x}\Bigr)dz\,dx=\oint_LP\,dx+Q\,dy+R\,dz .
```
**Векторная форма** (гл. 13): $`\iint_S\operatorname{rot}\vec F\cdot\vec n\,dS=\oint_L\vec F\cdot d\vec r`$ — [поток](../../18-vector-calculus.md#sec-18-2) вихря через поверхность равен циркуляции по её границе. **Частный случай:** $`S`$ в плоскости $`Oxy`$ ($`z=0`$, верхняя сторона) — [формула Грина](../../18-vector-calculus.md#green-theorem).

## Доказательство

*Малая формула (11.4.1)* для поверхности $`S:\ z=\varphi(x,y)`$, $`(x,y)\in D`$, верхняя сторона; $`L`$ проектируется в границу $`\partial D`$, обходимую в положительном направлении. На $`L`$ имеем $`z=\varphi(x,y)`$, поэтому
```math
\oint_LP(x,y,z)\,dx=\oint_{\partial D}P\bigl(x,y,\varphi(x,y)\bigr)dx\overset{\text{Грин}}{=}-\iint_D\frac{\partial}{\partial y}P\bigl(x,y,\varphi(x,y)\bigr)dx\,dy=-\iint_D\bigl(P'_y+P'_z\,\varphi'_y\bigr)dx\,dy .
```
С другой стороны, для верхней стороны нормаль $`\vec n\parallel(-p,-q,1)`$, $`p=\varphi'_x`$, $`q=\varphi'_y`$, так что $`\cos\mu=-q\cos\nu`$, и (через интеграл I рода, [билет 79](79.md))
```math
\iint_SP'_z\,dz\,dx-P'_y\,dx\,dy=\iint_S\bigl(P'_z\cos\mu-P'_y\cos\nu\bigr)dS=\iint_D\bigl(-qP'_z-P'_y\bigr)dx\,dy .
```
Правые части совпадают. Формулы (11.4.2), (11.4.3) — проектированием на другие плоскости; сумма даёт формулу Стокса. Сложные поверхности разбивают на части (по общим участкам границы контурные интегралы сокращаются). $`\square`$

## Разобранный пример

1) $`\oint_Ly\,dx+z\,dy+x\,dz`$, $`L`$ — окружность $`x^2+y^2+z^2=R^2`$, $`x+y+z=0`$, обходимая против часовой стрелки, если смотреть с конца вектора $`(1,1,1)`$. $`\operatorname{rot}(y,z,x)=(-1,-1,-1)`$, $`S`$ — круг радиуса $`R`$ в плоскости $`x+y+z=0`$, $`\vec n=\frac{(1,1,1)}{\sqrt3}`$:
```math
\oint_L=\iint_S\operatorname{rot}\vec F\cdot\vec n\,dS=-\frac{3}{\sqrt3}\pi R^2=-\sqrt3\,\pi R^2 .
```

2) *Проверка Грина.* Для плоского контура в $`Oxy`$ и $`R=0`$, $`P,Q`$ без $`z`$ формула Стокса превращается в $`\iint_D(Q'_x-P'_y)dx\,dy=\oint P\,dx+Q\,dy`$.

## Если снять условие

- **Ориентация контура должна быть согласована со стороной поверхности** — иначе меняется знак.
- **Поверхность должна быть двусторонней:** для листа Мёбиуса формула не имеет смысла.
- **Гладкость полей на всей поверхности:** для поля $`\frac{(-y,x,0)}{x^2+y^2}`$ [ротор](../../18-vector-calculus.md#sec-18-3) равен нулю вне оси $`Oz`$, но циркуляция по окружности вокруг оси равна $`2\pi`$ — любая поверхность, натянутая на эту окружность, пересекает ось, где поле не определено.

## Проверка готовности

1. Сформулируйте формулу Стокса и правило согласования ориентаций.
2. Докажите малую формулу (11.4.1) для поверхности $`z=\varphi(x,y)`$. Где используется формула Грина?
3. Как из формулы Стокса получить формулу Грина?
4. Запишите формулу Стокса в векторной форме.
5. Найдите $`\oint_L(y-z)\,dx+(z-x)\,dy+(x-y)\,dz`$ по окружности $`x^2+y^2=1`$, $`z=0`$, против часовой стрелки (если смотреть сверху).

<details>
<summary>Ответы</summary>

1. См. выше; наблюдатель вдоль нормали оставляет поверхность слева.
2. Ограничение $`P`$ на поверхность $`z=\varphi`$, формула Грина в $`D`$ и правило дифференцирования композиции; затем $`\cos\mu=-q\cos\nu`$.
3. Взять плоскую поверхность $`z=0`$ с верхней стороной и $`R=0`$.
4. $`\iint_S\operatorname{rot}\vec F\cdot\vec n\,dS=\oint_L\vec F\cdot d\vec r`$.
5. $`\operatorname{rot}=(-2,-2,-2)`$, $`\vec n=(0,0,1)`$: $`-2\pi`$.
</details>

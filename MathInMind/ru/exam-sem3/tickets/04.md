# Билет 4. Формула Тейлора–Лагранжа для функций нескольких переменных. Остаток в форме Лагранжа. Оценка остатка

[← Билет 3](03.md) · [Все билеты](../EXAM_SEM3.md) · [Лекции 65–66](../../lectures-2025-26/lecture-65-66.md) · [Билет 5 →](05.md)

> **Лекционная опора:** [теорема 6.5.2](../../lectures-2025-26/lecture-65-66.md#thm-6-5-2) и следствие из неё ([стр. p006](../../lectures-2025-26/lecture-65-66.md#p006)) (лекции 65–66); используются [определение 6.4.3](../../lectures-2025-26/lecture-63-64.md#def-6-4-3) и [теорема 6.4.2](../../lectures-2025-26/lecture-63-64.md#thm-6-4-2) (лекции 63–64). При расхождении формулировок приоритет у лекции.

## Вопрос

[Формула Тейлора–Лагранжа](../../lectures-2025-26/lecture-65-66.md#thm-6-5-2) для функций нескольких переменных. Остаток в форме Лагранжа. Оценка остатка.

## Эталонный ответ

**Обозначения.** $`\Delta_{a,b}=\{a+t(b-a):\ t\in[0,1]\}`$ — отрезок, $`\hat\Delta_{a,b}=\Delta_{a,b}\setminus\{a,b\}`$ — отрезок без концов. [Дифференциал](../../lectures-2025-26/lecture-24-25-26.md#def-3-3-1) порядка $`k`$ в точке $`c`$ на приращении $`h`$ ([определение 6.4.3](../../lectures/17-higher-derivatives-6-4.md#def-6-4-3), [теорема 6.4.2](../../lectures/17-higher-derivatives-6-4.md#thm-6-4-2)):
```math
d_c^kf(h)=\sum_{i_1,\ldots,i_k=1}^{n}\frac{\partial^kf}{\partial x_{i_1}\cdots\partial x_{i_k}}(c)\,h_{i_1}\cdots h_{i_k}=\sum_{|\alpha|=k}\frac{k!}{\alpha!}\,\frac{\partial^\alpha f}{\partial x^\alpha}(c)\,h^\alpha,\qquad d_c^0f(h)=f(c).
```

**Теорема 6.5.2 (формула Тейлора–Лагранжа).** Пусть множество $`E`$ открыто в $`\mathbb R^n`$, $`s\in\mathbb Z_+`$, функция $`f:E\to\mathbb R`$ [дифференцируема](../../lectures-2025-26/lecture-22-23.md#def-3-2-1) $`s+1`$ раз на $`E`$, точки $`a,x\in E`$, причём $`a\ne x`$ и $`\Delta_{a,x}\subset E`$. Тогда существует $`c\in\hat\Delta_{a,x}`$, для которой
```math
f(x)=\sum_{k=0}^{s}\frac{d_a^kf(x-a)}{k!}+\frac{d_c^{s+1}f(x-a)}{(s+1)!}.
```
Слагаемое $`R_{a,s}f(x)=\frac{d_c^{s+1}f(x-a)}{(s+1)!}`$ — [остаточный член](../../lectures-2025-26/lecture-27-28.md#thm-3-6-3) в форме Лагранжа.

**Следствие (оценка остатка).** В условиях [теоремы 6.5.2](../../lectures-2025-26/lecture-65-66.md#thm-6-5-2)
```math
|R_{a,s}f(x)|\le\sup_{c\in\hat\Delta_{a,x}}\frac{|d_c^{s+1}f(x-a)|}{(s+1)!}.
```
Если все [частные производные](../../lectures/14-differentiability-6-1.md#def-6-1-5) порядка $`s+1`$ ограничены на $`\hat\Delta_{a,x}`$ числом $`M`$, то по формуле для $`d^{s+1}`$ и неравенству $`|h_1|+\ldots+|h_n|\le\sqrt n\,\|h\|`$ получаем $`|d_c^{s+1}f(h)|\le M(|h_1|+\ldots+|h_n|)^{s+1}\le M(\sqrt n\,\|h\|)^{s+1}`$ и
```math
|R_{a,s}f(x)|\le\frac{M}{(s+1)!}\bigl(\sqrt n\,\|x-a\|\bigr)^{s+1}.
```

## Доказательство

Положим $`h=x-a`$. Множество $`\{t\in\mathbb R:\ a+th\in E\}`$ открыто (прообраз открытого $`E`$ при непрерывном отображении) и содержит $`[0,1]`$; на нём определена $`F(t)=f(a+th)=d^0_{a+th}f(h)`$.

**Утверждение (∗):** $`F^{(k)}(t)=d^k_{a+th}f(h)`$ при $`t\in[0,1]`$ и всех $`k\in\{0,1,\ldots,s+1\}`$.

[Индукция](../../01-logic-sets-functions.md#example-induction) по $`k`$. База $`k=0`$ — определение $`d^0`$. Переход $`k-1\mapsto k`$, $`1\le k\le s+1`$. Отображение $`G(y)=d^{k-1}_yf(h)`$ — линейная комбинация частных производных $`f`$ порядка $`k-1\le s`$ с постоянными коэффициентами $`h_{i_1}\cdots h_{i_{k-1}}`$; так как $`f`$ дифференцируема $`s+1`$ раз на $`E`$, частные производные порядка не выше $`s`$ дифференцируемы на $`E`$, т. е. $`G`$ дифференцируема на $`E`$. Вектор-функция $`t\mapsto a+th`$ дифференцируема с [производной](../../lectures-2025-26/lecture-22-23.md#def-3-1-1) $`h`$. По индукционному предположению $`F^{(k-1)}(t)=G(a+th)`$; по теореме о дифференцировании композиции и [определению 6.4.3](../../lectures/17-higher-derivatives-6-4.md#def-6-4-3)
```math
F^{(k)}(t)=d_{a+th}G(h)=d_{a+th}\bigl(d^{k-1}f(h)\bigr)(h)=d^k_{a+th}f(h).
```
Итак, $`F`$ дифференцируема $`s+1`$ раз на $`[0,1]`$ (даже в окрестности отрезка). По формуле Тейлора с остатком в форме Лагранжа для функции одной переменной существует $`\theta\in(0,1)`$ такое, что
```math
F(1)=\sum_{k=0}^{s}\frac{F^{(k)}(0)}{k!}+\frac{F^{(s+1)}(\theta)}{(s+1)!}.
```
Подставляя (∗) и $`F(1)=f(x)`$, получаем
```math
f(x)=\sum_{k=0}^{s}\frac{d_a^kf(x-a)}{k!}+\frac{d_{a+\theta h}^{s+1}f(x-a)}{(s+1)!}.
```
Положим $`c=a+\theta h`$; так как $`\theta\in(0,1)`$ и $`h\ne0`$, точка $`c`$ лежит в $`\hat\Delta_{a,x}`$. $`\square`$

Следствие: $`c\in\hat\Delta_{a,x}`$, поэтому $`|R_{a,s}f(x)|=\frac{|d_c^{s+1}f(x-a)|}{(s+1)!}`$ не превосходит [супремума](../../lectures-2025-26/lecture-11-12.md#def-2-3-1) по $`\hat\Delta_{a,x}`$. Оценка при ограниченных производных получена выше.

## Разобранный пример

Оценим $`\sin x\sin y-xy`$ при $`a=(0,0)`$, $`s=3`$. Для $`f=\sin x\sin y`$ в нуле: $`f=0`$, $`f_x=f_y=0`$, $`f_{xx}=f_{yy}=0`$, $`f_{xy}=\cos x\cos y=1`$, а все четыре третьи производные ($`-\cos x\sin y`$, $`-\sin x\cos y`$) равны нулю. Поэтому $`T_{0,3}f(x,y)=\frac{d_0^2f(h)}{2}=xy`$. Все частные производные четвёртого порядка имеют вид $`\pm\sin x\sin y`$ или $`\pm\cos x\cos y`$, т. е. $`M=1`$, и по следствию при $`n=2`$
```math
|\sin x\sin y-xy|\le\frac{(|x|+|y|)^4}{4!}\qquad\text{при всех }(x,y)\in\mathbb R^2.
```
(Здесь использовано неравенство $`|d_c^4f(h)|\le M(|h_1|+|h_2|)^4`$, более точное, чем с $`\sqrt n\|h\|`$.) При $`x=y=0{,}1`$ оценка даёт $`\frac{0{,}2^4}{24}\approx6{,}7\cdot10^{-5}`$; фактическая погрешность $`|\sin^2(0{,}1)-0{,}01|\approx3{,}3\cdot10^{-5}`$.

## Если снять условие

- **Отрезок $`\Delta_{a,x}`$ обязан лежать в $`E`$.** Пусть $`n=1`$, $`E=\mathbb R\setminus\{0\}`$, $`f(x)=\operatorname{sgn}x`$, $`s=0`$, $`a=-1`$, $`x=1`$. Функция дифференцируема на $`E`$, $`f'\equiv0`$, но $`f(1)-f(-1)=2\ne f'(c)\cdot2`$ ни при каком $`c`$; здесь $`\Delta_{-1,1}\not\subset E`$.
- **Дифференцируемость нужна во всех точках отрезка.** Для $`f(x)=|x|`$, $`s=0`$, $`a=-1`$, $`x=2`$: $`f(2)-f(-1)=1`$, а $`f'(c)\cdot3=\pm3`$ при $`c\ne0`$, и $`f`$ не дифференцируема в $`0\in\hat\Delta_{-1,2}`$. Равенство из теоремы не выполняется ни при каком $`c`$.
- **Для отображений $`f:E\to\mathbb R^m`$, $`m\ge2`$, равенство неверно** (см. билет 5): остаётся лишь оценка по [норме](../../14-several-variables.md#sec-14-1).

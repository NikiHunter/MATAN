## Вопрос

[Формула Гаусса–Остроградского](../../18-vector-calculus.md#divergence-theorem).

## Эталонный ответ

**Формула Остроградского–Гаусса (2024/25).** Пусть тело $`T`$ ограничено кусочно-гладкой поверхностью $`S_T`$ и функции $`P,Q,R`$ непрерывны вместе с [частными производными](../../15-multivariable-differentiation.md#sec-15-2) $`\frac{\partial P}{\partial x}`$, $`\frac{\partial Q}{\partial y}`$, $`\frac{\partial R}{\partial z}`$ в $`\overline T`$. Тогда
```math
\iiint_T\Bigl(\frac{\partial P}{\partial x}+\frac{\partial Q}{\partial y}+\frac{\partial R}{\partial z}\Bigr)dx\,dy\,dz=\iint_{S_T}P\,dy\,dz+Q\,dz\,dx+R\,dx\,dy ,
```
где интеграл справа берётся по **внешней** стороне $`S_T`$. Через интеграл I рода ($`\lambda,\mu,\nu`$ — углы внешней нормали с осями):
```math
\iiint_T\Bigl(\frac{\partial P}{\partial x}+\frac{\partial Q}{\partial y}+\frac{\partial R}{\partial z}\Bigr)dV=\iint_{S_T}\bigl(P\cos\lambda+Q\cos\mu+R\cos\nu\bigr)dS .
```

**Малые формулы:** $`\iiint_T\frac{\partial R}{\partial z}dV=\iint_{S_T}R\,dx\,dy`$ (11.3.1), $`\iiint_T\frac{\partial P}{\partial x}dV=\iint_{S_T}P\,dy\,dz`$ (11.3.2), $`\iiint_T\frac{\partial Q}{\partial y}dV=\iint_{S_T}Q\,dz\,dx`$ (11.3.3). Полная формула — их сумма.

**Векторная форма** (гл. 13): $`\iiint_T\operatorname{div}\vec F\,dV=\iint_{S_T}\vec F\cdot\vec n\,dS`$ — поток через замкнутую поверхность равен интегралу [дивергенции](../../18-vector-calculus.md#sec-18-3).

**Объём тела:** при $`P=x`$, $`Q=y`$, $`R=z`$
```math
V_T=\frac13\iint_{S_T}x\,dy\,dz+y\,dz\,dx+z\,dx\,dy=\frac13\iint_{S_T}\bigl(x\cos\lambda+y\cos\mu+z\cos\nu\bigr)dS .
```
Формулу можно обобщить на $`n`$-мерные интегралы и $`(n-1)`$-мерные поверхности.

## Доказательство

*Малая формула (11.3.1) для «простого вдоль $`Oz`$» тела* $`T=\{(x,y)\in D,\ \varphi(x,y)\le z\le\Phi(x,y)\}`$: снизу поверхность $`S_1:\ z=\varphi`$, сверху $`S_3:\ z=\Phi`$, сбоку цилиндрическая $`S_2`$ с образующими вдоль $`Oz`$. По [теореме Фубини](../../17-multiple-integrals.md#fubini-theorem-continuous) и [формуле Ньютона–Лейбница](../../08-riemann-integration.md#newton-leibniz-formula)
```math
\iiint_T\frac{\partial R}{\partial z}dx\,dy\,dz=\iint_Ddx\,dy\int_{\varphi(x,y)}^{\Phi(x,y)}\frac{\partial R}{\partial z}dz=\iint_D\bigl[R(x,y,\Phi)-R(x,y,\varphi)\bigr]dx\,dy .
```
По теореме 11.2.2 ([билет 79](79.md)) $`\iint_DR(x,y,\Phi)dx\,dy=\iint_{S_3\text{ (верх)}}R\,dx\,dy`$, $`-\iint_DR(x,y,\varphi)dx\,dy=\iint_{S_1\text{ (низ)}}R\,dx\,dy`$, а $`\iint_{S_2}R\,dx\,dy=0`$ (проекция боковой поверхности на $`Oxy`$ — кривая). Верхняя сторона $`S_3`$, нижняя сторона $`S_1`$ и любая сторона $`S_2`$ (вклад нулевой) — это внешняя сторона $`S_T`$. Получаем (11.3.1). Формулы (11.3.2), (11.3.3) — для тел, простых вдоль $`Ox`$ и $`Oy`$; для тела, простого во всех трёх направлениях, складываем. Тела, разрезаемые на конечное число таких, — аддитивность (по разрезам потоки сокращаются). $`\square`$

## Разобранный пример

1) *Поток радиус-вектора через сферу:* $`\operatorname{div}(x,y,z)=3`$, поток $`=\iiint_{\text{шар}}3\,dV=3\cdot\frac43\pi R^3=4\pi R^3`$ — совпадает с прямым вычислением ([билет 79](79.md)).

2) $`\iint_S x^3\,dy\,dz+y^3\,dz\,dx+z^3\,dx\,dy`$ по внешней стороне границы куба $`[0,1]^3`$: $`\iiint3(x^2+y^2+z^2)\,dV=3\cdot3\cdot\frac13=3`$.

3) *Объём шара* по формуле объёма: на сфере $`x\cos\lambda+y\cos\mu+z\cos\nu=\vec r\cdot\frac{\vec r}{R}=R`$, так что $`V=\frac13R\cdot4\pi R^2=\frac43\pi R^3`$.

## Если снять условие

- **Гладкость полей внутри тела существенна.** Поле $`\vec F=\frac{\vec r}{|\vec r|^3}`$ имеет $`\operatorname{div}\vec F=0`$ при $`\vec r\ne0`$, но поток через сферу вокруг нуля равен $`\iint\frac{1}{R^2}dS=4\pi\ne0`$: в начале координат поле не определено.
- **Нужна внешняя сторона:** по внутренней стороне знак меняется.
- **Поверхность должна быть замкнутой:** для незамкнутой поверхности (полусферы) формула неприменима — её «замыкают» плоской крышкой и вычитают поток через крышку.

## Проверка готовности

1. Сформулируйте формулу Остроградского–Гаусса в координатной форме и через интеграл I рода.
2. Докажите малую формулу (11.3.1). Почему вклад боковой поверхности нулевой?
3. Как получить формулу объёма тела через поверхностный интеграл?
4. Почему для поля $`\frac{\vec r}{r^3}`$ поток через сферу не равен нулю, хотя дивергенция нулевая?
5. Найдите поток поля $`\vec F=(x,y,0)`$ через внешнюю сторону поверхности цилиндра $`x^2+y^2\le1`$, $`0\le z\le2`$ (с основаниями).

# Билет 58. Непрерывность и интегрирование несобственного интеграла по параметру

При расхождении формулировок приоритет у лекции.

## Вопрос

Непрерывность и интегрирование [несобственного интеграла](../../lectures/06-improper-integrals-4-5.md#def-4-5-2) по параметру.

## Эталонный ответ

**Теорема 9.2.1 (непрерывность).** Пусть $`f`$ непрерывна на $`[a,b)\times[c,d]`$, $`y_0\in[c,d]`$, и $`I(y)=\int_a^bf(x,y)\,dx`$ [сходится равномерно](../../10-function-sequences-series.md#sec-10-1) в некоторой окрестности точки $`y_0`$ (пересечённой с $`[c,d]`$). Тогда $`I`$ непрерывна в $`y_0`$. В частности, при равномерной сходимости на $`[c,d]`$ имеем $`I\in C([c,d])`$.

**Теорема 9.2.3 (интегрирование).** Пусть $`f`$ непрерывна на $`[a,b)\times[c,d]`$ и $`I(y)`$ сходится равномерно на $`[c,d]`$. Тогда $`I`$ интегрируема на $`[c,d]`$, несобственный интеграл справа сходится, и
```math
\int_c^dI(y)\,dy=\int_a^b\left(\int_c^df(x,y)\,dy\right)dx .
```

**Идея обеих теорем.** Разбить интеграл на собственный $`\int_a^\eta`$ (для него работают [теоремы 9.1.1](../../lectures-2025-26/lecture-75-76.md#thm-9-1-1) и [9.1.3](../../lectures-2025-26/lecture-77-78.md#thm-9-1-3)) и «хвост» $`\int_\eta^b`$, который равномерная сходимость делает малым сразу для всех $`y`$.

**Важное следствие.** Равномерная сходимость в окрестности точки законно позволяет переходить к пределу под знаком интеграла: $`\lim_{y\to y_0}\int_a^bf(x,y)dx=\int_a^bf(x,y_0)dx`$.

## Доказательство

*[Теорема 9.2.1](../../lectures-2025-26/lecture-77-78.md#thm-9-2-1).* Пусть $`\varepsilon>0`$, $`K=[c,d]\cap[y_0-\frac{\delta_0}{2},y_0+\frac{\delta_0}{2}]`$. Найдётся $`\eta\in[a,b)`$ с $`\bigl|\int_\eta^bf(x,y)dx\bigr|<\varepsilon`$ при всех $`y\in K`$. Собственный интеграл $`J(y)=\int_a^\eta f(x,y)dx`$ непрерывен на $`K`$ ([теорема 9.1.1](../../lectures-2025-26/lecture-75-76.md#thm-9-1-1)), так что при $`|y-y_0|<\delta`$ ($`\delta\le\frac{\delta_0}{2}`$) имеем $`|J(y)-J(y_0)|<\varepsilon`$. Тогда
```math
|I(y)-I(y_0)|\le|J(y)-J(y_0)|+\Bigl|\int_\eta^bf(x,y)dx\Bigr|+\Bigl|\int_\eta^bf(x,y_0)dx\Bigr|<3\varepsilon .\qquad\square
```

*[Теорема 9.2.3](../../lectures-2025-26/lecture-77-78.md#thm-9-2-3).* По [теореме 9.2.1](../../lectures-2025-26/lecture-77-78.md#thm-9-2-1) $`I\in C([c,d])`$, значит, интегрируема. При $`t\in[a,b)`$ по [теореме 9.1.3](../../lectures-2025-26/lecture-77-78.md#thm-9-1-3) на прямоугольнике $`[a,t]\times[c,d]`$
```math
\int_a^t\left(\int_c^df\,dy\right)dx=\int_c^dI_t(y)\,dy,\qquad I_t(y)=\int_a^tf(x,y)\,dx .
```
При $`t\in(b_0,b)`$ (где $`b_0`$ из определения равномерной сходимости для данного $`\varepsilon`$)
```math
\Bigl|\int_c^dI(y)dy-\int_a^t\Bigl(\int_c^df\,dy\Bigr)dx\Bigr|\le\int_c^d\Bigl|\int_t^bf(x,y)dx\Bigr|dy\le\varepsilon(d-c) .
```
Значит, $`\lim_{t\to b}\int_a^t\bigl(\int_c^df\,dy\bigr)dx=\int_c^dI(y)dy`$. $`\square`$

## Разобранный пример

1) *Непрерывность в нуле интеграла Дирихле с множителем.* $`I_1(y)=\int_0^\infty\frac{\sin x}{x}e^{-xy}dx`$ сходится равномерно на $`[0,+\infty)`$ ([признак Абеля](../../lectures/06-improper-integrals-4-5.md#thm-4-5-4), [билет 57](57.md)), подынтегральная функция (с $`\frac{\sin x}{x}=1`$ при $`x=0`$) непрерывна. По [теореме 9.2.1](../../lectures-2025-26/lecture-77-78.md#thm-9-2-1)
```math
\int_0^\infty\frac{\sin x}{x}\,dx=I_1(0)=\lim_{y\to0+}I_1(y).
```
Это обосновывает последний шаг вычисления лекции ($`I_1(y)=\frac\pi2-\operatorname{arctg}y`$, см. [билет 59](59.md)), откуда $`\int_0^\infty\frac{\sin x}{x}dx=\frac\pi2`$.

2) *Интеграл Фруллани через интегрирование по параметру.* При $`0<a<b`$: $`\int_0^\infty e^{-xy}dx=\frac1y`$, сходимость равномерна на $`[a,b]`$ (мажоранта $`e^{-ax}`$). По [теореме 9.2.3](../../lectures-2025-26/lecture-77-78.md#thm-9-2-3)
```math
\ln\frac ba=\int_a^b\frac{dy}{y}=\int_a^b\Bigl(\int_0^\infty e^{-xy}dx\Bigr)dy=\int_0^\infty\Bigl(\int_a^be^{-xy}dy\Bigr)dx=\int_0^\infty\frac{e^{-ax}-e^{-bx}}{x}\,dx .
```
(В точке $`x=0`$ внутренний интеграл равен $`b-a`$ — функция непрерывна.)

## Если снять условие

- **Без равномерной сходимости $`I`$ может быть разрывна.** $`\int_0^\infty ye^{-xy}dx=1`$ при $`y>0`$, $`0`$ при $`y=0`$; хвост $`e^{-ty}`$ не мал равномерно около $`y=0`$.
- **Без равномерной сходимости повторные интегралы могут различаться.** Для $`f(x,y)=(1-xy)e^{-xy}`$ на $`[0,+\infty)\times[0,1]`$: $`\int_0^\infty f\,dx=\bigl[xe^{-xy}\bigr]_0^\infty=0`$ при $`y>0`$, так что $`\int_0^1\bigl(\int_0^\infty f\,dx\bigr)dy=0`$; а $`\int_0^1f\,dy=\bigl[ye^{-xy}\bigr]_0^1=e^{-x}`$ и $`\int_0^\infty e^{-x}dx=1`$. Хвост $`\int_t^\infty f\,dx=-te^{-ty}`$ при $`y=\frac1t`$ равен $`-\frac1e`$ — сходимость неравномерная.
- **Нужна непрерывность $`f`$ по совокупности переменных** (поправка M526): непрерывности по $`y`$ в одной точке мало даже для собственных интегралов (пример из [билета 52](52.md)).

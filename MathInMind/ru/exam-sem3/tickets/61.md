# Билет 61. Бета-функция. Связь бета- и гамма-функций

[← Билет 60](60.md) · [Все билеты](../EXAM_SEM3.md) · [Лекции 79–80](../../lectures-2025-26/lecture-79-80.md) · [Билет 62 →](62.md)

> **Лекционная опора:** [бета-функция](../../25-parameter-integrals.md#sec-9-3) и вывод формулы $`B(y,z)=\frac{\Gamma(y)\Gamma(z)}{\Gamma(y+z)}`$ (восстановлен по записи 2024/25, ФС p89, с обоснованием перестановки интегралов), сведение формулы дополнения к бета-функции ([стр. p070](../../lectures-2025-26/lecture-79-80.md#p070)), пример $`\int_0^{\pi/2}\sin^\alpha x\cos^\beta x\,dx`$ и независимый вывод $`\Gamma(\frac12)=\sqrt\pi`$ ([стр. p071](../../lectures-2025-26/lecture-79-80.md#p071)) (лекции 79–80). При расхождении формулировок приоритет у лекции.

## Вопрос

Бета-функция. Связь бета- и [гамма-функций](../../lectures-2025-26/lecture-79-80.md#def-9-3-1).

## Эталонный ответ

**Определение.** Для $`y,z>0`$
```math
B(y,z)=\int_0^1x^{y-1}(1-x)^{z-1}\,dx
```
— бета-функция (эйлеров интеграл первого рода). Интеграл сходится ровно при $`y>0`$, $`z>0`$: около $`0`$ подынтегральная функция эквивалентна $`x^{y-1}`$, около $`1`$ — функции $`(1-x)^{z-1}`$.

**Свойства.** 1) Симметрия $`B(y,z)=B(z,y)`$ (замена $`x\to1-x`$). 2) Другая запись: $`B(y,z)=\int_0^\infty\frac{b^{y-1}}{(1+b)^{y+z}}db`$ (замена $`x=\frac{b}{1+b}`$). 3) **Связь с гамма-функцией:**
```math
B(y,z)=\frac{\Gamma(y)\,\Gamma(z)}{\Gamma(y+z)},\qquad y,z>0 .
```
4) Тригонометрическая форма: $`\int_0^{\pi/2}\sin^\alpha x\cos^\beta x\,dx=\frac12B\bigl(\frac{\alpha+1}{2},\frac{\beta+1}{2}\bigr)`$, $`\alpha,\beta>-1`$.

**Следствия.** $`\Gamma(\frac12)=\sqrt\pi`$ без интеграла Эйлера–Пуассона; формула дополнения $`\Gamma(y)\Gamma(1-y)=B(y,1-y)=\int_0^\infty\frac{b^{y-1}}{1+b}db=\frac{\pi}{\sin\pi y}`$ (последний интеграл в лекции не вычислялся).

## Доказательство

*Связь с гамма-функцией.* По формуле Эйлера ([билет 60](60.md)) для $`y+z`$ и параметра $`b+1`$:
```math
\frac{\Gamma(y+z)}{(b+1)^{y+z}}=\int_0^\infty t^{y+z-1}e^{-(b+1)t}\,dt\qquad(b>0).
```
Умножим на $`b^{y-1}`$ и проинтегрируем по $`b\in(0,\infty)`$:
```math
\Gamma(y+z)\int_0^\infty\frac{b^{y-1}}{(b+1)^{y+z}}\,db=\int_0^\infty\Bigl(\int_0^\infty b^{y-1}t^{y+z-1}e^{-t}e^{-bt}\,dt\Bigr)db .
```
Переставим интегралы (подынтегральная функция непрерывна и неотрицательна при $`b,t>0`$, а оба [повторных интеграла](../../17-multiple-integrals.md#sec-17-1) конечны — для таких функций повторные [несобственные интегралы](../../lectures/06-improper-integrals-4-5.md#def-4-5-2) совпадают; в лекции это обосновано через [теорему 9.1.3](../../lectures-2025-26/lecture-77-78.md#thm-9-1-3) на квадратах $`[\frac1N,N]^2`$ и теорему Дини). Внутренний интеграл по $`b`$ — снова формула Эйлера: $`\int_0^\infty b^{y-1}e^{-bt}db=\frac{\Gamma(y)}{t^y}`$. Получаем
```math
\int_0^\infty t^{y+z-1}e^{-t}\,\frac{\Gamma(y)}{t^y}\,dt=\Gamma(y)\int_0^\infty t^{z-1}e^{-t}dt=\Gamma(y)\Gamma(z).
```
Значит, $`\int_0^\infty\frac{b^{y-1}}{(b+1)^{y+z}}db=\frac{\Gamma(y)\Gamma(z)}{\Gamma(y+z)}`$. Замена $`x=\frac{b}{b+1}`$ ($`b=\frac{x}{1-x}`$, $`b+1=\frac1{1-x}`$, $`db=\frac{dx}{(1-x)^2}`$) переводит левый интеграл в
```math
\int_0^1\frac{x^{y-1}}{(1-x)^{y-1}}(1-x)^{y+z}\frac{dx}{(1-x)^2}=\int_0^1x^{y-1}(1-x)^{z-1}dx=B(y,z).\qquad\square
```

*Тригонометрическая форма.* Замена $`t=\sin^2x`$, $`dx=\frac{dt}{2\sqrt t\sqrt{1-t}}`$: $`\int_0^{\pi/2}\sin^\alpha x\cos^\beta x\,dx=\frac12\int_0^1t^{\frac{\alpha+1}{2}-1}(1-t)^{\frac{\beta+1}{2}-1}dt`$. $`\square`$

*$`\Gamma(\frac12)=\sqrt\pi`$.* При $`\alpha=\beta=0`$: $`\frac\pi2=\frac12B(\frac12,\frac12)=\frac{\Gamma(\frac12)^2}{2\Gamma(1)}`$, и $`\Gamma(\frac12)>0`$. $`\square`$

## Разобранный пример

1) $`\int_0^1x^4(1-x)^3\,dx=B(5,4)=\frac{4!\,3!}{8!}=\frac{1}{280}`$.

2) $`\int_0^{\pi/2}\sin^6x\,dx=\frac{\Gamma(\frac72)\Gamma(\frac12)}{2\Gamma(4)}=\frac{\frac{15}{8}\sqrt\pi\cdot\sqrt\pi}{12}=\frac{5\pi}{32}`$ — совпадает с формулой Валлиса $`\frac{5\cdot3\cdot1}{6\cdot4\cdot2}\cdot\frac\pi2`$.

3) $`\int_0^1\frac{dx}{\sqrt{1-x^4}}`$: замена $`x^4=t`$ даёт $`\frac14\int_0^1t^{-3/4}(1-t)^{-1/2}dt=\frac14B\bigl(\frac14,\frac12\bigr)=\frac{\Gamma(\frac14)\Gamma(\frac12)}{4\Gamma(\frac34)}`$.

4) $`\int_0^\infty\frac{dx}{1+x^4}`$: замена $`x^4=t`$ даёт $`\frac14\int_0^\infty\frac{t^{-3/4}}{1+t}dt=\frac14B\bigl(\frac14,\frac34\bigr)=\frac14\Gamma(\tfrac14)\Gamma(\tfrac34)=\frac{\pi}{4\sin\frac\pi4}=\frac{\pi}{2\sqrt2}`$ (по формуле дополнения).

## Если снять условие

- **При $`y\le0`$ или $`z\le0`$ интеграл расходится** ($`x^{y-1}`$ не интегрируема около нуля при $`y\le0`$).
- **Перестановку несобственных интегралов нужно обосновывать.** Для неотрицательных функций она законна, если повторные интегралы конечны; для знакопеременных — может нарушаться: $`f=(1-xy)e^{-xy}`$ на $`[0,\infty)\times[0,1]`$ даёт повторные интегралы $`0`$ и $`1`$ ([билет 58](58.md)).
- **Формула дополнения в лекции не доказана:** вычисление $`\int_0^\infty\frac{b^{y-1}}{1+b}db=\frac{\pi}{\sin\pi y}`$ требует теории вычетов или рядов; на экзамене её можно лишь сформулировать и свести к бета-функции.

## Проверка готовности

1. Дайте определение бета-функции. При каких $`y,z`$ интеграл сходится?
2. Выведите формулу $`B(y,z)=\frac{\Gamma(y)\Gamma(z)}{\Gamma(y+z)}`$. Где нужна перестановка интегралов и почему она законна?
3. Выразите $`\int_0^{\pi/2}\sin^\alpha x\cos^\beta x\,dx`$ через гамма-функцию.
4. Получите $`\Gamma(\frac12)=\sqrt\pi`$ с помощью бета-функции.
5. Вычислите $`\int_0^1x^2\sqrt{1-x^2}\,dx`$.

<details>
<summary>Ответы</summary>

1. $`\int_0^1x^{y-1}(1-x)^{z-1}dx`$, $`y,z>0`$.
2. Формула Эйлера для $`(y+z,b+1)`$, умножить на $`b^{y-1}`$, проинтегрировать по $`b`$, переставить (неотрицательная непрерывная функция, конечные повторные интегралы), снова формула Эйлера, затем замена $`x=\frac{b}{b+1}`$.
3. $`\frac{\Gamma(\frac{\alpha+1}{2})\Gamma(\frac{\beta+1}{2})}{2\Gamma(\frac{\alpha+\beta}{2}+1)}`$.
4. $`\alpha=\beta=0`$: $`\frac\pi2=\frac12\Gamma(\frac12)^2`$.
5. Замена $`x^2=t`$: $`\frac12\int_0^1t^{1/2}(1-t)^{1/2}dt=\frac12B(\frac32,\frac32)=\frac12\cdot\frac{(\sqrt\pi/2)^2}{\Gamma(3)}=\frac{\pi}{16}`$.
</details>

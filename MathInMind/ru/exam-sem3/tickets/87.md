# Билет 87. Неравенство Бесселя. Равенство Парсеваля

[← Билет 86](86.md) · [Все билеты](../EXAM_SEM3.md) · [Тема в курсе: гл. 12](../../12-fourier-series.md) · [Билет 88 →](88.md)

> **Прогноз.** Билет по гл. 11–13; лекций 2025/26 ещё нет, нумерация по слайдам 2024/25 (стр. 123: «Неравенство Бесселя» и вывод в записях для $`N=1`$; стр. 124: «Равенство Парсеваля» и его формальный вывод почленным интегрированием квадрата ряда). Строгого доказательства равенства Парсеваля на слайдах нет; ниже — стандартное, через минимальное свойство [частичных сумм](../../04-numeric-series.md#sec-4-1) и [билет 86](86.md). После лекций формулировки и номера нужно сверить.

## Вопрос

[Неравенство Бесселя](../../12-fourier-series.md#sec-12-4). Равенство Парсеваля.

## Эталонный ответ

**Неравенство Бесселя (2024/25).** Для кусочно-непрерывной функции $`f`$ на $`[-\pi,\pi]`$ с [коэффициентами Фурье](../../12-fourier-series.md#sec-12-1) $`a_n,b_n`$
```math
\frac{a_0^2}{2}+\sum_{n=1}^{\infty}\bigl(a_n^2+b_n^2\bigr)\le\frac1\pi\int_{-\pi}^{\pi}f^2(x)\,dx .
```
Отсюда следует, что ряд $`\sum(a_n^2+b_n^2)`$ сходится; в частности, $`a_n,b_n\to0`$.

**Равенство Парсеваля.** Если $`f`$ квадратично интегрируема на $`[-\pi,\pi]`$, т. е. $`\int_{-\pi}^{\pi}f^2(x)\,dx<+\infty`$, то неравенство Бесселя становится равенством:
```math
\frac{a_0^2}{2}+\sum_{n=1}^{\infty}\bigl(a_n^2+b_n^2\bigr)=\frac1\pi\int_{-\pi}^{\pi}f^2(x)\,dx .
```

**Смысл.** Равенство Парсеваля равносильно сходимости ряда Фурье к $`f`$ **в среднем квадратичном**: $`\int_{-\pi}^{\pi}(f-S_N)^2dx\to0`$. Это выражает полноту тригонометрической системы: «энергия» функции равна сумме «энергий» её гармоник.

**Минимальное свойство частичных сумм.** Среди всех тригонометрических многочленов $`T`$ степени не выше $`N`$ наименьшее значение $`\int_{-\pi}^{\pi}(f-T)^2dx`$ даёт частичная сумма $`S_N`$ ряда Фурье.

## Доказательство

*Основное тождество.* Пусть $`T(x)=\frac{\alpha_0}{2}+\sum_{k=1}^{N}(\alpha_k\cos kx+\beta_k\sin kx)`$. По ортогональности ([билет 82](82.md)) $`\int T^2=\pi\bigl(\frac{\alpha_0^2}{2}+\sum(\alpha_k^2+\beta_k^2)\bigr)`$ и $`\int fT=\pi\bigl(\frac{\alpha_0a_0}{2}+\sum(\alpha_ka_k+\beta_kb_k)\bigr)`$. Раскрывая $`\int(f-T)^2=\int f^2-2\int fT+\int T^2`$ и выделяя полные квадраты:
```math
\int_{-\pi}^{\pi}(f-T)^2dx=\int_{-\pi}^{\pi}f^2dx-\pi\Bigl[\frac{a_0^2}{2}+\sum_{k=1}^{N}(a_k^2+b_k^2)\Bigr]+\pi\Bigl[\frac{(\alpha_0-a_0)^2}{2}+\sum_{k=1}^{N}\bigl((\alpha_k-a_k)^2+(\beta_k-b_k)^2\bigr)\Bigr].
```
Последняя скобка неотрицательна и равна нулю только при $`T=S_N`$ — это минимальное свойство.

*Неравенство Бесселя.* При $`T=S_N`$ (в записях к слайду — для $`N=1`$):
```math
0\le\int_{-\pi}^{\pi}(f-S_N)^2dx=\int_{-\pi}^{\pi}f^2dx-\pi\Bigl[\frac{a_0^2}{2}+\sum_{k=1}^{N}(a_k^2+b_k^2)\Bigr].
```
Частичные суммы ряда $`\frac{a_0^2}{2}+\sum(a_k^2+b_k^2)`$ не убывают и [ограничены сверху](../../02-real-numbers.md#sec-2-2) числом $`\frac1\pi\int f^2`$, поэтому ряд сходится, и в пределе получаем неравенство.

*Равенство Парсеваля* (для кусочно-непрерывной $`f`$; на слайде — формальный вывод возведением ряда в квадрат и почленным интегрированием). По тождеству достаточно доказать, что $`\int(f-S_N)^2\to0`$. Обозначим $`\|h\|=\bigl(\int_{-\pi}^{\pi}h^2\bigr)^{1/2}`$; для этой величины верно неравенство треугольника (следствие [неравенства Коши–Буняковского](../../21-lp-spaces.md#sec-21-4)). Пусть $`\varepsilon>0`$.
1. Найдётся непрерывная $`2\pi`$-периодическая кусочно-линейная $`g`$ с $`\|f-g\|<\varepsilon`$: если $`|f|\le M`$, возьмём ступенчатую $`h\le f`$ с $`\int(f-h)<\eta`$ ([нижняя сумма Дарбу](../../08-riemann-integration.md#sec-8-1)), тогда $`\int(f-h)^2\le2M\eta`$; затем заменим скачки $`h`$ (и концы отрезка) линейными участками малой суммарной длины $`\eta'`$: $`\int(h-g)^2\le4M^2\eta'`$.
2. Ряд Фурье $`g`$ сходится к $`g`$ равномерно (теорема 12.2.2, [билет 86](86.md)), поэтому $`\|g-S_N(g)\|\le\sqrt{2\pi}\sup|g-S_N(g)|<\varepsilon`$ при $`N\ge N_0`$.
3. $`S_N(g)`$ — тригонометрический многочлен степени $`N`$, и по минимальному свойству
```math
\|f-S_N(f)\|\le\|f-S_N(g)\|\le\|f-g\|+\|g-S_N(g)\|<2\varepsilon\qquad(N\ge N_0).
```
Итак, $`\int(f-S_N)^2\to0`$, и тождество даёт равенство Парсеваля. Для неограниченной $`f`$ с $`\int f^2<\infty`$ сначала срезают её на уровне $`M`$. $`\square`$

## Разобранный пример

1) $`f(x)=x`$ на $`(-\pi,\pi)`$: $`a_n=0`$, $`b_n=\frac{2(-1)^{n+1}}{n}`$. Парсеваль: $`\sum\frac4{n^2}=\frac1\pi\int_{-\pi}^{\pi}x^2dx=\frac{2\pi^2}{3}`$, т. е. $`\sum_{n=1}^{\infty}\frac1{n^2}=\frac{\pi^2}{6}`$.

2) $`f(x)=x^2`$: $`a_0=\frac{2\pi^2}{3}`$, $`a_n=\frac{4(-1)^n}{n^2}`$. Парсеваль: $`\frac{2\pi^4}{9}+16\sum\frac1{n^4}=\frac1\pi\int_{-\pi}^{\pi}x^4dx=\frac{2\pi^4}{5}`$, откуда $`\sum_{n=1}^{\infty}\frac1{n^4}=\frac{\pi^4}{90}`$.

3) *Неравенство Бесселя как признак.* Тригонометрический ряд $`\sum\frac{\sin nx}{\sqrt n}`$ сходится при каждом $`x`$ ([признак Дирихле](../../04-numeric-series.md#sec-4-3)), но не является рядом Фурье никакой функции с $`\int f^2<\infty`$: иначе $`\sum b_n^2=\sum\frac1n<\infty`$.

## Если снять условие

- **Без квадратичной интегрируемости** ряд $`\sum(a_n^2+b_n^2)`$ может расходиться: для $`f(x)=|x|^{-1/2}`$ (интегрируема, но $`\int f^2=\infty`$) $`a_n\sim\sqrt{\frac{2}{\pi n}}`$. Коэффициенты при этом всё равно стремятся к нулю (лемма Римана–Лебега, [билет 84](84.md)).
- **Неравенство Бесселя верно для любой ортогональной системы, равенство — только для полной.** Если выбросить из системы $`\cos x`$, то для $`f=\cos x`$ левая часть равна $`0`$, правая — $`1`$.
- **Сходимость в среднем не означает поточечной:** равенство Парсеваля выполнено для любой кусочно-непрерывной $`f`$, но в [точке разрыва](../../05-limits-continuity.md#sec-5-3) ряд сходится к полусумме [односторонних пределов](../../05-limits-continuity.md#sec-5-1), а для некоторых непрерывных функций расходится в отдельных точках.

## Проверка готовности

1. Сформулируйте неравенство Бесселя. Что из него следует для коэффициентов Фурье?
2. Выведите тождество для $`\int(f-T)^2`$ и минимальное свойство частичных сумм.
3. Докажите неравенство Бесселя.
4. Как из [равномерной сходимости](../../10-function-sequences-series.md#sec-10-1) рядов Фурье гладких функций получить равенство Парсеваля?
5. С помощью равенства Парсеваля для $`f(x)=|x|`$ найдите $`\sum_{k\ge0}\frac{1}{(2k+1)^4}`$.

<details>
<summary>Ответы</summary>

1. См. выше; ряд $`\sum(a_n^2+b_n^2)`$ сходится, $`a_n,b_n\to0`$.
2. Раскрыть $`\int(f-T)^2`$ по ортогональности и выделить полные квадраты; последняя скобка равна нулю только при $`T=S_N`$.
3. $`0\le\int(f-S_N)^2=\int f^2-\pi[\ldots]`$; частичные суммы ограничены и не убывают.
4. Приблизить $`f`$ непрерывной кусочно-линейной $`g`$, у которой $`S_N(g)\to g`$ равномерно; затем минимальное свойство и неравенство треугольника.
5. $`a_0=\pi`$, $`a_{2k+1}=-\frac{4}{\pi(2k+1)^2}`$: $`\frac{\pi^2}{2}+\frac{16}{\pi^2}\sum\frac1{(2k+1)^4}=\frac{2\pi^2}{3}`$, откуда сумма равна $`\frac{\pi^4}{96}`$.
</details>

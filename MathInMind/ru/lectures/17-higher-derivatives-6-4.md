# §6.4 Производные и дифференциалы высших порядков

[← §6.3](16-continuous-differentiability-6-3.md) · [Лекционный указатель](index.md) · [Термины](terms.md) · [Билеты 67–72](../exam/index.md)

> **Первичный источник нумерации:** `МАТАН_Л/Лекция 63-64 1.md`. Сохранены [определения 6.4.1](#def-6-4-1)–[6.4.3](#def-6-4-3) и [теорема 6.4.2](#thm-6-4-2). Формулировка [теоремы 6.4.1](#thm-6-4-1) восстановлена по прямым ссылкам на неё в замечаниях лекции и по билетам 70–71; отсутствие отдельного слайда отмечено явно.

<a id="def-6-4-1"></a>
## Определение 6.4.1 — частная производная порядка $`s`$

Для индексов $`i_1,\ldots,i_s`$:

```math
\frac{\partial^s f}{\partial x_{i_1}\cdots\partial x_{i_s}}(a)
```

называется [частной производной](14-differentiability-6-1.md#def-6-1-5) порядка $`s`$. Если все индексы совпадают, производная чистая; иначе смешанная. Порядок записи показывает порядок дифференцирования:

```math
f_{xy}=(f_x)_y,\qquad f_{yx}=(f_y)_x.
```

Без дополнительных условий $`f_{xy}`$ и $`f_{yx}`$ не обязаны совпадать.

<a id="def-6-4-2"></a>
## Определение 6.4.2 — многократная дифференцируемость

$`f`$ называется $`s`$ раз дифференцируемой в $`a`$, если:

1. все частные производные порядков $`0,\ldots,s-2`$ дифференцируемы в некоторой окрестности $`a`$;
2. все частные производные порядка $`s-1`$ дифференцируемы в точке $`a`$.

На [открытом множестве](11-topology-rn-5-3.md#def-5-3-1) условие требуется в каждой точке. Бесконечная дифференцируемость означает выполнение для любого $`s`$. Класс $`C^s`$ с непрерывными частными производными до порядка $`s`$ сильнее и удобнее для вычислений.

<a id="thm-6-4-1"></a>
## Теорема 6.4.1 — равенство смешанных производных

Достаточные условия симметрии:

1. если $`f_{xy}`$ и $`f_{yx}`$ существуют в окрестности $`a`$ и хотя бы одна из них непрерывна в $`a`$, то $`f_{xy}(a)=f_{yx}(a)`$;
2. в частности, равенство верно для $`f\in C^2`$;
3. если $`f`$ дважды дифференцируема в смысле [определения 6.4.2](#def-6-4-2), вторая дифференциальная форма также симметрична.

**Доказательство через двойное приращение.** Для $`a=(x_0,y_0)`$ рассмотрим

```math
\Delta=f(x_0+h,y_0+k)-f(x_0+h,y_0)-f(x_0,y_0+k)+f(x_0,y_0).
```

Двукратное применение теоремы Лагранжа в одном порядке даёт $`\Delta/(hk)=f_{xy}(\xi,\eta)`$, в другом — $`f_{yx}(\xi',\eta')`$. Непрерывность одной производной позволяет перейти к пределу; единственность предела даёт равенство.

**Контрпример без регулярности.** Для

```math
f(x,y)=
\begin{cases}
\dfrac{xy(x^2-y^2)}{x^2+y^2},&(x,y)\ne0,\\
0,&(x,y)=0
\end{cases}
```

получаем $`f_x(0,y)=-y`$, $`f_y(x,0)=x`$, поэтому

```math
f_{xy}(0,0)=-1,\qquad f_{yx}(0,0)=1.
```

Смешанные производные существуют, но не равны; условия теоремы нарушены.

<a id="def-6-4-3"></a>
## Определение 6.4.3 — дифференциалы высших порядков

Положим $`d_a^0f(h)=f(a)`$. Если $`d^{s-1}f(h)`$ как функция точки дифференцируемо в $`a`$, то рекурсивно

```math
d_a^s f(h)=d_a\bigl(d^{s-1}f(h)\bigr)(h).
```

Здесь $`h`$ фиксируется при внешнем дифференцировании и затем подставляется в линейный оператор. Для $`s=1`$ получается обычный $`d_af(h)`$.

Для скалярной $`f\in C^2`$:

```math
d_a^2f(h)=\sum_{i,j=1}^n f_{x_ix_j}(a)h_ih_j.
```

При $`n=2`$ и равенстве [смешанных производных](#thm-6-4-1):

```math
d^2f=f_{xx}h_1^2+2f_{xy}h_1h_2+f_{yy}h_2^2.
```

<a id="thm-6-4-2"></a>
## Теорема 6.4.2 — вычисление высших дифференциалов

Если $`f`$ $`s`$ раз дифференцируема в $`a`$, то

```math
d_a^s f(h)=
\sum_{i_1,\ldots,i_s=1}^{n}
\frac{\partial^s f(a)}{\partial x_{i_1}\cdots\partial x_{i_s}}
h_{i_1}\cdots h_{i_s}.
```

В мультииндексной форме при $`|\alpha|=s`$:

```math
d_a^s f(h)=\sum_{|\alpha|=s}
\frac{s!}{\alpha!}\,\partial^\alpha f(a)h^\alpha,
```

где $`\alpha!=\alpha_1!\cdots\alpha_n!`$ и $`h^\alpha=h_1^{\alpha_1}\cdots h_n^{\alpha_n}`$. Множитель $`h^\alpha`$ существенен; в исходной транскрипции второй формулы он опущен типографски.

**Доказательство.** [Индукция](../01-logic-sets-functions.md#example-induction) по $`s`$: дифференцирование суммы порядка $`s-1`$ добавляет один частный производный и один множитель $`h_i`$. Коэффициент $`s!/\alpha!`$ считает перестановки индексов, дающие один мультичлен.

## Связь с формулой Тейлора

При достаточной гладкости

```math
f(a+h)=f(a)+\sum_{k=1}^{s}\frac1{k!}d_a^kf(h)+o(\|h\|^s).
```

Для $`s=2`$ получаем $`f(a)+\nabla f(a)\cdot h+\frac12h^THf(a)h+o(\|h\|^2)`$, где $`Hf`$ — [гессиан](../15-multivariable-differentiation.md#sec-15-4).

## Практика в стиле задачников

1. Для $`f=x^2e^y`$ в $`(1,0)`$: $`f_{xx}=2`$, $`f_{xy}=f_{yx}=2`$, $`f_{yy}=1`$; $`d^2f(h,k)=2h^2+4hk+k^2`$.
2. Для $`f=x^3y^2`$ вычислите $`\partial^5f/(\partial x^3\partial y^2)=3!\,2!=12`$; остальные чистые пятые производные равны нулю.
3. Для $`f\in C^2`$ докажите симметричность гессиана через [теорему 6.4.1](#thm-6-4-1) и запишите $`d^2f`$ как квадратичную форму.
4. Проверьте контрпример $`xy(x^2-y^2)/(x^2+y^2)`$ по определениям, не используя формулы для гладких функций вне нуля в самой точке нуля.

Примеры оригинальные, по типам задач Зорича и стандартных упражнений на смешанные производные.

# §4.3 Свойства интеграла Римана

[← §4.2](03-riemann-integral-4-2.md) · [Лекционный указатель](index.md) · [Термины](terms.md) · [Билеты 21–23](../exam/index.md) · [§4.4 →](05-taylor-wallis-inequalities-4-4.md)

> **Первичный источник нумерации:** лекции 43–46. В источнике после [теоремы 4.3.3](#thm-4-3-3) следует [теорема 4.3.5](#thm-4-3-5); номер 4.3.4 здесь не выдумывается и не переназначается.

## Ненумерованные свойства из лекций

Для $`f,g\in\mathcal R[a,b]`$:

```math
\int_a^b(\alpha f+\beta g)=\alpha\int_a^b f+\beta\int_a^b g,
\qquad
\int_a^b f=\int_a^c f+\int_c^b f.
```

Если $`f\le g`$, то $`\int_a^b f\le\int_a^b g`$; если $`m\le f\le M`$, то

```math
m(b-a)\le\int_a^b f\le M(b-a),
\qquad
\left|\int_a^b f\right|\le\int_a^b|f|.
```

По соглашению $`\int_a^a f=0`$ и $`\int_b^a f=-\int_a^b f`$. Все формулы доказываются предельным переходом в [суммах Римана](03-riemann-integral-4-2.md#def-4-2-4).

## Теорема Барроу — производная интеграла по верхнему пределу

Если $`f`$ [непрерывна в точке](../lectures-2025-26/lecture-16.md#def-2-5-1) $`x`$, а $`F(x)=\int_a^x f(t)\,dt`$, то $`F'(x)=f(x)`$.

**Доказательство.**

```math
\frac{F(x+h)-F(x)}h=\frac1h\int_x^{x+h}f(t)\,dt.
```

Непрерывность даёт $`f(t)=f(x)+o(1)`$ при $`t\to x`$, поэтому правая часть равна $`f(x)+o(1)`$. При $`h<0`$ используется та же ориентированная запись.

<a id="thm-4-3-1"></a>
## Теорема 4.3.1 — первая теорема о среднем с весом

Пусть $`f,g\in\mathcal R[a,b]`$, $`g`$ сохраняет знак и $`m\le f\le M`$. Тогда существует $`\mu\in[m,M]`$ такое, что

```math
\int_a^b fg=\mu\int_a^b g.
```

**Доказательство для $`g\ge0`$.** Умножение $`m\le f\le M`$ на $`g`$ и интегрирование дают

```math
m\int g\le\int fg\le M\int g.
```

Если $`\int g=0`$, любое $`\mu`$ подходит; иначе положим $`\mu=\int fg/\int g`$.

<a id="cor-4-3-1"></a>
## Следствие 4.3.1 — непрерывная функция и вес

Если $`f\in C[a,b]`$ и $`g`$ интегрируема и сохраняет знак, то найдётся $`c\in[a,b]`$ с

```math
\int_a^b fg=f(c)\int_a^b g.
```

Число $`\mu`$ из [теоремы 4.3.1](#thm-4-3-1) лежит между минимумом и максимумом $`f`$; [теорема о промежуточном значении](../lectures-2025-26/lecture-17-18.md#thm-2-5-5) даёт точку $`c`$.

<a id="cor-4-3-2"></a>
## Следствие 4.3.2 — среднее без веса

Для $`f\in\mathcal R[a,b]`$ существует $`\mu\in[m,M]`$ с

```math
\int_a^b f=\mu(b-a),
\qquad
\mu=\frac1{b-a}\int_a^b f.
```

Здесь $`\mu`$ не обязано быть значением функции: разрывная функция может «перепрыгнуть» своё среднее.

<a id="cor-4-3-3"></a>
## Следствие 4.3.3 — среднее как значение непрерывной функции

Если $`f\in C[a,b]`$, то существует $`c\in[a,b]`$:

```math
\int_a^b f=f(c)(b-a).
```

Геометрически площадь подграфика равна площади прямоугольника с основанием $`b-a`$ и высотой $`f(c)`$.

<a id="thm-4-3-2"></a>
## Теорема 4.3.2 — формула Ньютона–Лейбница

Если $`F`$ — [первообразная](02-antiderivatives-4-1.md#def-4-1-1) $`f`$ на $`[a,b]`$ и $`f\in\mathcal R[a,b]`$, то

```math
\int_a^b f(x)\,dx=F(b)-F(a).
```

**Доказательство.** Для [разбиения](03-riemann-integral-4-2.md#def-4-2-2) по [теореме Лагранжа](../lectures-2025-26/lecture-24-25-26.md#thm-3-4-3) выберем $`\xi_k`$ с $`F(x_{k+1})-F(x_k)=f(\xi_k)\Delta x_k`$. Тогда соответствующая сумма Римана телескопируется в $`F(b)-F(a)`$. При измельчении она стремится к интегралу.

Нельзя применять формулу через разрыв, где $`F`$ не является первообразной: $`\int_{-1}^1x^{-2}\,dx`$ не равен $`[-1/x]_{-1}^1`$; сам [несобственный интеграл](06-improper-integrals-4-5.md#def-4-5-2) расходится.

<a id="thm-4-3-3"></a>
## Теорема 4.3.3 — интегрирование по частям

Если $`f,g`$ [дифференцируемы](../lectures-2025-26/lecture-22-23.md#def-3-2-1) и $`f',g'\in\mathcal R[a,b]`$, то

```math
\int_a^b f g'=[fg]_a^b-\int_a^b f'g.
```

**Доказательство.** Интегрируем $`(fg)'=f'g+fg'`$ и применяем [теорему 4.3.2](#thm-4-3-2). Существование всех интегралов обеспечено условиями и [теоремой 4.2.6](03-riemann-integral-4-2.md#thm-4-2-6).

**Пример.** $`\int_0^\pi x\sin x\,dx=[-x\cos x]_0^\pi+\int_0^\pi\cos x\,dx=\pi`$.

<a id="thm-4-3-5"></a>
## Теорема 4.3.5 — замена переменной в определённом интеграле

Пусть $`\varphi:[\alpha,\beta]\to[A,B]`$ дифференцируема, $`\varphi'\in\mathcal R[\alpha,\beta]`$, а $`f\in C[A,B]`$. Тогда

```math
\int_\alpha^\beta f(\varphi(x))\varphi'(x)\,dx
=\int_{\varphi(\alpha)}^{\varphi(\beta)}f(t)\,dt.
```

**Доказательство.** Если $`F'=f`$, то $`(F\circ\varphi)'=(f\circ\varphi)\varphi'`$. Остаётся применить [формулу Ньютона–Лейбница](#thm-4-3-2) к обеим сторонам.

**Пример.** Для $`t=1+x^2`$:

```math
\int_0^1\frac{x}{1+x^2}\,dx
=\frac12\int_1^2\frac{dt}{t}=\frac12\log2.
```

## Практика в стиле задачников

1. Среднее $`f(x)=x^2`$ на $`[0,1]`$ равно $`1/3`$; по [следствию 4.3.3](#cor-4-3-3) существует $`c`$ с $`c^2=1/3`$, и здесь $`c=1/\sqrt3`$.
2. $`\int_0^1xe^x\,dx=[xe^x-e^x]_0^1=1`$.
3. $`\int_0^{\sqrt\pi}x\sin(x^2)\,dx=\frac12[-\cos(x^2)]_0^{\sqrt\pi}=1`$.
4. Для $`f=1`$ при $`x<1`$ и $`f=3`$ при $`x\ge1`$ на $`[0,2]`$ среднее равно $`2`$, но значения $`2`$ функция не принимает; применимо [следствие 4.3.2](#cor-4-3-2), не 4.3.3.

Примеры оригинальные, по типам вычислительных задач Демидовича и теоретических упражнений Фихтенгольца.

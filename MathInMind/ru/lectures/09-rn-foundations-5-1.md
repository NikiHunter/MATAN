# §5.1 Функции многих переменных: основные определения

[← §4.7](08-integral-applications-4-7.md) · [Лекционный указатель](index.md) · [Термины](terms.md) · [Билет 41](../exam/tickets/41.md) · [§5.2 →](10-vector-sequences-5-2.md)

<a id="def-5-1-1"></a>
## Определение 5.1.1 — евклидова норма

Для $`x=(x_1,\ldots,x_n)\in\mathbb R^n`$:

```math
\|x\|=\sqrt{\sum_{k=1}^{n}x_k^2}.
```

Расстояние между $`x,y`$ равно $`\|x-y\|`$. [Норма](../14-several-variables.md#sec-14-1) обладает свойствами:

```math
\|x\|\ge0,\quad \|x\|=0\iff x=0,
```
```math
\|\lambda x\|=|\lambda|\,\|x\|,
\qquad
\|x+y\|\le\|x\|+\|y\|.
```

Последнее следует из [неравенства Коши–Буняковского](05-taylor-wallis-inequalities-4-4.md#thm-4-4-6)

```math
|x\cdot y|\le\|x\|\,\|y\|,
\qquad x\cdot y=\sum_{k=1}^nx_ky_k.
```

**Пример.** Для $`x=(3,4)`$ норма равна $`5`$; для $`x=(1,1,\ldots,1)`$ в $`\mathbb R^n`$ — $`\sqrt n`$.

<a id="def-5-1-2"></a>
## Определение 5.1.2 — окрестности конечной и бесконечно удалённой точек

Для $`a\in\mathbb R^n`$ и $`\delta>0`$:

```math
V_\delta(a)=\{x:\|x-a\|<\delta\},
\qquad
\dot V_\delta(a)=V_\delta(a)\setminus\{a\}.
```

Это [открытый шар](11-topology-rn-5-3.md#def-5-3-1) и проколотый шар. Для бесконечно удалённой точки:

```math
V_\delta(\infty)=\{x:\|x\|>\delta\}=\dot V_\delta(\infty).
```

При $`n=1`$ получается интервал, при $`n=2`$ — круг, при $`n=3`$ — шар. Пересечение двух окрестностей конечной точки имеет радиус $`\min(\delta_1,\delta_2)`$, а бесконечной — $`\max(\delta_1,\delta_2)`$.

## Ненумерованные операции из лекции

Для $`x,y\in\mathbb R^n`$ операции выполняются покоординатно: $`x+y`$ и $`\lambda x`$. Для отображений $`f,g:E\to\mathbb R^m`$ аналогично определяются $`f+g`$, $`\lambda f`$ и [скалярное произведение](../21-lp-spaces.md#sec-21-4)

```math
(f\cdot g)(x)=\sum_{k=1}^m f_k(x)g_k(x).
```

Функция многих переменных — это $`f:E\to\mathbb R`$; векторное отображение — $`f:E\to\mathbb R^m`$. График скалярной функции двух переменных лежит в $`\mathbb R^3`$, а линия уровня задаётся $`f(x,y)=C`$.

## Практика в стиле задачников

1. Докажите $`\bigl|\|x\|-\|y\|\bigr|\le\|x-y\|`$: примените неравенство треугольника к $`x=(x-y)+y`$ и затем поменяйте $`x,y`$ местами.
2. Для $`a=(1,2)`$ и $`\delta=3`$ окрестность $`V_\delta(a)`$ — круг $`(x-1)^2+(y-2)^2<9`$; граничная окружность не входит.
3. Для $`x^k=(1/k,1+1/k)`$ получим $`\|x^k-(0,1)\|=\sqrt2/k\to0`$.
4. $`V_5(\infty)`$ — внешность шара радиуса $`5`$: $`\|x\|>5`$, а не $`\|x\|<5`$.

Примеры оригинальные, по типам начальных задач на векторы и окрестности из задачников по многомерному анализу.

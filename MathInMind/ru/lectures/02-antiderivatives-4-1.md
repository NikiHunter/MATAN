# §4.1 Первообразная и неопределённый интеграл

[← §3.8](01-convexity-3-8.md) · [Лекционный указатель](index.md) · [Термины](terms.md) · [Билеты 8–14](../exam/index.md) · [§4.2 →](03-riemann-integral-4-2.md)

> **Первичный источник нумерации:** `МАТАН_Л/Лекция 36.md` и `МАТАН_Л/Лекция 37-38.md`. Сохранены обозначения и номера 4.1.1–4.1.6.

<a id="def-4-1-1"></a>
## Определение 4.1.1 — первообразная на промежутке

Функция $`F`$ называется первообразной $`f`$ на промежутке $`\langle A,B\rangle`$, если $`F`$ [дифференцируема](../lectures-2025-26/lecture-22-23.md#def-3-2-1) и

```math
F'(x)=f(x)
```

во всех точках промежутка. На концах используются [односторонние производные](../06-derivatives.md#sec-6-1).

Важно указывать область: $`\log x`$ — первообразная $`1/x`$ на $`(0,\infty)`$, а $`\log(-x)`$ — на $`(-\infty,0)`$. Единой формулой $`\log|x|`$ пользуются отдельно на каждом из этих промежутков.

<a id="thm-4-1-1"></a>
## Теорема 4.1.1 — описание всех первообразных

Если $`F`$ — [первообразная](#def-4-1-1) $`f`$ на промежутке, то все первообразные имеют вид

```math
F(x)+C,\qquad C\in\mathbb R,
```

и только они.

**Доказательство.** [Производная](../lectures-2025-26/lecture-22-23.md#def-3-1-1) константы равна нулю, поэтому $`F+C`$ — первообразная. Если $`G'=f`$, то $`(G-F)'=0`$; по [теореме Лагранжа](../lectures-2025-26/lecture-24-25-26.md#thm-3-4-3) $`G-F`$ постоянна на промежутке. [Связность](../13-metric-spaces.md#sec-13-5) промежутка существенна: на объединении двух интервалов константы могут быть разными.

<a id="def-4-1-2"></a>
## Определение 4.1.2 — неопределённый интеграл

Неопределённый интеграл $`\int f(x)\,dx`$ — совокупность всех первообразных $`f`$ на заданном промежутке. Поэтому пишут $`F(x)+C`$, а не одну «случайную» функцию.

Символ $`\int`$ здесь не обозначает площадь; это операция обращения дифференцирования. [Определённый интеграл](03-riemann-integral-4-2.md#def-4-2-6) появляется только в §4.2.

<a id="thm-4-1-2"></a>
## Теорема 4.1.2 — существование первообразной у непрерывной функции

Непрерывная на промежутке функция имеет первообразную.

**Доказательство.** Для отрезка $`[a,b]`$ положим

```math
F(x)=\int_a^x f(t)\,dt.
```

По теореме Барроу $`F'(x)=f(x)`$. Для произвольного промежутка выбирают [внутреннюю точку](11-topology-rn-5-3.md#def-5-3-3) и применяют ту же конструкцию с ориентированным интегралом.

Непрерывность достаточна, но не необходима: производная может быть разрывной, однако обязана обладать [свойством Дарбу](../lectures-2025-26/lecture-31-32.md#thm-3-7-6). Функция со скачком не может быть производной на промежутке, содержащем скачок.

<a id="def-4-1-3"></a>
## Определение 4.1.3 — первообразная на множестве

Для $`E\subseteq\mathbb R`$ функция $`F`$ называется первообразной $`f`$ на $`E`$, если $`F`$ дифференцируема на $`E`$ и $`F'=f`$ во всех точках $`E`$. Дифференцируемость на произвольном множестве понимается в смысле, принятом в лекции; на экзамене прежде всего уточняйте структуру $`E`$.

На несвязном $`E`$ [теорема 4.1.1](#thm-4-1-1) о единой константе не применяется: на каждой компоненте константа своя.

<a id="thm-4-1-3"></a>
## Теорема 4.1.3 — линейность

Если $`f,g`$ имеют первообразные, то для $`\alpha,\beta\in\mathbb R`$

```math
\int(\alpha f+\beta g)\,dx
=\alpha\int f\,dx+\beta\int g\,dx.
```

**Доказательство.** Если $`F'=f`$, $`G'=g`$, то $`(\alpha F+\beta G)'=\alpha f+\beta g`$. Равенство понимается как равенство семейств функций с точностью до константы; ограничение $`\alpha,\beta\ne0`$ в отдельных слайдах не требуется.

<a id="thm-4-1-4"></a>
## Теорема 4.1.4 — замена переменной

Если $`F'=f`$ и $`\varphi`$ дифференцируема, то

```math
\int f(\varphi(x))\varphi'(x)\,dx=F(\varphi(x))+C.
```

**Доказательство.** По цепному правилу $`(F\circ\varphi)'=(f\circ\varphi)\varphi'`$.

**Пример.**

```math
\int 2x\cos(x^2)\,dx=\sin(x^2)+C,
\qquad \varphi(x)=x^2.
```

<a id="thm-4-1-5"></a>
## Теорема 4.1.5 — интегрирование по частям

Для $`f,g\in C^1`$:

```math
\int f g'\,dx=fg-\int f'g\,dx.
```

Это следует из $`(fg)'=f'g+fg'`$. Равенство снова понимается с точностью до аддитивной константы.

**Пример.**

```math
\int x e^x\,dx=xe^x-\int e^x\,dx=(x-1)e^x+C.
```

<a id="thm-4-1-6"></a>
## Теорема 4.1.6 — интегрирование рациональных функций

Каждая рациональная функция имеет элементарную первообразную на любом промежутке, где её знаменатель не обращается в ноль.

**Схема доказательства.**

1. Делением многочленов выделить целую часть.
2. Разложить правильную дробь на простейшие над $`\mathbb R`$: множители $`x-a`$ и неразложимые $`x^2+px+q`$.
3. Интегрирование даёт многочлены, логарифмы, арктангенсы и рациональные слагаемые.

**Пример.**

```math
\frac1{x(x+1)}=\frac1x-\frac1{x+1}
\implies
\int\frac{dx}{x(x+1)}=\log\left|\frac{x}{x+1}\right|+C
```

на промежутке, не содержащем $`0`$ и $`-1`$.

## Практика в стиле задачников

1. $`\int(3x^2-2x+1)\,dx=x^3-x^2+x+C`$; проверка — дифференцирование.
2. $`\int x/(1+x^2)\,dx=\frac12\log(1+x^2)+C`$.
3. $`\int\log x\,dx=x\log x-x+C`$ на $`(0,\infty)`$: возьмите $`f=\log x`$, $`g'=1`$.
4. Для $`\int dx/(x^2+1)`$ на всём $`\mathbb R`$ получаем $`\arctan x+C`$; для $`\int dx/(1-x^2)`$ область должна исключать $`x=\pm1`$.

Примеры оригинальные, составлены по стандартным типам упражнений Демидовича, Фихтенгольца и Зорича; номера задач не выдумываются.

# §5.3 Открытые, замкнутые и компактные множества

[← §5.2](10-vector-sequences-5-2.md) · [Лекционный указатель](index.md) · [Термины](terms.md) · [Билеты 47–51](../exam/index.md) · [§5.4 →](12-mapping-limits-5-4.md)

> **Первичный источник нумерации:** лекции 55–58. Сохранены [определения 5.3.1](#def-5-3-1)–[5.3.7](#def-5-3-7) и [теоремы 5.3.1](#thm-5-3-1)–[5.3.5](#thm-5-3-5).

<a id="def-5-3-1"></a>
## Определение 5.3.1 — внутренняя точка, открытое и замкнутое множества

$`a\in E`$ внутренняя, если $`V_\delta(a)\subseteq E`$ для некоторого $`\delta>0`$. Множество $`E`$ открыто, если все его точки внутренние; замкнуто, если $`\mathbb R^n\setminus E`$ открыто.

Открытый шар открыт, закрытый шар замкнут. $`\varnothing`$ и $`\mathbb R^n`$ одновременно открыты и замкнуты. Полуинтервал $`(0,1]`$ не является ни открытым, ни замкнутым в $`\mathbb R`$.

<a id="thm-5-3-1"></a>
## Теорема 5.3.1 — характеристики замкнутости

Равносильны:

1. $`E`$ замкнуто;
2. $`E`$ содержит все свои предельные точки;
3. предел любой [сходящейся последовательности](../lectures-2025-26/lecture-08.md#def-2-1-3) из $`E`$ принадлежит $`E`$.

**Доказательство.** Если $`a\notin E`$ и $`E`$ замкнуто, открытое дополнение даёт окрестность без точек $`E`$, поэтому $`a`$ не предельная. Обратно, если дополнение не открыто, существует $`a\notin E`$, каждая окрестность которого встречает $`E`$, значит $`a`$ — предельная. Последовательностная форма следует из [теоремы 5.2.6](10-vector-sequences-5-2.md#thm-5-2-6).

<a id="thm-5-3-2"></a>
## Теорема 5.3.2 — операции над множествами

Произвольные объединения открытых и произвольные пересечения замкнутых сохраняют соответствующее свойство. Конечные пересечения открытых и конечные объединения замкнутых также сохраняют его.

**Доказательство.** Для конечного пересечения открытых берётся минимум радиусов; для бесконечного пересечения минимум может быть нулевым. Утверждения для замкнутых следуют из законов де Моргана.

**Контрпример.** $`\bigcap_{k=1}^\infty(-1/k,1/k)=\{0\}`$ не открыто в $`\mathbb R`$.

<a id="def-5-3-2"></a>
## Определение 5.3.2 — замыкание

Замыкание $`\overline E`$ — наименьшее по включению [замкнутое множество](#thm-5-3-1), содержащее $`E`$:

```math
\overline E=\bigcap\{F:F\text{ замкнуто и }E\subseteq F\}.
```

Оно существует и единственно благодаря [теореме 5.3.2](#thm-5-3-2).

<a id="thm-5-3-3"></a>
## Теорема 5.3.3 — точки замыкания

Равносильны:

1. $`a\in\overline E`$;
2. $`a\in E`$ или $`a`$ — предельная точка $`E`$;
3. существует последовательность $`x^k\in E`$ с $`x^k\to a`$;
4. каждая окрестность $`a`$ пересекает $`E`$.

**Пример.** Для $`E=(0,1)\cup\{2\}`$ в $`\mathbb R`$ [замыкание](#def-5-3-2) равно $`[0,1]\cup\{2\}`$.

<a id="def-5-3-3"></a>
## Определение 5.3.3 — внутренность

$`\operatorname{Int}E`$ — множество всех внутренних точек $`E`$. Это наибольшее [открытое множество](#def-5-3-1), содержащееся в $`E`$:

```math
\operatorname{Int}E=\bigcup\{G:G\text{ открыто и }G\subseteq E\}.
```

Для $`E=[0,1]`$ внутренность в $`\mathbb R`$ равна $`(0,1)`$; для $`\mathbb Q`$ внутренность пуста.

<a id="def-5-3-4"></a>
## Определение 5.3.4 — граница

```math
\partial E=\overline E\setminus\operatorname{Int}E.
```

Граница замкнута, поскольку $`\overline E`$ замкнуто, а $`\operatorname{Int}E`$ открыто. Для шара $`V_r(a)`$ граница — сфера $`\{x:\|x-a\|=r\}`$. Для $`\mathbb Q`$ в $`\mathbb R`$ граница равна всему $`\mathbb R`$.

<a id="def-5-3-5"></a>
## Определение 5.3.5 — открытые и замкнутые подмножества в $`E`$

Для $`F\subseteq E`$ множество $`F`$ открыто **в относительной топологии** $`E`$, если у каждой $`a\in F`$ есть $`\delta`$ с

```math
V_\delta(a)\cap E\subseteq F.
```

$`F`$ замкнуто в $`E`$, если $`E\setminus F`$ открыто в $`E`$. Открытость в $`E`$ не обязана означать открытость в $`\mathbb R^n`$: $`[0,1/2)`$ открыто в $`E=[0,1]`$, но не в $`\mathbb R`$.

<a id="thm-5-3-4"></a>
## Теорема 5.3.4 — описание относительно открытых множеств

$`F`$ открыто в $`E`$ тогда и только тогда, когда существует открытое $`G\subseteq\mathbb R^n`$ с

```math
F=E\cap G.
```

**Доказательство.** Для каждой $`a\in F`$ выберите шар $`G_a`$ с $`G_a\cap E\subseteq F`$ и положите $`G=\bigcup_aG_a`$. Обратно, открытость $`G`$ позволяет выбрать шар внутри $`G`$, пересечение которого с $`E`$ остаётся в $`F`$.

<a id="def-5-3-6"></a>
## Определение 5.3.6 — покрытие и подпокрытие

Семейство $`\Omega`$ покрывает $`E`$, если $`E\subseteq\bigcup_{A\in\Omega}A`$. Подсемейство $`\widetilde\Omega\subseteq\Omega`$, также покрывающее $`E`$, называется подпокрытием. [Открытое покрытие](#def-5-3-7) состоит из открытых множеств.

<a id="def-5-3-7"></a>
## Определение 5.3.7 — компакт

$`E`$ компактно, если из **каждого** открытого покрытия можно выбрать конечное подпокрытие.

Нельзя проверять только одно удобное покрытие: у любого множества есть покрытие одним множеством $`\mathbb R^n`$.

<a id="thm-5-3-5"></a>
## Теорема 5.3.5 — критерии компактности в $`\mathbb R^n`$

Для $`E\subseteq\mathbb R^n`$ равносильны:

1. $`E`$ компактно;
2. $`E`$ замкнуто и ограничено (Гейне–Борель);
3. любая последовательность из $`E`$ имеет [подпоследовательность](../lectures-2025-26/lecture-11-12.md#def-2-3-7), сходящуюся в $`E`$.

**Идея доказательства.** Компактность даёт ограниченность через покрытие шарами $`V_k(0)`$ и замкнутость через отделение внешней точки малыми шарами. Замкнутость и ограниченность дают последовательностную компактность по Больцано–Вейерштрассу. Из последовательностной компактности выводят конечную $`\varepsilon`$-сеть и затем конечное подпокрытие.

**Примеры.** $`[0,1]^n`$ компактен; $`(0,1)`$ ограничен, но не замкнут; $`\mathbb Z`$ замкнут в $`\mathbb R`$, но не ограничен.

## Практика в стиле задачников

1. Для $`E=\{1/k:k\in\mathbb N\}`$ замыкание равно $`E\cup\{0\}`$; оно компактно, а исходное $`E`$ не замкнуто.
2. Для $`E=\{(x,y):x^2+y^2<1\}`$ [внутренность](#def-5-3-3) равна $`E`$, граница — единичная окружность, замыкание — единичный круг с границей.
3. Докажите компактность $`E\cup\{0\}`$ из предыдущего примера и последовательностно, и через покрытия: любой элемент покрытия, содержащий ноль, покрывает все, кроме конечного числа точек.
4. Для $`E=[0,1]`$ найдите $`G`$ такое, что $`[0,1/2)=E\cap G`$; подходит $`G=(-1,1/2)`$.

Примеры оригинальные, по типам задач на топологию $`\mathbb R^n`$ из Зорича и Рудина.

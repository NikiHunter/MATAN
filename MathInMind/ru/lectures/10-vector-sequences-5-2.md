# §5.2 Предел последовательности векторов

[Лекционный указатель](index.md) · [Термины](terms.md) · [Билеты 42–47](../exam/index.md)

> **Первичный источник нумерации:** лекции 54–56. Сохранены определения 5.2.1–5.2.3, леммы 5.2.1–5.2.2 и теоремы 5.2.1–5.2.6.

<a id="def-5-2-1"></a>
## Определение 5.2.1 — предел последовательности в $\mathbb R^n$

$x^k\to a$, если для любого $\varepsilon>0$ найдётся $N$ такое, что $k>N\implies x^k\in V_\varepsilon(a)$. Для конечного $a$ это равносильно

$$
\|x^k-a\|\to0.
$$

Для $a=\infty$ используется $V_\varepsilon(\infty)$: для любого $R$ с некоторого номера $\|x^k\|>R$.

**Пример.** $(1/k,1-1/k)\to(0,1)$, поскольку норма разности равна $\sqrt2/k$.

<a id="lem-5-2-1"></a>
## Лемма 5.2.1 — единственность предела

Последовательность не может иметь двух различных пределов.

**Доказательство.** Различные точки имеют непересекающиеся окрестности. Если $a\ne b$, возьмите $\varepsilon<\|a-b\|/2$; одна и та же подпоследовательность не может с некоторого номера лежать одновременно в $V_\varepsilon(a)$ и $V_\varepsilon(b)$.

<a id="thm-5-2-1"></a>
## Теорема 5.2.1 — покоординатная сходимость

$x^k\to a\in\mathbb R^n$ тогда и только тогда, когда $x_i^k\to a_i$ для каждой координаты $i$.

**Доказательство.** Используются оценки

$$
|x_i^k-a_i|\le\|x^k-a\|
\le\sum_{i=1}^n|x_i^k-a_i|.
$$

Первая даёт необходимость, вторая — достаточность.

**Предупреждение.** Для предела функции двух переменных существование пределов по координатным осям не равносильно совместному пределу; теорема относится именно к векторным последовательностям.

<a id="thm-5-2-2"></a>
## Теорема 5.2.2 — арифметика пределов

Если $x^k\to a$, $y^k\to b$, $\lambda_k\to\lambda$, то

$$
x^k+y^k\to a+b,
\qquad
\lambda_kx^k\to\lambda a,
\qquad
x^k\cdot y^k\to a\cdot b.
$$

Для скалярных $z^k\to c\ne0$ также $1/z^k\to1/c$. Доказательство проводится покоординатно или оценками нормы, например

$$
\|\lambda_kx^k-\lambda a\|
\le|\lambda_k|\,\|x^k-a\|+|\lambda_k-\lambda|\,\|a\|.
$$

<a id="thm-5-2-3"></a>
## Теорема 5.2.3 — предел подпоследовательности

Любая подпоследовательность сходящейся последовательности сходится к тому же пределу.

**Доказательство.** Если $k_i\to\infty$, то для каждого $N$ найдётся $I$ с $k_i>N$ при $i>I$. Остаётся применить определение предела исходной последовательности.

Обратное без дополнительных условий неверно: $(-1)^k$ имеет сходящиеся чётную и нечётную подпоследовательности, но сама расходится. Если все подпоследовательности имеют один предел, сходится и исходная.

<a id="def-5-2-2"></a>
## Определение 5.2.2 — ограниченное множество и отображение

$E\subseteq\mathbb R^n$ ограничено, если существует $C$ с $E\subset V_C(0)$. Отображение $f:E\to\mathbb R^m$ ограничено, если ограничен образ $f(E)$.

Для последовательности это означает $\sup_k\|x^k\|<\infty$, а для скалярной функции — существование $M$ с $|f(x)|\le M$.

<a id="lem-5-2-2"></a>
## Лемма 5.2.2 — сходящаяся последовательность ограничена

Если $x^k\to a$, то при $\varepsilon=1$ с некоторого $N$ имеем $\|x^k\|<\|a\|+1$. Конечное число оставшихся членов также ограничено; максимум этих констант даёт общую границу.

<a id="thm-5-2-4"></a>
## Теорема 5.2.4 — Больцано–Вейерштрасс и неограниченный случай

1. Из любой ограниченной последовательности в $\mathbb R^n$ можно выделить сходящуюся подпоследовательность.
2. Из неограниченной последовательности можно выделить подпоследовательность с $\|x^{k_i}\|\to\infty$.

**Доказательство.** В первом случае выделяют сходящуюся подпоследовательность первой координаты, затем из неё — второй и так далее до $n$. Во втором для каждого $i$ выбирают индекс с $\|x^{k_i}\|>i$, обеспечивая строгое возрастание индексов.

<a id="thm-5-2-5"></a>
## Теорема 5.2.5 — критерий Больцано–Коши

Последовательность сходится в $\mathbb R^n$ тогда и только тогда, когда она фундаментальна:

$$
\forall\varepsilon>0\;\exists N:\quad k,m>N\implies\|x^k-x^m\|<\varepsilon.
$$

**Доказательство.** Необходимость следует из $\|x^k-x^m\|\le\|x^k-a\|+\|x^m-a\|$. Для достаточности фундаментальность даёт ограниченность; по теореме 5.2.4 есть сходящаяся подпоследовательность, а условие Коши заставляет всю последовательность приближаться к её пределу.

<a id="def-5-2-3"></a>
## Определение 5.2.3 — предельная и изолированная точки

$a$ — предельная точка $E$, если для любого $\varepsilon>0$

$$
E\cap\dot V_\varepsilon(a)\ne\varnothing.
$$

Точка $a\in E$ изолирована, если она не предельная, то есть существует окрестность с $E\cap V_\varepsilon(a)=\{a\}$. Предельная точка не обязана принадлежать $E$: ноль предельный для $\{1/k\}$, но не входит в него.

<a id="thm-5-2-6"></a>
## Теорема 5.2.6 — последовательностный критерий предельной точки

$a$ предельная для $E$ тогда и только тогда, когда существует последовательность $x^k\in E\setminus\{a\}$ с $x^k\to a$.

**Доказательство.** Для необходимости выберите $x^k\in E\cap\dot V_{1/k}(a)$. Для достаточности любая проколотая окрестность содержит все члены такой последовательности с некоторого номера.

## Практика в стиле задачников

1. Для $x^k=(k/(k+1),\sin(1/k))$ координатные пределы дают $(1,0)$.
2. Для $x^k=((-1)^k,1/k)$ первая координата мешает сходимости, но последовательность ограничена; сходящаяся подпоследовательность — чётные индексы.
3. Для $E=(0,1]\cup\{2\}$ ноль предельный, но не принадлежит $E$; $2$ изолированная точка.
4. Проверьте фундаментальность $x^k=(1/k,1/k^2)$ непосредственно: $\|x^k-x^m\|\le2/\min(k,m)$ по норме $\|\cdot\|_1$, эквивалентной евклидовой.

Примеры оригинальные, по типам задач на векторные пределы и топологию из курсов Зорича и Фихтенгольца.

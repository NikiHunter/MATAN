## Печатный слайд 5 (стр. PDF 5) — Основные определения

Рассматриваются отображения $`f:E\subset\mathbb R^n\to\mathbb R^m`$. При $`m=1`$ это функция $`n`$ вещественных переменных; координаты вектора обозначаются нижними индексами.


```math
f:E\subset\mathbb R^n\to\mathbb R^m
```


```math
x=(x_1,\ldots,x_n)
```

## Печатный слайд 6 (стр. PDF 6) — Евклидова норма

<a id="def-5-1-1"></a>**Определение 5.1.1.** Евклидова норма вектора — квадратный корень из суммы квадратов координат. При $`n=1`$ это модуль, при $`n=2,3`$ — обычная длина.


```math
\|x\|=\sqrt{\sum_{k=1}^{n}x_k^2}
```

## Печатный слайд 7 (стр. PDF 7) — Аксиомы нормы

[Норма](../14-several-variables.md#sec-14-1) неотрицательна и равна нулю только на нулевом векторе; однородна относительно умножения на число; удовлетворяет неравенству треугольника.


```math
\|x\|\ge0
```


```math
\|\lambda x\|=|\lambda|\,\|x\|
```


```math
\|x+y\|\le\|x\|+\|y\|
```

## Рукописная страница (стр. PDF 8) — Евклидова норма: рукописные свойства

Cauchy–Schwarz выводится из неотрицательности квадратичного многочлена $`\|x-ty\|^2`$. Из определения нормы следуют $`|x_k|\le\|x\|`$ и оценка сверху через максимум модулей координат; размерность обозначаем $`n`$.

## Печатный слайд 8 (стр. PDF 9) — Другие свойства нормы

Обратное неравенство треугольника связывает разность норм с нормой разности. Неравенство Коши ограничивает [скалярное произведение](../21-lp-spaces.md#sec-21-4); отдельная координата не превосходит евклидову норму.


```math
\|x-y\|\ge|\|x\|-\|y\||
```


```math
|x\cdot y|\le\|x\|\,\|y\|
```

## Печатный слайд 9 (стр. PDF 10) — Окрестности точек в $`\mathbb R^n`$

В многомерном анализе вводятся аналоги окрестностей и [проколотых окрестностей](lecture-14.md#def-2-4-2) вещественной прямой. Рукописные пометки уточняют бесконечно удалённые символы.


![Окрестности точек в $\mathbb R^n$ (стр. PDF 10)](../../assets/lectures-2025-26/lec54-p10-neighborhoods-infinity.jpg)

## Печатный слайд 10 (стр. PDF 11) — Окрестности и бесконечно удалённая точка

<a id="def-5-1-2"></a>**Определение 5.1.2.** Окрестность точки — открытый шар радиуса $`\delta`$ в евклидовой норме; проколотая окрестность исключает саму точку. Окрестность бесконечно удалённой точки состоит из векторов нормы больше $`\delta`$.


```math
V_\delta(a)=\{x\in\mathbb R^n:\|x-a\|<\delta\}
```


```math
\dot V_\delta(a)=V_\delta(a)\setminus\{a\}
```


```math
V_\delta(\infty)=\{x\in\mathbb R^n:\|x\|>\delta\}
```

## Печатный слайд 11 (стр. PDF 12) — Геометрический смысл окрестностей

В $`\mathbb R`$, $`\mathbb R^2`$ и $`\mathbb R^3`$ это интервал, круг и шар. На рукописной помете для $`n\ge2`$ отмечено, что $`+\infty`$ и $`-\infty`$ не различаются в многомерном пространстве.


```math
V_\delta(a)=(a-\delta,a+\delta)
```

## Печатный слайд 12 (стр. PDF 13) — Пересечение окрестностей

Пересечение окрестностей одной точки снова является окрестностью; для двух различных конечных точек можно выбрать непересекающиеся окрестности.


```math
V_{\delta_1}(a)\cap V_{\delta_2}(a)=V_{\min(\delta_1,\delta_2)}(a)
```

## Печатный слайд 13 (стр. PDF 14) — Операции над векторами

Сложение и умножение на скаляр выполняются покоординатно; скалярное произведение — сумма произведений соответствующих координат.


```math
x+y=(x_1+y_1,\ldots,x_n+y_n)
```


```math
\lambda x=(\lambda x_1,\ldots,\lambda x_n)
```


```math
x\cdot y=\sum_{i=1}^{n}x_iy_i
```

## Печатный слайд 14 (стр. PDF 15) — Операции над отображениями

Векторные операции применяются поточечно к отображениям со значениями в $`\mathbb R^m`$; скалярное произведение отображений суммирует произведения компонент.


```math
(f\cdot g)(x)=\sum_{k=1}^{m}f_k(x)g_k(x)
```

## Печатный слайд 15 (стр. PDF 16) — §2. Предел последовательности векторов

<a id="def-5-2-1"></a>**Определение 5.2.1.** Последовательность векторов сходится к $`a`$, если для каждого $`\varepsilon>0`$ все достаточно поздние члены лежат в $`\varepsilon`$-окрестности $`a`$.


```math
\forall\varepsilon>0\ \exists N\ \forall k>N:\ x_k\in V_\varepsilon(a)
```


```math
\lim_{k\to\infty}x_k=a
```

## Печатный слайд 16 (стр. PDF 17) — Эквивалентные определения предела

Сходимость к конечному вектору эквивалентна стремлению нормы разности к нулю; уход нормы в бесконечность задаёт предел $`\infty`$.


```math
\|x_k-a\|<\varepsilon
```


```math
\lim_{k\to\infty}\|x_k-a\|=0
```


```math
\lim_{k\to\infty}\|x_k\|=+\infty
```

## Печатный слайд 17 (стр. PDF 18) — Единственность предела

<a id="lem-5-2-1"></a>**Лемма 5.2.1.** Если последовательность имеет пределы $`a`$ и $`b`$, то $`a=b`$. Также из сходимости к $`a`$ следует сходимость норм к $`\|a\|`$ по обратному неравенству треугольника.


```math
|\|x_k\|-\|a\||\le\|x_k-a\|
```

## Рукописная страница (стр. PDF 19) — Единственность предела: доказательство

Предположим, $`a\ne b`$. Выбираются непересекающиеся окрестности точек $`a`$ и $`b`$. Если последовательность сходится к обеим точкам, все достаточно поздние члены должны принадлежать пересечению этих окрестностей; оно пусто. Противоречие доказывает единственность.

## Печатный слайд 18 (стр. PDF 20) — Сходимость по координатам

<a id="thm-5-2-1"></a>**Теорема 5.2.1.** Последовательность в $`\mathbb R^n`$ сходится тогда и только тогда, когда сходится каждая координатная последовательность к соответствующей координате предельного вектора.


```math
|x_i^k-a_i|\le\|x^k-a\|
```

## Рукописная страница (стр. PDF 21) — Покоординатная сходимость: доказательство

Из $`\|x^k-a\|\to0`$ следует $`|x_i^k-a_i|\le\|x^k-a\|\to0`$ для каждой координаты. Обратно, если каждая из $`n`$ координат сходится, при заданном $`\varepsilon`$ выбирают общий индекс, после которого все координатные ошибки меньше $`\varepsilon/\sqrt n`$; тогда евклидова норма ошибки меньше $`\varepsilon`$.


![Покоординатная сходимость: доказательство (стр. PDF 21)](../../assets/lectures-2025-26/lec54-p21-coordinate-limit-proof.jpg)

## Печатный слайд 19 (стр. PDF 22) — Вектор может стремиться к бесконечности без пределов координат

Пример чередует направления и одновременно увеличивает длину вектора; норма стремится к бесконечности, тогда как координатные последовательности не обязаны иметь пределы.


```math
x_k=\left(k\cos\frac{\pi k}{2},k\sin\frac{\pi k}{2}\right)
```


```math
\|x_k\|=k\to+\infty
```

## Печатный слайд 20 (стр. PDF 23) — Арифметика пределов

<a id="thm-5-2-2"></a>**Теорема 5.2.2.** Предел суммы равен сумме пределов; если $`\lambda_k\to\lambda`$, то произведение скалярной последовательности на векторную имеет ожидаемый предел; предел скалярного произведения равен скалярному произведению пределов.


```math
\lim_{k\to\infty}(x_k+y_k)=a+b
```


```math
\lim_{k\to\infty}\lambda_kx_k=\lambda a
```


```math
\lim_{k\to\infty}x_k\cdot y_k=a\cdot b
```

## Рукописная страница (стр. PDF 24) — Закон суммы: доказательство

Для каждого индекса $`i`$ скалярные последовательности координат сходятся, поэтому $`x_i^k+y_i^k\to a_i+b_i`$. По [теореме 5.2.1](#thm-5-2-1) это означает $`x^k+y^k\to a+b`$ в $`\mathbb R^n`$.

## Печатный слайд 21 (стр. PDF 25) — Линейность предела последовательности

Комбинируя закон суммы и умножение на скаляр, получаем линейность предела векторной последовательности.


```math
\lim_{k\to\infty}(\lambda x_k+\mu y_k)=\lambda a+\mu b
```

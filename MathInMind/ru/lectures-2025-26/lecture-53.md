## Печатный слайд 4 (стр. PDF 4) — Длина пути и производная

Для [дифференцируемого](lecture-22-23.md#def-3-2-1) пути координатные [производные](lecture-22-23.md#def-3-1-1) образуют вектор $`\gamma'`$; его [евклидова норма](lecture-54.md#def-5-1-1) — мгновенная скорость.


```math
\|\gamma'(t)\|=\sqrt{\sum_{i=1}^{m}(\gamma_i'(t))^2}
```

## Печатный слайд 5 (стр. PDF 5) — Теорема о длине гладкого пути

<a id="thm-4-7-1"></a>**Теорема 4.7.1.** Гладкий путь спрямляем, а его длина равна интегралу нормы производной. Для кусочно-гладких путей результат следует по аддитивности. Для $`\gamma=(\varphi,\psi)`$ в плоскости подынтегральная функция — $`\sqrt{\varphi'{}^2+\psi'{}^2}`$.


```math
s_\gamma=\int_a^b\|\gamma'(t)\|\,dt
```


```math
s_\gamma=\int_a^b\sqrt{\varphi'(t)^2+\psi'(t)^2}\,dt
```

## Рукописная страница (стр. PDF 6) — Доказательство теоремы о длине: разбиение координат

Разбивают отрезок параметра на малые интервалы. Приращение пути на каждом интервале оценивается через значения координатных производных в промежуточных точках. Длина хорды даёт нижнюю оценку, а изменения координат контролируют длину дуги.

## Рукописная страница (стр. PDF 7) — Покомпонентные экстремумы

Для каждой координаты на коротком интервале берут минимум и максимум производной. Полученные векторные оценки зажимают длины хорд и дуг; одинаковый промежуточный параметр не требуется для разных координат.

## Рукописная страница (стр. PDF 8) — Оценка разности верхней и нижней сумм

Непрерывность производных на [компактном](lecture-57-58.md#def-5-3-7) отрезке обеспечивает [равномерную непрерывность](lecture-17-18.md#def-2-5-7). Поэтому на достаточно коротких интервалах разности между координатными экстремальными оценками малы.

## Рукописная страница (стр. PDF 9) — Редакторское замечание к суммам

Красной ручкой отмечено: суммы из покоординатных экстремумов сами по себе не являются автоматически [суммами Дарбу](lecture-39-40.md#def-4-2-8) для евклидовой нормы вектора производной. Этот переход требует отдельной оценки; далее разность контролируется равномерной непрерывностью компонент.

## Рукописная страница (стр. PDF 10) — Сходимость к интегралу

На коротком интервале вектор производной почти не меняется. Непрерывность евклидовой нормы позволяет заменить координатные экстремальные оценки [интегральными суммами](lecture-37-38.md#def-4-2-4) для функции скорости.

## Рукописная страница (стр. PDF 11) — Завершение доказательства

Когда диаметр [разбиения](lecture-37-38.md#def-4-2-2) стремится к нулю, верхние и нижние оценки сходятся к одному интегралу. Это отождествляет [супремум](lecture-11-12.md#def-2-3-1) длин вписанных ломаных с интегралом скорости.


![Рукописный вывод (стр. PDF 11)](../../assets/lectures-2025-26/lec53-p11-length-estimate.jpg)

## Рукописная страница (стр. PDF 12) — Предел оценок

Для любого положительного допуска равномерная непрерывность позволяет выбрать достаточно мелкое разбиение, чтобы суммарная разность верхних и нижних оценок была меньше этого допуска; так завершается доказательство формулы длины.

## Печатный слайд 6 (стр. PDF 13) — Длина графика

<a id="cor-4-7-1"></a>**Следствие 4.7.1.** График функции класса $`C^1[a,b]`$ спрямляем; его длина равна интегралу скорости параметризации $`\Gamma_f(t)=(t,f(t))`$.




```math
s_{\Gamma_f}=\int_a^b\sqrt{1+f'(t)^2}\,dt
```

```math
\Gamma_f(t)=(t,f(t))
```

## Печатный слайд 7 (стр. PDF 14) — Длина пути в полярных координатах

<a id="cor-4-7-2"></a>**Следствие 4.7.2.** При $`r=f(\theta)`$ длина кривой находится интегрированием квадратного корня из суммы квадратов радиуса и его производной.





```math
\gamma(\theta)=(f(\theta)\cos\theta,f(\theta)\sin\theta),\qquad \theta\in[\alpha,\beta]
```


```math
s_\gamma=\int_\alpha^\beta\sqrt{f(\theta)^2+f'(\theta)^2}\,d\theta
```

## Рукописная страница (стр. PDF 15) — Полярная параметризация

Пусть радиус в [полярных координатах](../17-multiple-integrals.md#sec-17-3) задаётся функцией f от угла θ на промежутке от α до β. Тогда координаты пути равны f(θ), умноженной соответственно на cos θ и sin θ. При дифференцировании возникают смешанные члены противоположных знаков.

## Рукописная страница (стр. PDF 16) — Упрощение полярной скорости

После раскрытия квадратов смешанные члены сокращаются, поскольку синус в квадрате плюс косинус в квадрате равен единице. Квадрат скорости равен сумме квадрата производной радиуса и квадрата радиуса; интегрирование даёт полярную формулу длины.

## Печатный слайд 8 (стр. PDF 17) — Работа переменной силы

Движение материальной точки идёт вдоль числовой оси. Сила $`F`$ параллельна оси; знак $`F(x)`$ задаёт направление относительно выбранной оси.


```math
F:E\subset\mathbb R\to\mathbb R
```


```math
F(x)>0
```


```math
F(x)<0
```

## Печатный слайд 9 (стр. PDF 18) — Аддитивность работы

Работа аддитивна по отрезку. Если сила заключена между $`m`$ и $`M`$, работа заключена между работами постоянных сил $`m`$ и $`M`$ на этом отрезке.


```math
m(b-a)\le A_F([a,b])\le M(b-a)
```

## Печатный слайд 10 (стр. PDF 19) — Работа при непрерывной силе

Для непрерывной силы нижние и верхние суммы Дарбу ограничивают работу. В печатных суммах на этой странице стоит $`f`$ вместо $`F`$; это исправлено редакционно.


> **Редакторское исправление.** В печатной строке PDF буква $`f`$ использована вместо уже обозначенной силы $`F`$; в определении сумм исправлено на $`F`$.


```math
m_k=\inf_{x\in[x_k,x_{k+1}]}F(x),\qquad M_k=\sup_{x\in[x_k,x_{k+1}]}F(x)
```


```math
s_\tau=\sum_{k=0}^{n-1}m_k\Delta x_k,\qquad S_\tau=\sum_{k=0}^{n-1}M_k\Delta x_k
```


```math
s_\tau\le A_F([a,b])\le S_\tau
```

## Печатный слайд 11 (стр. PDF 20) — Формула работы

Переход к интегралу даёт работу силы при перемещении от $`a`$ до $`b`$. Для произвольного направления учитывается составляющая силы вдоль движения.


```math
A_F([a,b])=\int_a^bF(x)\,dx
```

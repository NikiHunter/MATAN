## Глава 4. Интегральное исчисление, §3. Свойства интеграла Римана

### Печатный слайд 4 (стр. PDF 4). Замена переменной

<a id="thm-4-3-5"></a>**Теорема 4.3.5.** Пусть $`\varphi:[\alpha,\beta]\to[A,B]`$, функция $`\varphi`$ дифференцируема на $`[\alpha,\beta]`$, $`\varphi'\in\mathcal R[\alpha,\beta]`$, $`f\in C[A,B]`$. Тогда

```math
\int_\alpha^\beta (f\circ\varphi)(x)\varphi'(x)\,dx
=\int_{\varphi(\alpha)}^{\varphi(\beta)} f(t)\,dt.
```

### Печатный слайд 5 (стр. PDF 5). Замечания к замене переменной

1. Некоторые значения $`\varphi(t)`$ при $`t\in[\alpha,\beta]`$ могут не лежать между $`\varphi(\alpha)`$ и $`\varphi(\beta)`$. Существенно, что все значения $`\varphi(t)`$ принадлежат $`[A,B]`$, где определена $`f`$.
2. [Нижний предел](lecture-13.md#def-2-3-9) не обязан быть меньше верхнего. Если $`\varphi`$ строго убывает и $`\alpha<\beta`$, то $`\varphi(\alpha)>\varphi(\beta)`$; ориентированный интеграл учитывает это без отдельной перестановки пределов.

## §4. Формулы Тейлора и Валлиса и интегральные неравенства

### Печатный слайд 6 (стр. PDF 6). Заголовок раздела

«§4. Формулы Тейлора и Валлиса и интегральные неравенства».

### Печатный слайд 7 (стр. PDF 7). Формула Тейлора с интегральным остатком

<a id="thm-4-4-1"></a>**Теорема 4.4.1.** Пусть $`n\in\mathbb Z_+`$, $`f\in C^{n+1}\langle A,B\rangle`$, $`a,x\in\langle A,B\rangle`$. Тогда

```math
f(x)=\sum_{k=0}^{n}\frac{f^{(k)}(a)}{k!}(x-a)^k+
\frac1{n!}\int_a^x f^{(n+1)}(t)(x-t)^n\,dt.
```

### Рукописная страница (стр. PDF 8). Доказательство теоремы 4.4.1, база и переход к интегрированию по частям

На чёрной доске доказательство начинается [индукцией](../01-logic-sets-functions.md#example-induction). При $`n=0`$ по [формуле Ньютона–Лейбница](lecture-43-44.md#thm-4-3-2)

```math
f(x)=f(a)+\int_a^x f'(t)\,dt.
```

Предполагая формулу для $`n-1`$, остаточный член имеет вид

```math
\frac1{(n-1)!}\int_a^x f^{(n)}(t)(x-t)^{n-1}\,dt
=\int_a^x f^{(n)}(t)\,d\!\left(-\frac{(x-t)^n}{n!}\right).
```

К нему применяется [интегрирование по частям](lecture-37-38.md#thm-4-1-4). Страница заканчивается переходом

```math
=-\frac1{n!}\left[f^{(n)}(t)(x-t)^n\right]_{t=a}^{x}
+\frac1{n!}\int_a^x f^{(n+1)}(t)(x-t)^n\,dt.
```

### Рукописная страница (стр. PDF 9). Завершение доказательства формулы Тейлора

Граничное слагаемое упрощается так:

```math
-\frac1{n!}\left[f^{(n)}(t)(x-t)^n\right]_{a}^{x}
=-\frac1{n!}\left(0-f^{(n)}(a)(x-a)^n\right)
=\frac{f^{(n)}(a)}{n!}(x-a)^n.
```

Подстановка в предположение индукции добавляет к сумме член с индексом $`n`$ и оставляет остаток порядка $`n+1`$ из [теоремы 4.4.1](#thm-4-4-1). На доске отмечено, что интегрирование по частям применяется к множителям $`f^{(n)}(t)`$ и $`-(x-t)^n/n!`$.

### Печатный слайд 8 (стр. PDF 10). Замечания к интегральному остатку

1. Интегральную форму остатка иногда называют формой К. Якоби.
2. По [первой теореме о среднем](lecture-43-44.md#thm-4-3-1) в условиях [теоремы 4.4.1](#thm-4-4-1) найдётся $`c\in[a,x]`$ (при $`x<a`$ используется ориентированная запись), для которого

```math
\frac1{n!}\int_a^x f^{(n+1)}(t)(x-t)^n\,dt
=\frac{f^{(n+1)}(c)}{n!}\int_a^x(x-t)^n\,dt
=\frac{f^{(n+1)}(c)}{(n+1)!}(x-a)^{n+1}.
```

3. Преимущество интегральной формы: в ней нет неизвестной точки $`c`$.

### Печатный слайд 9 (стр. PDF 11). Формула Валлиса

Двойной факториал $`m!!`$ — произведение натуральных чисел, не превосходящих $`m`$ и имеющих с $`m`$ одинаковую чётность; принято $`0!!=(-1)!!=1`$.

<a id="thm-4-4-2"></a>**Теорема 4.4.2.**

```math
\pi=\lim_{n\to\infty}\frac1n\left(\frac{(2n)!!}{(2n-1)!!}\right)^2.
```

### Печатный слайд 10 (стр. PDF 12). Интегралы степеней синуса

<a id="lem-4-4-1"></a>**Лемма 4.4.1.** Если $`m\in\mathbb Z_+`$, то

```math
\int_0^{\pi/2}\sin^m x\,dx
=\frac{(m-1)!!}{m!!}\begin{cases}
\dfrac\pi2,&m\text{ чётно},\\[2pt]
1,&m\text{ нечётно}.
\end{cases}
```

### Рукописная страница (стр. PDF 13). Доказательство леммы 4.4.1: обозначения и база

Введено $`J_m=\int_0^{\pi/2}\sin^m x\,dx`$. База:

```math
J_0=\int_0^{\pi/2}dx=\frac\pi2,\qquad
J_1=\int_0^{\pi/2}\sin x\,dx=[-\cos x]_0^{\pi/2}=1.
```

Красными пометками проверена формула двойных факториалов для $`m=0`$ и $`m=1`$; далее выводится рекурсия интегрированием по частям при $`m\ge2`$.

### Рукописная страница (стр. PDF 14). Рекурсия для $`J_m`$

Записано $`J_m=\int_0^{\pi/2}\sin^{m-1}x\,d(-\cos x)`$. Интегрирование по частям, $`d(\sin^{m-1}x)=(m-1)\sin^{m-2}x\cos x\,dx`$ и $`\cos^2x=1-\sin^2x`$ дают

```math
J_m=(m-1)\left(J_{m-2}-J_m\right),\qquad
mJ_m=(m-1)J_{m-2},\qquad
J_m=\frac{m-1}{m}J_{m-2}.
```

Граничное слагаемое $`[-\sin^{m-1}x\cos x]_0^{\pi/2}`$ равно нулю.

### Рукописная страница (стр. PDF 15). Первые значения при нечётном показателе и сравнение

Для нечётных индексов выписаны

```math
J_3=\frac23J_1=\frac23,\qquad
J_5=\frac45J_3=\frac45\frac23,
\qquad J_7=\frac67J_5=\frac67\frac45\frac23.
```

Затем используется $`0<\sin x<1`$ при $`0<x<\pi/2`$:

```math
\sin^{2n+1}x<\sin^{2n}x<\sin^{2n-1}x.
```

### Рукописная страница (стр. PDF 16). Первые значения при чётном показателе и оценка

Для чётных индексов:

```math
J_2=\frac12J_0=\frac\pi4,\qquad
J_4=\frac34J_2=\frac34\frac12\frac\pi2,
\qquad J_6=\frac56J_4=\frac56\frac34\frac12\frac\pi2.
```

Интегрирование сравнения со стр. PDF 15 даёт $`J_{2n+1}<J_{2n}<J_{2n-1}`$.

### Рукописная страница (стр. PDF 17). Доказательство формулы Валлиса

Подставляя значения из леммы, получаем

```math
\frac{(2n)!!}{(2n+1)!!}
<\frac{(2n-1)!!}{(2n)!!}\frac\pi2
<\frac{(2n-2)!!}{(2n-1)!!}.
```

После умножения на $`\frac{(2n)!!}{(2n-1)!!}`$ и использования $`(2n+1)!!=(2n+1)(2n-1)!!`$, $`(2n)!!=2n(2n-2)!!`$:

```math
\frac1{2n+1}\left(\frac{(2n)!!}{(2n-1)!!}\right)^2
<\frac\pi2<
\frac1{2n}\left(\frac{(2n)!!}{(2n-1)!!}\right)^2.
```

Положив $`x_n=\frac1n\left(\frac{(2n)!!}{(2n-1)!!}\right)^2`$, получаем $`\frac{2n}{2n+1}x_n<\pi<x_n`$, то есть $`\pi<x_n<\frac{2n+1}{2n}\pi`$. Обе границы стремятся к $`\pi`$, и теорема о зажатой последовательности доказывает [теорему 4.4.2](#thm-4-4-2).

### Печатный слайд 11 (стр. PDF 18). Вторая теорема о среднем интегрального исчисления

<a id="thm-4-4-3"></a>**Теорема 4.4.3 (О. Бонне).** Пусть $`f\in C[a,b]`$, $`g\in C^1[a,b]`$, $`g`$ монотонна на $`[a,b]`$. Тогда существует $`c\in[a,b]`$ такое, что

```math
\int_a^b fg=g(a)\int_a^c f+g(b)\int_c^b f.
```

### Рукописная страница (стр. PDF 19). Доказательство теоремы Бонне: интегрирование по частям

Положим $`F(x)=\int_a^x f`$, так что $`F(a)=0`$ и $`F'=f`$. Тогда

```math
\int_a^b fg=\int_a^b gF'
=-\int_a^b Fg'+[Fg]_a^b
=-\int_a^b Fg'+g(b)\int_a^b f.
```

### Рукописная страница (стр. PDF 20). Применение первой теоремы о среднем

Так как $`g`$ монотонна и [дифференцируема](lecture-22-23.md#def-3-2-1), $`g'`$ сохраняет знак. По первой теореме о среднем к $`F`$ с весом $`g'`$ существует $`c\in[a,b]`$ такое, что

```math
\int_a^b Fg'=F(c)\int_a^b g'=F(c)(g(b)-g(a)).
```

Поскольку $`F(c)=\int_a^c f`$, подстановка в предыдущую строку даёт

```math
\int_a^b fg
=-\left(g(b)-g(a)\right)\int_a^c f+g(b)\int_a^b f
=g(a)\int_a^c f+g(b)\int_c^b f.
```

### Рукописная страница (стр. PDF 21). Геометрическая схема разбиения

Рукописный рисунок показывает отрезок $`[a,b]`$, точку $`c`$ и две части интеграла: $`\int_a^c f`$ и $`\int_c^b f`$; красная дуга охватывает весь отрезок, зелёная — первую часть. Это схема разложения в формуле Бонне, не график функции.

![Стр. PDF 21: схема отрезка Бонне с точкой c и двумя участками интегрирования](../../assets/lectures-2025-26/lec45-46-p21-bonnet-interval.jpg)

### Печатный слайд 12 (стр. PDF 22). Замечания к теореме Бонне

1. Теорема Бонне остаётся верной при более слабых предположениях: $`f\in\mathcal R[a,b]`$, $`g`$ монотонна на $`[a,b]`$.
2. Вторая теорема о среднем обычно не даёт новых результатов по сравнению с теми, которые можно получить интегрированием по частям.

### Рукописная страница (стр. PDF 23). Оценка осциллирующего интеграла

На доске записан пример

```math
I=\int_{100\pi}^{200\pi}\frac{\sin x}{x}\,dx.
```

Утверждение: интеграл «не берущийся» в элементарных функциях, но его можно оценить. Так как $`x>0`$ на промежутке,

```math
|I|\le\int_{100\pi}^{200\pi}\frac{|\sin x|}{x}\,dx
\le\int_{100\pi}^{200\pi}\frac{dx}{x}
=\log 2.
```

На доске приведена более подробная верхняя оценка с [разбиением](lecture-37-38.md#def-4-2-2) по периодам:

```math
I=\sum_{k=100}^{199}\int_{k\pi}^{(k+1)\pi}\frac{\sin x}{x}\,dx,
\qquad
\left|\int_{k\pi}^{(k+1)\pi}\frac{\sin x}{x}\,dx\right|
\le\frac{2}{k\pi}.
```

Отсюда получается грубая оценка порядка $`\sum_{k=100}^{199}2/(k\pi)`$; непосредственно на странице также выписана [верхняя граница](../02-real-numbers.md#sec-2-2) $`\log 2`$ для интеграла абсолютного значения.

### Рукописная страница (стр. PDF 24). Оценивание с помощью формулы Бонне

Записано $`g(x)=1/x`$, монотонная функция, и $`f(x)=\sin x`$. Применение теоремы Бонне на $`[100\pi,200\pi]`$ даёт некоторую $`c\in[100\pi,200\pi]`$:

```math
I=g(100\pi)\int_{100\pi}^{c}\sin x\,dx
+g(200\pi)\int_c^{200\pi}\sin x\,dx.
```

Интегрирование $`\sin x`$ приводит к выражениям с $`[-\cos x]`$ на соответствующих частях. Поскольку $`\cos(100\pi)=\cos(200\pi)=1`$, далее упрощаются граничные значения и оцениваются два слагаемых.

### Рукописная страница (стр. PDF 25). Продолжение оценки

В продолжении вычислений используются $`\cos c\in[-1,1]`$ и формула с предыдущей страницы; записанная итоговая формула упрощается до $`(1-\cos c)/(200\pi)`$, откуда $`0\le I\le 1/(100\pi)`$. Рукописное вычисление оценивает исходный знакопеременный интеграл, а не утверждает его [абсолютную сходимость](../04-numeric-series.md#sec-4-3).

### Печатный слайд 13 (стр. PDF 26). Неравенство Йенсена для интегралов

<a id="thm-4-4-4"></a>**Теорема 4.4.4.** Пусть $`f`$ выпукла и непрерывна на $`\langle A,B\rangle`$, $`\varphi:[a,b]\to\langle A,B\rangle`$ непрерывна, $`\lambda:[a,b]\to[0,+\infty)`$ непрерывна и $`\int_a^b\lambda=1`$. Тогда

```math
f\left(\int_a^b\lambda\varphi\right)
\le\int_a^b\lambda\,(f\circ\varphi).
```

### Рукописная страница (стр. PDF 27). Доказательство Йенсена: обозначения и крайние наклоны

Введены

```math
E=\{x\in[a,b]:\lambda(x)>0\},\qquad
m=\inf_E\varphi,\qquad M=\sup_E\varphi,
```

а также $`c=\int_a^b\lambda\varphi`$. По непрерывности $`\varphi`$ значения на отрезке ограничены. Случай $`m=M`$ даёт постоянное значение $`\varphi`$ на $`E`$ и равенство. Если $`m<M`$, то $`c\in[m,M]`$; [выпуклая функция](lecture-31-32.md#def-3-8-1) имеет в точке $`c`$ опорную прямую $`y=\alpha x+\beta`$:

```math
f(c)=\alpha c+\beta,\qquad f(t)\ge\alpha t+\beta.
```

### Рукописная страница (стр. PDF 28). Доказательство Йенсена: интегрирование опорной прямой

Умножая опорное неравенство на $`\lambda\ge0`$ и интегрируя, получаем

```math
\int_a^b\lambda f(\varphi)
\ge\int_a^b\lambda(\alpha\varphi+\beta)
=\alpha\int_a^b\lambda\varphi+\beta\int_a^b\lambda
=\alpha c+\beta=f(c).
```

Это доказывает [теорему 4.4.4](#thm-4-4-4). Рукописный аргумент использует непрерывность $`f`$ и выпуклость на отрезке значений $`\varphi`$; при [граничной точке](lecture-57-58.md#def-5-3-4) опорная прямая понимается односторонне.

### Печатный слайд 14 (стр. PDF 29). Замечания к неравенству Йенсена

1. Если $`\varphi`$ не постоянна на $`E=\{x\in[a,b]:\lambda(x)>0\}`$, а $`f`$ строго выпукла, [неравенство Йенсена](#thm-4-4-4) строгое.
2. Для вогнутой функции $`f`$ неравенство выполняется с противоположным знаком.

# 2. Действительные числа и полнота

[← 1. Логика, множества и функции](01-logic-sets-functions.md) · [Оглавление](index.md) · [Термины и теоремы](term-index.md) · [3. Последовательности и пределы →](03-sequences.md)

> **Цель.** Понять алгебраические, порядковые свойства и полноту, отличающую $`\mathbb R`$ от $`\mathbb Q`$.

<a id="sec-2-1"></a>
## 2.1 Упорядоченное поле

Действительные числа образуют поле: сложение и умножение ассоциативны, коммутативны, связаны дистрибутивностью, имеют нейтральные и обратные элементы (кроме деления на ноль). Порядок $`<`$ согласован с операциями:

```math
a<b\implies a+c<b+c,
```
```math
a<b,\ c>0\implies ac<bc.
```

При умножении на отрицательное число знак неравенства меняется. Модуль определяется как

```math
|x|=\begin{cases}x,&x\ge0,\\-x,&x<0.\end{cases}
```

Для любых $`x,y\in\mathbb R`$

```math
|xy|=|x|\,|y|,\qquad |x+y|\le |x|+|y|,
```

и верно обратное неравенство треугольника $`\bigl||x|-|y|\bigr|\le |x-y|`$. Величина $`|x-y|`$ — расстояние между точками.

<a id="sec-2-2"></a>
## 2.2 Супремум и инфимум

Пусть $`\varnothing\ne A\subseteq\mathbb R`$. Число $`u`$ — **верхняя грань**, если $`a\le u`$ для всех $`a\in A`$. **Супремум** $`\sup A`$ — наименьшая верхняя грань, инфимум — наибольшая нижняя грань.

> <a id="completeness-axiom"></a>**Аксиома полноты.** Любое непустое ограниченное сверху подмножество $`\mathbb R`$ имеет супремум в $`\mathbb R`$.

Равносильное свойство: любое непустое ограниченное снизу множество имеет инфимум. Супремум не обязан принадлежать множеству: $`\sup(0,1)=1`$, а максимум обязан.

Полезный критерий:

```math
u=\sup A\iff
\begin{cases}
a\le u\quad(a\in A),\\
\forall\varepsilon>0\;\exists a\in A:a>u-\varepsilon.
\end{cases}
```

Множество $`\{q\in\mathbb Q:q^2<2\}`$ не имеет рационального супремума, поэтому $`\mathbb Q`$ неполно.

<a id="sec-2-3"></a>
## 2.3 Следствия полноты

> <a id="archimedean-property"></a>**Архимедовость.** Для любого $`x\in\mathbb R`$ найдётся $`n\in\mathbb N`$ с $`n>x`$. Равносильно: для любого $`\varepsilon>0`$ найдётся $`n`$ такое, что $`1/n<\varepsilon`$.

Если бы $`\mathbb N`$ было [ограничено сверху](#sec-2-2), то для его супремума $`s`$ нашлось бы целое $`n`$ с $`s-1<n<s`$, откуда $`n+1>s`$ — противоречие.

> <a id="density-of-rationals"></a>**Плотность рациональных чисел.** Если $`a<b`$, существует $`q\in\mathbb Q`$ с $`a<q<b`$.

Выберем $`n`$ с $`n(b-a)>1`$ и целое $`m`$ между $`na`$ и $`nb`$; тогда $`q=m/n`$ подходит. Иррациональные числа также плотны: в любой интервал можно поместить $`q+\sqrt2/k`$.

<a id="sec-2-4"></a>
## 2.4 Вложенные отрезки

Последовательность отрезков $`I_n=[a_n,b_n]`$ называется **вложенной**, если $`I_{n+1}\subseteq I_n`$.

> <a id="nested-interval-theorem"></a>**Теорема о вложенных отрезках.** Для вложенных замкнутых ограниченных отрезков $`\bigcap_{n=1}^{\infty}I_n\ne\varnothing`$. Если $`b_n-a_n\to0`$, пересечение состоит ровно из одной точки.

Действительно, $`a=\sup\{a_n\}`$ принадлежит каждому отрезку. Замкнутость и ограниченность существенны: пересечение $`(0,1/n)`$ пусто, как и пересечение $`[n,\infty)`$.

Расширенная прямая $`\overline{\mathbb R}=\mathbb R\cup\{-\infty,+\infty\}`$ удобна для неограниченных множеств, но $`\infty-\infty`$ не определено.

## Разобранный пример

Пусть $`A=\{1-1/n:n\in\mathbb N\}`$. Все элементы меньше $`1`$. Для любого $`\varepsilon>0`$ по [архимедовости](#archimedean-property) найдётся $`1/n<\varepsilon`$, значит $`1-1/n>1-\varepsilon`$. Поэтому $`\sup A=1`$. Поскольку $`1\notin A`$, максимума нет.

## Типичные ошибки

1. «Ограничено» означает ограничено и сверху, и снизу.
2. $`\sup A`$ может не лежать в $`A`$, а $`\max A`$ обязан лежать.
3. В [теореме о вложенных отрезках](#nested-interval-theorem) нужны замкнутые ограниченные отрезки.

## Упражнения

1. Докажите $`\sup(A+B)=\sup A+\sup B`$ для непустых ограниченных множеств, где $`A+B=\{a+b:a\in A,b\in B\}`$.
2. Покажите, что между любыми двумя действительными числами есть иррациональное.
3. Найдите $`\sup\{x\in\mathbb R:x^2+x<2\}`$ и проверьте, является ли он максимумом.

<details>
<summary>Краткие ответы</summary>

1. Сумма супремумов — верхняя грань; приблизьте оба супремума с точностью $`\varepsilon/2`$.
2. Возьмите подходящее рациональное $`q`$ и достаточно большое $`k`$, затем рассмотрите $`q+\sqrt2/k`$.
3. Множество равно $`(-2,1)`$; супремум равен $`1`$, максимума нет.
</details>

# Работа с хранилищем и обозначения

[[ru/index|Оглавление]] · [[ru/formula-sheet|Шпаргалка]] · [[ru/glossary|Глоссарий]]

## Obsidian и GitHub

Курс существует в двух представлениях, которые генерируются из одного текста командой `python3 scripts/build_views.py`:

| | Для GitHub — `MathInMind/` | Для Obsidian — `MathInMind-Obsidian/` |
|---|---|---|
| Как открыть | просматривать репозиторий на GitHub | **Open folder as vault** в Obsidian |
| Ссылки | относительные Markdown-ссылки с `#якорями` | `[[вики-ссылки]]` с предпросмотром при наведении, обратными ссылками и графом |
| Строчная формула | `` $`...`$ `` (не портится обработкой Markdown на GitHub) | `$...$` (MathJax) |
| Выключная формула | блок ```` ```math ```` | `$$...$$` |
| Определения и теоремы | цитаты с жирной подписью | цветные выноски (`[!definition]`, `[!theorem]`, …) |
| Ответы к упражнениям | блоки `<details>` | свёрнутые выноски `[!answer]-` |

До любого термина, именной теоремы или пронумерованного утверждения лекций можно дойти одним щелчком: первое упоминание термина в каждой заметке ведёт к его определению, ссылки вида «[[ru/lectures-2025-26/lecture-13#^thm-2-3-5|теорема 2.3.5]]» ведут к формулировке, а [[ru/term-index|указатель терминов и теорем]] собирает их все. Диаграммы — простые Mermaid-блоки `flowchart`, их отображают оба представления. Сначала решите упражнение, потом раскрывайте ответ.

Сторонние плагины и общий преамбульный файл MathJax не нужны. Если Obsidian показывает формулы как текст, проверьте, что открыт каталог `MathInMind-Obsidian/` (а не `MathInMind/`) и что поддержка MathJax включена в настройках редактора.

## Логика и множества

| Обозначение | Значение |
|---|---|
| $\forall$, $\exists$ | для всех, существует |
| $\neg$, $\land$, $\lor$, $\implies$, $\iff$ | не, и, или, влечёт, тогда и только тогда |
| $\varnothing$, $A^c$, $A\setminus B$ | пустое множество, дополнение, разность |
| $A\subseteq B$ | подмножество, включая равенство |
| $\mathcal P(A)$ | булеан множества $A$ |
| $1_A$ | индикатор: $1_A(x)=1$ при $x\in A$, иначе $0$ |

## Числовые множества и промежутки

Мы используем $\mathbb N=\{1,2,3,\ldots\}$ и $\mathbb N_0=\{0,1,2,\ldots\}$. Символы $\mathbb Z,\mathbb Q,\mathbb R,\mathbb C$ обозначают целые, рациональные, действительные и комплексные числа. Расширенная прямая: $\overline{\mathbb R}=\mathbb R\cup\{-\infty,+\infty\}$.

Промежутки: $(a,b)$ открытый, $[a,b]$ замкнутый, $[a,b)$ и $(a,b]$ полуоткрытые. Если не оговорено иное, $\log x$ — натуральный логарифм.

## Обозначения анализа

| Обозначение | Значение |
|---|---|
| $\sup A$, $\inf A$ | точная верхняя и нижняя грани |
| $\limsup a_n$, $\liminf a_n$ | [[ru/03-sequences#3.5 Верхний и нижний пределы\|верхний и нижний пределы]] |
| $a_n\sim b_n$ | $a_n/b_n\to1$ для членов, отличных от нуля с некоторого номера |
| $f=O(g)$ | $\vert f\vert \le C\vert g\vert$ в указанном предельном режиме |
| $f=o(g)$ | $f/g\to0$ в указанном предельном режиме |
| $f'$, $\partial_i f$, $Df$ | обычная, частная и [[ru/15-multivariable-differentiation#15.1 Полная производная\|полная производные]] |
| $\nabla f$, $Hf$ | [[ru/15-multivariable-differentiation#15.2 Частные производные и производные по направлению\|градиент]] и [[ru/15-multivariable-differentiation#15.4 Высшие производные и формула Тейлора\|гессиан]] |
| $\Vert x\Vert _p$ | $p$-норма; $\Vert x\Vert$ обычно означает [[ru/14-several-variables#14.1 Евклидово пространство и нормы\|евклидову норму]] |
| $\langle f,g\rangle$ | [[ru/21-lp-spaces#21.4 Гильбертово пространство L2\|скалярное произведение]], уточняется в контексте |
| [[ru/19-measure-theory#19.4 Измеримые функции\|п.в.]] | почти всюду, вне [[ru/08-riemann-integration#8.2 Интегральные суммы и свойства\|множества меры ноль]] |
| $C^k$, $C^\infty$ | $k$ раз непрерывно дифференцируемая, бесконечно [[ru/06-derivatives#6.1 Определение и линейное приближение\|дифференцируемая]] |

Для асимптотических обозначений всегда указывайте режим: $x\to0$ или $n\to\infty$. В интегралах $dA$ и $dV$ — элементы площади и объёма; $d\mu$ указывает меру.

## Проверка доказательства

Перед применением теоремы спросите:

1. Выполнены ли условия на область и гладкость?
2. Какая сходимость используется: поточечная, равномерная, абсолютная, почти всюду или по норме?
3. Существенны ли концы, ориентация, [[ru/13-metric-spaces#13.4 Компактность|компактность]] и конечность?
4. Пример доказывает утверждение или только иллюстрирует его?
5. Можно ли контрпримером показать необходимость опущенного условия?

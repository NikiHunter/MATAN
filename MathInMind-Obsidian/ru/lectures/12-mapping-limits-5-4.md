# §5.4 Предел отображения нескольких переменных

[[ru/lectures/11-topology-rn-5-3|← §5.3]] · [[ru/lectures/index|Лекционный указатель]] · [[ru/lectures/terms|Термины]] · [[ru/exam/index|Билеты 52–54]] · [[ru/lectures/13-continuity-rn-5-5|§5.5 →]]

## Определение 5.4.1 — предел по Коши

Пусть $a$ — предельная точка $E$, $f:E\to\mathbb R^m$. Тогда $f(x)\to A$ при $x\to a$, если

$$
\forall\varepsilon>0\;\exists\delta>0:\quad
x\in\dot V_\delta(a)\cap E\implies f(x)\in V_\varepsilon(A).
$$

Для конечных $a,A$ это $\|f(x)-A\|<\varepsilon$ при $0<\|x-a\|<\delta$. Для $a=\infty$ условие на $x$ становится $\|x\|>\delta$; для $A=\infty$ условие на значение — $\|f(x)\|>\varepsilon$.

Значение $f(a)$ не участвует в пределе; сама точка $a$ может не принадлежать $E$.

## Определение 5.4.2 — предел по Гейне

$f(x)\to A$, если для **каждой** последовательности $x^k\in E\setminus\{a\}$ с $x^k\to a$ выполняется $f(x^k)\to A$.

Одна последовательность может опровергнуть предел, если её значения не сходятся к $A$. Но проверка конечного набора путей не доказывает предел.

## Теорема 5.4.1 — эквивалентность Коши и Гейне

[[#Определение 5.4.1 — предел по Коши|Определения 5.4.1]] и [[#Определение 5.4.2 — предел по Гейне|5.4.2]] равносильны.

**Доказательство.** Коши $\Rightarrow$ Гейне: любая $x^k\to a$ с $x^k\ne a$ с некоторого номера попадает в $\dot V_\delta(a)\cap E$, поэтому $f(x^k)\in V_\varepsilon(A)$.

Гейне $\Rightarrow$ Коши: если Коши нарушено для некоторого $\varepsilon_0$, то для каждого $k$ выберите $x^k\in\dot V_{1/k}(a)\cap E$ с $f(x^k)\notin V_{\varepsilon_0}(A)$. Тогда $x^k\to a$, но $f(x^k)\not\to A$.

## Следствия из лекции: единственность и покоординатный предел

Предел отображения единственен по [[ru/lectures/10-vector-sequences-5-2#Лемма 5.2.1 — единственность предела|лемме 5.2.1]] и определению Гейне. Для $f=(f_1,\ldots,f_m)$ и конечного $A$:

$$
f(x)\to A\iff f_i(x)\to A_i\quad(i=1,\ldots,m).
$$

Это следует из [[ru/lectures/10-vector-sequences-5-2#Теорема 5.2.1 — покоординатная сходимость|теоремы 5.2.1]]. Покоординатный предел **значения** отображения не следует путать с [[#Определение 5.4.2 — предел по Гейне|повторными пределами]] по входным переменным.

**Контрпример.** Для $f(x,y)=xy/(x^2+y^2)$ пути $(1/k,0)$ и $(1/k,1/k)$ дают пределы $0$ и $1/2$, поэтому совместного предела в нуле нет. Оба повторных предела при этом равны нулю.

## Теорема 5.4.2 — арифметические операции

Если $f\to A$, $g\to B$, $\lambda\to\alpha$, то

$$
f+g\to A+B,\qquad \lambda f\to\alpha A,\qquad f\cdot g\to A\cdot B.
$$

Для скалярной $g$ и $B\ne0$ также $f/g\to A/B$.

**Доказательство.** По Гейне всё сводится к [[ru/lectures/10-vector-sequences-5-2#Теорема 5.2.2 — арифметика пределов|теореме 5.2.2]] для последовательностей. Для частного ненулевой предел обеспечивает $g(x)\ne0$ в достаточно малой [[ru/lectures-2025-26/lecture-14#^def-2-4-2|проколотой окрестности]].

## Теорема 5.4.3 — предел композиции

Если $f(x)\to b$ при $x\to a$ и $g$ непрерывна в $b$, то

$$
g(f(x))\to g(b).
$$

**Доказательство.** Для $\varepsilon$ выберите $\sigma$ из непрерывности $g$, затем $\delta$ из предела $f$. Если $x$ достаточно близко к $a$, то $f(x)$ достаточно близко к $b$ и $g(f(x))$ близко к $g(b)$. Условие $f(x)\ne b$ не требуется, поскольку в $b$ задано именно $g(b)$.

## Теорема 5.4.4 — критерий Больцано–Коши для отображения

Конечный предел $f$ при $x\to a$ существует тогда и только тогда, когда

$$
\forall\varepsilon>0\;\exists V(a):\quad
x,y\in\dot V(a)\cap E\implies\|f(x)-f(y)\|<\varepsilon.
$$

Это называется сходимостью $f$ в себе.

**Доказательство.** Необходимость — неравенство треугольника через $A$. Достаточность: по Гейне для любой $x^k\to a$ последовательность $f(x^k)$ фундаментальна и потому сходится по [[ru/lectures/10-vector-sequences-5-2#Теорема 5.2.5 — критерий Больцано–Коши|теореме 5.2.5]]. Две такие последовательности можно объединить в одну; [[ru/lectures-2025-26/lecture-13#^def-2-3-10|условие Коши]] показывает, что предел одинаков.

## Практика в стиле задачников

1. Для $f(x,y)=(x^3+y^3)/(x^2+y^2)$ положим $r=\sqrt{x^2+y^2}$. Тогда $|f|\le|x|+|y|\le2r\to0$, поэтому предел в нуле равен нулю.
2. Для $f(x,y)=x^2y/(x^4+y^2)$ путь $y=kx^2$ даёт $k/(1+k^2)$, поэтому совместного предела нет.
3. Для $F(x,y)=(x+y,xy)$ предел при $(x,y)\to(1,2)$ равен $(3,2)$ по непрерывности компонент.
4. Для $\sin(x^2+y^2)/(x^2+y^2)$ композиция с $\sin t/t$ даёт предел $1$ в нуле.

Примеры оригинальные, по типам задач Демидовича и Зорича на совместные пределы.

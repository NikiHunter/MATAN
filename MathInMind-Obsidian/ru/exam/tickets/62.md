# Билет 62. Геометрические свойства градиента. Экстремальное свойство градиента

## Вопрос

Геометрические свойства [[ru/lectures/14-differentiability-6-1#Определение 6.1.6 — матрица Якоби и градиент|градиента]]. Экстремальное свойство градиента.

## Эталонный ответ

При дифференцируемости $\partial_ef(a)=\nabla f(a)\cdot e$. Для единичного $e$ по Коши–Буняковскому:

$$
|\partial_ef(a)|\le\|\nabla f(a)\|.
$$

Равенство достигается только при $e=\pm\nabla f/\|\nabla f\|$. Таким образом градиент указывает направление наибольшего возрастания, $-\nabla f$ — наибольшего убывания, а максимальная скорость равна $\|\nabla f\|$. Градиент также нормален линии или поверхности уровня при его ненулевом значении.

## Разобранный пример

Для $f=x^2+y^2$ в $(1,2)$: $\nabla f=(2,4)$, максимальная [[ru/lectures/14-differentiability-6-1#Определение 6.1.4 — производная по вектору и по направлению|производная по направлению]] $2\sqrt5$ при $e=(1,2)/\sqrt5$.

## Примечания

- Файлы `Семинар_09_09_отред.pdf` и `дополненный_семинар_по_МА_от_07_10_2026.pdf` — это отредактированные/дополненные версии соответствующих семинаров. При транскрипции использованы наиболее полные версии.
- Семинар от 14.10.2026 (`Интерактивная_панель_20261014.pdf`) содержит только пустые страницы и не транскрибирован.
- Исходные PDF и скриншоты в Git не коммитятся (как и сканы предыдущих семинаров): в папке лежат только текстовые транскрипции; имена источников указаны в шапке каждого файла.
- `13_2026-11-13_Параметрический_интеграл.pdf.txt` — дословная постраничная OCR доски 13.11.2026;
  `13_2026-11-13_Параметрический_интеграл_и_равномерная_сходимость.md` — та же доска, сгруппированная по утверждениям (Obsidian, MathJax).
- `14_Консультация_к_экзамену_20-11-2026.md` — OCR девяти кадров консультации, упорядоченных по таймкоду записи; в конце — сводка двух типов задач контрольной работы 20.11.2026.
- Во всех новых файлах `<?>` означает сомнительное место; сразу после знака в скобках дана версия прочтения этой части фразы (по контексту доски). Заведомые описки доски (например, $\frac{42}{(0;2)!}$ вместо $\frac{72}{(0;2)!}$ в примере 1'.1) не исправлены, а помечены `<?>`.

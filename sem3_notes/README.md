## Примечания

- Файлы `Семинар_09_09_отред.pdf` и `дополненный_семинар_по_МА_от_07_10_2026.pdf` — это отредактированные/дополненные версии соответствующих семинаров. При транскрипции использованы наиболее полные версии.
- Семинар от 14.10.2026 (`Интерактивная_панель_20261014.pdf`) содержит только пустые страницы и не транскрибирован.
- Исходные PDF и скриншоты в Git не коммитятся (как и сканы предыдущих семинаров): в папке лежат только текстовые транскрипции; имена источников указаны в шапке каждого файла.
- `13_2026-11-13_Параметрический_интеграл.pdf.txt` — дословная постраничная OCR доски 13.11.2026;
  `13_2026-11-13_Параметрический_интеграл_и_равномерная_сходимость.md` — та же доска, сгруппированная по утверждениям (Obsidian, MathJax).
- `14_Консультация_к_экзамену_20-11-2026.md` — OCR девяти кадров консультации, упорядоченных по таймкоду записи. Выкладки пересчитаны в sympy; пример 1'.3 доведён до ответа (на кадрах нет проверки миноров): $(0;-\sqrt2;-\frac{\sqrt2}3)$ — минимум, $(0;\sqrt2;\frac{\sqrt2}3)$ — экстремума нет, $(1;1;\frac13)$ — максимум. В конце — сводка задач контрольной работы 20.11.2026.
- `14_Консультация_к_экзамену_20-11-2026_конспект.md` — конспект аудиозаписи той же консультации (обещания преподавателя, перенос рядов, тактика). Это копия `Exam_Consultation_Summary.md` с исправлениями; список исправлений — в конце файла. Главное: окаймлённая матрица Гессе записана, как на доске, с окаймлением в первой строке и столбце, иначе «угловой минор третьего порядка» даёт неверный ответ.
- В файлах 13 и 14 `<?>` означает сомнительное прочтение, которое по смыслу доски не восстановить (таймкоды, неразборчивые пометки на полях). Сомнения, которые снимаются вычислением или записью консультации, сняты. Ошибки доски помечены «**Описка доски**» / «**Ошибка доски**» с верным значением (например, $\frac{42}{(0;2)!}$ вместо $\frac{72}{(0;2)!}$ в примере 1'.1); в дословной OCR `.pdf.txt` сам текст доски не меняется, а в `.md`-файле семинара 13.11 выкладки исправлены (предел по диагонали в примере 15.4 равен $1$, а не $\frac12$) и дописано доказательство п. 3.

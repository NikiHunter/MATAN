# Supplied source archive

`MathInMind/` contains the unchanged extracted contents of the user-supplied `MathInMind.zip.txt` attachment. Despite its suffix, the attachment had a valid ZIP signature.

The archive includes:

- `МАТАН_Л/`: Russian lecture notes, principally convexity, integration, and several-variable analysis;
- `МАТАН_Б/`: Russian question-by-question theory notes;
- `MATAN_ULTIMATE/`: concise revision notes;
- PNG diagrams and slide captures, including a directory whose legacy filenames contain mojibake.

The original filenames and contents are intentionally preserved for traceability. These files are **source material**, not the normalized trilingual course. Some Obsidian wiki-style image links in the legacy notes are not expected to render as links on GitHub. New course files use portable relative Markdown links instead.

The curated course starts at [`../MathInMind/en/index.md`](../MathInMind/en/index.md), with parallel Russian and Spanish editions.

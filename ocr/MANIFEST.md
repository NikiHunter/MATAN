# Инвентарь страниц

**Источник.** Архив `handwritten_notes_part_1_*.txt` (4 фрагмента, склеенные в один файл
96 941 029 байт), присланный в чат. Внутри — ZIP с AES-шифрованием:

- сигнатура: `50 4B 03 04` (`PK\x03\x04`) — обычный ZIP;
- 21 запись, все `.jpg`, все зашифрованы (AES-256, `PK compat. v5.1`), поэтому системный
  `unzip` их пропускает; распаковка выполнена библиотекой `pyzipper` с паролем из задания;
- `testzip()` — ошибок нет; посторонних файлов (`__MACOSX`, каталоги) в архиве нет;
- zip-slip проверен: каждое имя сверялось с `realpath` целевого каталога.

**Порядок страниц.** Определён естественной сортировкой имён: имена — метки времени
съёмки (`YYYYMMDD_HHMMSS.jpg`) и возрастают монотонно; EXIF `DateTimeOriginal`
подтверждает тот же порядок (28.10.2026, 16:05:46 → 16:08:35). Перестановок нет.

**Ориентация.** У всех 21 файлов EXIF-orientation = 6 (съёмка в альбомной ориентации,
поворот на 90° по часовой стрелке для просмотра). Поворот применён при нормализации,
размер после поворота — 2250 × 4000 (портрет). Дополнительных перекосов не обнаружено.

**Нормализация.** Файлы перекодированы (JPEG, quality 92) после `exif_transpose`;
содержимое не кадрировалось, не ретушировалось, не выравнивалось.

**Размер.** 41 МБ на диске (< 50 МБ), поэтому сканы **закоммичены** в `raw/scans/`.

## Часть 4 — `Videocaptures_lectures_83_84.txt` (страницы p083–p124, лекции 83–84)

**Источник.** Один файл `.txt` объёмом 12,010,775 байт
(SHA-256 `e4947ec2cc2e55eba5e414db295f3a8d420e9d727bd0051ed4d063968be5f95b`). Внутри — обычный ZIP (`PK\x03\x04`):
43 записи = каталог `Videocaptures/` + 42 JPEG-кадра, метод 8 (deflate),
флаг шифрования `0x0`; `testzip()` — ошибок нет. Пароль из задания

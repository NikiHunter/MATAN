# Первый признак сравнения положительных рядов

> [!theorem] Первый признак сравнения положительных рядов
> Для рядов $\sum_{n=1}^{\infty}a_n$ и $\sum b_n$ с $0\le a_n\le b_n$ из сходимости второго ряда следует сходимость первого, а из расходимости первого — расходимость второго.

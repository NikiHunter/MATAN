# Теорема Тейлора–Пеано

> [!theorem] Теорема 6.5.1
> Пусть $E\subset\mathbb{R}^n$, $a$ — внутренняя точка $E$, $s\in\mathbb{Z}_+$, отображение $f: E\to\mathbb{R}^m$ $s$ раз дифференцируемо в точке $a$. Тогда
> $$f(x)=\sum_{|\alpha|\le s}\frac{1}{\alpha!}\frac{\partial^\alpha f}{\partial x^\alpha}(a)(x-a)^\alpha+o(\|x-a\|^s)\quad \text{при } x\to a.$$

Иными словами, многочлен Тейлора порядка $s$ существует и равен
$$T_{a,s}f(x)=\sum_{|\alpha|\le s}\frac{1}{\alpha!}\frac{\partial^\alpha f}{\partial x^\alpha}(a)(x-a)^\alpha,$$
где суммирование идёт по всем мультииндексам порядка $\le s$.

> [!proof]- Доказательство из конспекта
> Положим $p(x)$ равным этой сумме и $F:=f-p$. Для любого мультииндекса $\alpha$ порядка не больше $s$ имеем $\partial^\alpha F/\partial x^\alpha(a)=0$; по лемме 6.5.1 получаем $F(x)=o(\|x-a\|^s)$ при $x\to a$. $\blacksquare$

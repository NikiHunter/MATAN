# Необходимое условие экстремума

> [!theorem] Теорема 6.7.1
> Пусть $E\subset\mathbb{R}^n$, $a$ — внутренняя точка $E$, функция $f: E\to\mathbb{R}$ дифференцируема в точке $a$. Если $a$ является точкой экстремума $f$, то $d_af=0$.

В координатах это означает $\dfrac{\partial f}{\partial x_k}(a)=0$ при всех $k\in\{1,\ldots,n\}$, то есть $\operatorname{grad}f(a)=0$: точка экстремума стационарна.

> [!proof]- Доказательство из конспекта
> Пусть $a$ — точка минимума: $f(x)\ge f(a)$ при $x\in V_\delta(a)$. Для $h\neq0$ полагаем $F(t)=f(a+th)$ при $t\in\left(-\delta/\|h\|,\delta/\|h\|\right)$. Тогда $F'(0)=d_af(h)$ и $F(t)\ge F(0)$, поэтому $F'(0)=0$ для всех $h\neq0$, то есть $d_af=0$. $\blacksquare$

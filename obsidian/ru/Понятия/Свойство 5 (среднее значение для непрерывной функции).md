# Свойство 5 (среднее значение для непрерывной функции)

> [!theorem] Свойство 5 (среднее значение для непрерывной функции)
> Свойство 5: для непрерывной функции на допустимом связном множестве найдётся точка, значение функции в которой даёт среднее значение:
> $\int_\Omega f(x)\,dx=f(\xi)\mu(\Omega),\quad\xi\in\Omega$

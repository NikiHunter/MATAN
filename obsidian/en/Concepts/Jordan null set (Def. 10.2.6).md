# Jordan null set (Def. 10.2.6)

> [!definition] Jordan null set (Def. 10.2.6)
> Def. 10.2.6: for every $\varepsilon>0$ the set can be covered by a finite system of rectangles with $\sum_{i=1}^k\mu(I_i)<\varepsilon$.

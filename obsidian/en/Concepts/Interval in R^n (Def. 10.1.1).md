# Interval in R^n (Def. 10.1.1)

> [!definition] Interval in R^n (Def. 10.1.1)
> Def. 10.1.1: the set $I=I_{a,b}=\{x\in\mathbb{R}^n: a_i\le x_i\le b_i,\ i=\overline{1,n}\}$ is called an interval in $\mathbb{R}^n$.

# Gamma function (Def. 9.3.1)

> [!definition] Gamma function (Def. 9.3.1)
> Def. 9.3.1: the gamma function is given by $\Gamma(y)=\int_0^\infty x^{y-1}e^{-x}\,dx$ for $y>0$.

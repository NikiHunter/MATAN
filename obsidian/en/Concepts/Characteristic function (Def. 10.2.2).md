# Characteristic function (Def. 10.2.2)

> [!definition] Characteristic function (Def. 10.2.2)
> Def. 10.2.2: $\chi_\Omega(x)=\begin{cases}1,&x\in\Omega\\0,&x\notin\Omega\end{cases}$; its discontinuities lie only on $\partial\Omega$, so for admissible $\Omega$ it is continuous almost everywhere.

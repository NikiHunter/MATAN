# Analytic function (Def. 8.4.4)

> [!definition] Analytic function (Def. 8.4.4)
> Def. 8.4.4: $f$ is analytic at $a$ if it expands into a power series $f(x)=\sum C_k(x-a)^k$ in a neighbourhood of $a$.

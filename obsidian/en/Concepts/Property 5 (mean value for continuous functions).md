# Property 5 (mean value for continuous functions)

> [!theorem] Property 5 (mean value for continuous functions)
> Property 5: for a continuous function on an admissible connected set there is a point at which the value of the function gives the mean value:
> $\int_\Omega f(x)\,dx=f(\xi)\mu(\Omega),\quad\xi\in\Omega$

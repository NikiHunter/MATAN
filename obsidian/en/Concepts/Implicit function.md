# Implicit function

Let $f: E\subset\mathbb{R}^2\to\mathbb{R}$. Consider the equation in the variables $x$ and $y$:
$$f(x,y)=0,\quad (x,y)\in E. \tag{6.6.1}$$

> [!definition] Definition 6.6.1
> The map $\varphi$ introduced in theorem 6.6.1 is called the implicit map generated by the equation $f(x,y)=0$ in a neighbourhood of $(x^0,y^0)$.

Equation (6.6.1) defines a dependence between $x$ and $y$ called implicit. If one variable can be expressed uniquely through the other, the solution set has the form $\{(x,y)\in E:\ y=\varphi(x)\}$, and $\varphi$ is called the implicit function generated by (6.6.1). If near every point of $E$ the equation generates an implicit function, it is called locally solvable.

The notes record a sufficient condition for local solvability near $a=(x^0,y^0)$: $\operatorname{grad}f(a)\neq0$.

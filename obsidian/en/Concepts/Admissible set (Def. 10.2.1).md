# Admissible set (Def. 10.2.1)

> [!definition] Admissible set (Def. 10.2.1)
> Def. 10.2.1: $\Omega\subset\mathbb{R}^n$ is admissible if it is bounded and its boundary $\partial\Omega$ has measure zero.

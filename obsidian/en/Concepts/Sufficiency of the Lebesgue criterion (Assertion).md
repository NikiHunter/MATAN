# Sufficiency of the Lebesgue criterion (Assertion)

> [!theorem] Sufficiency of the Lebesgue criterion (Assertion)
> Assertion: a function defined and bounded on an interval and continuous almost everywhere is Riemann integrable. The board proves it via the Cauchy criterion and a cover of the set of discontinuity points:
> $f\in\mathcal{R}([a,b])$

# Riemann-integrable function (Def. 10.1.7)

> [!definition] Riemann-integrable function (Def. 10.1.7)
> Def. 10.1.7: if the finite limit of the Riemann sums exists, $f$ is integrable; the set of such functions is denoted by $R(I)$.

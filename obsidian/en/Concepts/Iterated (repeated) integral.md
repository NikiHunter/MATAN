# Iterated (repeated) integral

> [!definition] Iterated (repeated) integral
> Iterated integral: for a fixed value of the first variable one first computes the inner integral, then integrates the resulting function in the outer variable:
> $F(x)=\int_{I_y}f(x,y)\,dy$

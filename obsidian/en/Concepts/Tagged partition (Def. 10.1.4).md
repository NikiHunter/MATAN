# Tagged partition (Def. 10.1.4)

> [!definition] Tagged partition (Def. 10.1.4)
> Def. 10.1.4: if a point $\xi_j\in I_j$ is fixed in each $I_j$ of a partition $P$, it is called a tagged partition.

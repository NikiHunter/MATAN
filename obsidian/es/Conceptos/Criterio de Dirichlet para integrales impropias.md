# Criterio de Dirichlet para integrales impropias

> [!theorem] Criterio de Dirichlet para integrales impropias
> Si $f(x,y)\to0$ uniformemente y $|G(t,y)|=\left|\int_a^t g(x,y)\,dx\right|\le C$, entonces $\int_a^bf g\,dx$ converge uniformemente.

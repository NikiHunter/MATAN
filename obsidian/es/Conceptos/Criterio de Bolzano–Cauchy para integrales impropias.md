# Criterio de Bolzano–Cauchy para integrales impropias

> [!theorem] Criterio de Bolzano–Cauchy para integrales impropias
> Criterio: $\forall\varepsilon>0\ \exists b_0\ \forall t_1,t_2\in(b_0,b)$ se tiene $\left|\int_{t_1}^{t_2}f(x,y)\,dx\right|<\varepsilon$.

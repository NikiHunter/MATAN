# Criterio de Weierstrass para integrales impropias

> [!theorem] Criterio de Weierstrass para integrales impropias
> Si $|f(x,y)|\le\varphi(x)$ y $\int_a^b\varphi(x)\,dx$ converge, la integral converge uniformemente.
